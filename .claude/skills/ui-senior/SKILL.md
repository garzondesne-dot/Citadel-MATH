## 1. 다섯 원칙 (모든 판단의 기준 · 순서 = 우선순위)
1. **📱 모바일 전용**: 세로 360 ~ 430px 하나만 기준(더 넓으면 가운데 430px 기둥 + 양옆 바탕). 가로 스크롤 0. 주요 단추는 엄지가 닿는 **아래쪽**. 누르는 칸 **48px 이상** · 칸 사이 8px 이상.
2. **🧭 경험 통일**: 모든 화면이 같은 뼈대 — **위 = 어디인지**(뒤로 ‹ · 제목 · 지갑) / **가운데 = 내용**(스크롤은 여기만) / **아래 = 할 일**(주요 단추 1 + 보조 0~2). 같은 기능 = 어느 화면에서나 같은 자리 · 같은 아이콘 · 같은 색 · 같은 낱말(`docs/GLOSSARY.md`). 레이드 · 성채 · 게시판 던전 · 허수아비 · 체험판 · 테스트 모드 · 선생님 시연은 **같은 부품**(🪞).
3. **🫧 심플**: 한 화면 = 할 일 하나. 주요 단추는 한 화면에 **1개**. 나머지는 접거나(▾) 다음 화면으로. 글은 한 줄 · 15자 안쪽 권장 · 문장보다 낱말 + 아이콘. 같은 정보를 두 번 보여 주지 않음.
4. **👆 직관**: 누를 수 있는 것은 누를 수 있게 보임(채운 단추 · 그림자 · 눌림 표시), 못 누르는 것은 흐리게 + 왜 못 누르는지 한 줄. **지금 할 일**은 크게 · 은은한 반짝임 1개만. 아이콘엔 글자를 붙임(아이콘만 단추 금지 · 뒤로 ‹ · 닫기 ✕ 예외). 안내 창 · 튜토리얼 · 설명 문단에 기대지 않음 — 필요하면 그 자리에 빈 상태 그림 + 한 줄.
5. **✨ 세련**: 아래 2절 토큰만 씀(임의 색 · 임의 간격 금지). 도트 그림은 그림 칸(몬스터 · 용사 · 아이템)에만, 글 · 단추 · 칸은 매끈한 글꼴과 둥근 모서리. 움직임은 **0.2초 안쪽** · 들어올 때만(나갈 때 생략) · 화면 흔들림은 큰 사건(처치 · 승리)에만.

## 1-1. 시니어 키워드 (2026-11-12 선생님이 받아 온 「좋은 UI 키워드」 중 우리 원칙에 맞는 것만)
| 키워드 | 우리 규칙 |
|---|---|
| 시각적 계층 | 한 화면의 1순위 = 문제(또는 지금 할 일) · 2순위 = 체력 · 시간 · 지갑 · 3순위 = 보조 단추. 크기 · 명도 · 강조색을 이 순서로만 씀(2순위가 1순위보다 크거나 밝으면 ✗) |
| 명도 분리 | 바탕은 어둡고 채도 낮게 · 문제 카드 · 칩 · 단추 · 몬스터는 밝고 선명하게. **흑백으로 바꿔도** 바탕 · 카드 · 단추가 섞이지 않아야 함(5절 검사 11) |
| 여백 | 묶음 사이 16 이상 · 묶음 안 8 · **수식 · 원소 칩 주변은 12 이상**(수식이 뭉치면 읽기 피로가 급증) |
| 실루엣 가독성 | 탭 · 아이콘은 속을 지우고 그림자만 남겨도 0.5초 안에 구별되는 모양 · 같은 모양 아이콘 두 개 금지 |
| 어포던스 | 누르는 것 = 채운 면 + 아래쪽 **칼각 그림자**(blur 0 · `0 3px 0` 한 단 어두운 색) · 누르지 못하는 글 · 카드에는 그 그림자를 쓰지 않음 |
| 상태 피드백 | 모바일이라 마우스 올림은 없음 → **기본 · 누름(2px 내려가고 그림자 사라짐) · 비활성(흐림 + 이유 한 줄) · 선택됨(✓)** 네 상태를 모든 단추 · 칩 · 탭에 그림 |
| 주스 · 타격감 | 편의성 우선이라 **양을 정해 둠**: 누름 2px(늘) · 맞힘 = 체력 막대 하얀 번쩍임 0.1초(Hit Flash) · 화면 흔들림 = 처치 · 승리에만 · 진동은 큰 사건에만. 연출이 조작을 0.2초 넘게 막으면 ✗ |
| 히트박스 | 보이는 아이콘이 작아도 터치 영역은 48 × 48 이상(투명 여백으로) |
| 해상도 일관성(No Mixels) | **도트 그림끼리는** 정수 배율 하나(`image-rendering: pixelated` · 2배 또는 3배 중 화면마다 하나). 글 · 단추 · 카드는 일부러 매끈한 벡터(편의성 결정 2026-11-12) — 도트 그림 안에 벡터 장식을 섞지 않음 |
| 휴 시프팅 | 🎨 도트 그림 주문서에 늘 적음: 「그림자는 차가운 보라 · 파랑 쪽, 하이라이트는 따뜻한 노랑 · 주황 쪽 · 검정 · 흰색만 섞지 말 것」. 토큰의 어두운 단계도 순검정 대신 푸른 기 |
| 나인슬라이스 | 도트 테두리를 쓰는 칸(보스 결과 · 상자 같은 특별 장면)에만 `border-image` 9-slice · 일반 카드 · 단추는 둥근 벡터 |

## 6. 하지 말 것
