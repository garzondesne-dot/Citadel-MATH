## 집합 단원 기호

| 기호 | ① 쉬운 한 줄 | ② 읽는 법 · 교과서 정의 | ③ 기억 고리 · 주의 | 쪽 |
|---|---|---|---|---|
| a ∈ A | **a 는 A 팀 소속!** | 「a 는 집합 A 에 속한다」 · a 가 집합 A 의 원소일 때 | ∈ = 원소(element)의 e 를 바꾼 기호 · 왼쪽 = 원소, 오른쪽 = 집합 | 64 |
| b ∉ A | **b 는 A 팀 소속이 아니다** | 「b 는 집합 A 에 속하지 않는다」 · b 가 A 의 원소가 아닐 때 | — | 64 |
| {1, 2, 4, 8} | **원소를 하나하나 다 적기** (원소나열법) | 집합에 속하는 모든 원소를 { } 안에 나열 | 순서는 상관없음 · 같은 원소는 한 번만 | 64 |
| {x \| 조건} | **{ 누구 \| 어떤 애들 }** · 조건에 맞는 x 를 다 모은 것 (조건제시법) | 원소들이 갖는 공통된 성질을 조건으로 제시 · x = 원소를 대표하는 문자 | \| 는 「그중에서 이런 것」이라고 읽으면 쉬움 | 64 |
| n(A) | **A 안에 원소가 몇 개?** | 유한집합 A 의 원소의 개수 | n = 개수(number)의 첫 글자 · 예 n({1, 2, 4, 8}) = 4 | 65 |
| ∅ | **텅 빈 집합 (원소 0개)** | 원소가 하나도 없는 집합 = 공집합 | n(∅) = 0 · {0} 은 0 이 들어 있으니 공집합 아님 | 65 |
| A ⊂ B | **A 가 B 안에 쏙 들어간다** (A 의 원소는 모두 B 에도 있다) | A 의 모든 원소가 B 에 속할 때 A 는 B 의 부분집합 · 「A 는 B 에 포함된다」 | 자기 자신도 부분집합(A ⊂ A) · ∅ 은 모든 집합의 부분집합 · 원소 n 개 → 부분집합 2ⁿ 개 | 66 |
| A ⊄ B | **A 에 B 밖으로 삐져나온 원소가 있다** | A 가 B 의 부분집합이 아닐 때 | 하나만 삐져나와도 ⊄ | 66 |
| A = B | **원소가 똑같은 두 집합** | A ⊂ B 이고 B ⊂ A 일 때 서로 같다 | 순서가 달라도 같은 집합 | 67 |
| A ∩ B | **A 와 B 가 겹친 곳** (둘 다 있는 원소) | A 에도 속하고 B 에도 속하는 모든 원소로 이루어진 집합 = 교집합 | 「그리고」 · 모양이 아래로 열린 ∩ = 좁아진다 | 68 |
| A ∪ B | **A 와 B 를 합친 것** (겹친 건 한 번만) | A 에 속하거나 B 에 속하는 모든 원소로 이루어진 집합 = 합집합 | 「또는」 · 위로 열린 ∪ = 담는 그릇 | 68 |
| A ∩ B = ∅ | **A 와 B 는 하나도 안 겹친다** (서로소) | 공통인 원소가 하나도 없을 때 A 와 B 는 서로소 | 서로소면 n(A ∪ B) = n(A) + n(B) | 69 |
| n(A ∪ B) | **합친 개수 = 더하고, 겹친 만큼 한 번 빼기** | n(A ∪ B) = n(A) + n(B) − n(A ∩ B) | 겹친 곳을 두 번 세지 않게 | 69 |
| U | **지금 다루는 원소 전부** (전체집합) | 부분집합을 생각할 때 처음의 집합 | U = universal set 의 첫 글자 | 72 |
| Aᶜ | **U 안에서 A 밖에 있는 것 전부** (여집합) | U 의 원소 중 A 에 속하지 않는 모든 원소로 이루어진 집합 | C = complement 의 첫 글자 · Aᶜ = U − A · 「A 가 아니다」 | 72 |
| A − B | **A 에서 B 를 빼고 남은 것** (A 쪽만) | A 에 속하지만 B 에는 속하지 않는 모든 원소로 이루어진 집합 = A 에 대한 B 의 차집합 | A − B ≠ B − A · A − B = A ∩ Bᶜ | 73 |
