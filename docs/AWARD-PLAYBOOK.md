# 미래교육상 응모 플레이북 (2026-11-05 · 제11회 응모작 4편 학습)

> 사용자가 올린 **제11회 미래교육상(목정미래재단) 응모작 4편**을 분석해 공통 뼈대 · 잘 쓴 장치 · 심사자가 볼 약점을 정리했다.
> 원문 PDF 와 다른 학교의 자세한 자료는 저장소에 넣지 않는다 (남의 미공개 응모작). 여기에는 구조와 방법만 적는다.
> 목적: 「모두의 던전 : 공통수학2」로 응모할 때 바로 쓰는 틀.

## 2. 형식 (모두 같음)

- **A4 약 21~24쪽** = 요약서 1쪽 + (목차 1 · 표 목차 1) + 본문 약 20쪽(참고문헌 포함) · 부록(소감문 · 공문 · 사진)은 선택.
- **요약서 1쪽 = 2열 표**: 왼쪽 칸 이름 열(색 바탕) · 오른쪽 내용 — 칸은 **주제 / 서론 / 본론 / 결론**.
  - 주제: 1~2줄, 브랜드 로고(글자마다 색).
  - 서론: 5~11줄 — 문제(학생 말 인용 · 우리 학교 수치) → ⇨ 해결 방향.
  - 본론: 쪽의 절반 이상 — 연구 개요 표 · 연구 과제 3칸 표(과제 이름) · **결과 수치 한두 개**.
  - 결론: 첫째 · 둘째 · 셋째 + 제언. 굵은 마무리 한 문장.
  - 잘한 것: ③(표 + 개조식 + 수치 먼저), ④(명사구 + 표만). 아쉬운 것: ①②(글만 빽빽 · 그림 없음).
- 본문 밀도: 10pt 안팎 · 쪽마다 표 · 사진 · 색 상자 2~4개 · 여백 거의 없음.
- 번호 체계: **Ⅰ.**(색 띠) → **1**(번호 탭) → **가.** → • / - / ▶ / ✔ · 핵심 결론은 테두리 상자 + ⇨.
- 문장: 요약서 · 진단 · 결과는 개조식(~함 · ~음), 본문 서술은 ~하였다 · ~할 수 있었다.

## 4. 가져올 장치 (체크리스트)

- [ ] **브랜드 약어 하나** → 제목 · 장 제목(「『브랜드』를 시작하며」) · 머리말 · 배지 · 결론까지 반복 (4편 모두의 최대 강점)
- [ ] 단계 · 과제 이름을 **이어지는 말**로 (나는 특별해 → 너도 → 우리 학교는) 또는 **질문형 활동 제목**
- [ ] 목적 n개 ↔ 연구 과제 n개 ↔ 결론 n개 **1:1 대응**
- [ ] 이론 끝마다 「시사점 → 적용」 짝 표
- [ ] 교육과정 연계 표: 성취기준 코드 · 핵심역량 ◉(중점)/●(관련) · 과정중심평가 · 생활기록부 기재 예시
- [ ] 실천 쪽 고정 틀 · 사진은 캡션과 함께 · 학생 소감 · 교사 성찰 · **실패 기록**
- [ ] AI · 디지털은 **도구 + 비판 대상**으로 (기술만으로 미래교육이 아니다 — ③)
- [ ] 검증: 대응표본 t · p · 효과크기(Cohen's d) + 문항별 상승 + 사례 학생 + FGI
- [ ] 확산 장: 동료 교사 공유 · 연수 · 자료 공개 · 다른 학교급 적용 안내
- [ ] 마지막 점검: 요약서 ↔ 본문 수치 · 이름 · 그래프 ↔ 표 숫자 대조 · 오탈자 (4편 모두 실수함)

## 5. 「모두의 던전」에 맞추기 (초안 생각 · 사용자와 논의 전)

| 심사 포인트 | 우리가 이미 가진 것 | 더 모아야 할 것 |
|---|---|---|
| 필요성 (우리 학교 수치) | 특성화고 1학년 · 수학 흥미 낮음 · 기초 부족 | 학교 기초학력 진단 · 수학 포기 비율(설문) · 학생 말 인용 |
| 미래교육 (AI · 디지털) | 웹 앱 직접 개발 · 실시간 동기화 · 생성형 AI 로 제작(그림 · 영상 · 학습지) · 📷 서술형 사진 AI 채점(0.9.12) · 오개념 자동 진단 | AI 를 쓴 과정과 한계를 기록(교사의 AI 활용 윤리 · 학생 데이터 보호) |
| 실천 (같은 틀 반복) | 2~6차시 레이드 · 차시마다 학습지 ↔ 게임 칸 · 성취기준 연결(`lessons/curriculum.js`) | 차시마다 사진 · 학생 소감 · 교사 성찰 · 실패와 고친 점(예: 수업 너무 빡빡 → 차시 재조직 · 형성평가 세트 버그 → 4번 재도전) |
| 검증 (양적) | 게임 기록 = 행동 자료: 참여율 · **첫 시도 정답률 · 고침률** · 형성평가 문항별 · 오답노트 복습 완료 · 반별 · 차시별 추이 (자기보고가 아닌 실제 풀이 — 4편보다 강한 점) | **사전 · 사후 설문**(수학 흥미 · 학습동기 · 자기효능감, 기존 검사지) · t 검정 · 효과크기 |
| 검증 (질적) | 마지막 한마디 · 설문 기능(`survey`) | FGI(학생 · 동료 교사) · 사례 학생 추적 |
| 확산 | 공개 저장소 · 누구나 쓰는 웹 · 도구(`tools/`)로 다른 교사가 차시 추가 가능 | 동료 교사 적용 사례 · 연수 · 자료 공개 실적 |
| 브랜드 | 「모두의 던전」 · 레이드 · 성채 · 허수아비 | 약어 후보를 사용자와 정함 (예: D·U·N·G·E·O·N 단계 풀이는 무리 · 짧게 3~4글자) |

- 주의: 게임 기록은 **성적이 아니다**(DECISIONS) → 보고서에서도 「학습 참여 · 고침 행동 자료」로 쓴다. 학생 이름 · 반 · 개인 자료는 익명.
- 공모 요강(부문 · 분량 · 양식 · 심사 기준 · 마감)은 아직 없음 — 사용자에게 받는다.
