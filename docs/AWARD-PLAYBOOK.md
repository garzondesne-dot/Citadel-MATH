# 미래교육상 응모 플레이북 (2026-11-05 · 제11회 응모작 4편 학습)

> 사용자가 올린 **제11회 미래교육상(목정미래재단) 응모작 4편**을 분석해 공통 뼈대 · 잘 쓴 장치 · 심사자가 볼 약점을 정리했다.
> 원문 PDF 와 다른 학교의 자세한 자료는 저장소에 넣지 않는다 (남의 미공개 응모작). 여기에는 구조와 방법만 적는다.
> 목적: 「모두의 던전 : 공통수학2」로 응모할 때 바로 쓰는 틀.

## 2. 형식 (모두 같음)

- (제11회 응모작) A4 약 21~24쪽 = 요약서 1쪽 + (목차 1 · 표 목차 1) + 본문 약 20쪽.
- **⚠ 우리 응모(제13회 요강 · 미래교육연구) = 요약서 1쪽 + 본문 14쪽 이내 = 15쪽 이내 · 맑은 고딕 11pt · 행간 160% · 이름 · 학교 금지 · 영상은 링크** → 응모작 4편보다 짧으니 실천 장 틀을 줄이고 표로 압축.
- **요약서 1쪽 = 2열 표**: 왼쪽 칸 이름 열(색 바탕) · 오른쪽 내용 — 칸은 **주제 / 서론 / 본론 / 결론**.
  - 주제: 1~2줄, 브랜드 로고(글자마다 색).
  - 서론: 5~11줄 — 문제(학생 말 인용 · 우리 학교 수치) → ⇨ 해결 방향.
  - 본론: 쪽의 절반 이상 — 연구 개요 표 · 연구 과제 3칸 표(과제 이름) · **결과 수치 한두 개**.
  - 결론: 첫째 · 둘째 · 셋째 + 제언. 굵은 마무리 한 문장.
  - 잘한 것: ③(표 + 개조식 + 수치 먼저), ④(명사구 + 표만). 아쉬운 것: ①②(글만 빽빽 · 그림 없음).
- 본문 밀도: (11회 응모작) 10pt 안팎 → 우리는 11pt 고정 · 쪽마다 표 · 사진 · 색 상자 2~4개 · 여백 거의 없음.
- 번호 체계: **Ⅰ.**(색 띠) → **1**(번호 탭) → **가.** → • / - / ▶ / ✔ · 핵심 결론은 테두리 상자 + ⇨.
- 문장: 요약서 · 진단 · 결과는 개조식(~함 · ~음), 본문 서술은 ~하였다 · ~할 수 있었다.

## 4. 가져올 장치 (체크리스트)

- [ ] **브랜드 약어 하나** → 제목 · 장 제목(「『브랜드』를 시작하며」) · 머리말 · 배지 · 결론까지 반복 (4편 모두의 최대 강점)
- [ ] 단계 · 과제 이름을 **이어지는 말**로 (나는 특별해 → 너도 → 우리 학교는) 또는 **질문형 활동 제목**
- [ ] 목적 n개 ↔ 연구 과제 n개 ↔ 결론 n개 **1:1 대응**
- [ ] 이론 끝마다 「시사점 → 적용」 짝 표
- [ ] 교육과정 연계 표: 성취기준 코드 · 핵심역량 ◉(중점)/●(관련) · 과정중심평가 · 생활기록부 기재 예시
- [ ] 실천 쪽 고정 틀 · 사진은 캡션과 함께 · 학생 소감 · 교사 성찰 · **실패 기록**
- [ ] AI · 디지털은 **도구 + 비판 대상**으로 (기술만으로 미래교육이 아니다 — ③)
- [ ] 검증: 대응표본 t · p · 효과크기(Cohen's d) + 문항별 상승 + 사례 학생 + FGI
- [ ] 확산 장: 동료 교사 공유 · 연수 · 자료 공개 · 다른 학교급 적용 안내
- [ ] 마지막 점검: 요약서 ↔ 본문 수치 · 이름 · 그래프 ↔ 표 숫자 대조 · 오탈자 (4편 모두 실수함)

### 6-4. 엄격 규칙 (위원 모두 지킴 · 걸릴 때마다 해당 항목에서 깎음)

1. **숫자마다 n · 시기 · 출처**: 「61명 중」「11월 셋째 주」처럼 분모가 없으면 그 숫자는 근거로 치지 않는다(③ · ④).
2. **요약서 ↔ 본문 대조**: 숫자 · 차시 범위 · 반 수 · 이름이 하나라도 다르면 ⑦ −3 (11회 응모작 4편이 모두 걸린 곳).
3. **인과 표현 검사**: 「때문에」「효과가 있었다」「입증」은 비교 근거가 있을 때만. 회고 설문 · 단일 집단은 「~로 나타났다 · ~로 보인다」까지만 허용(④).
4. **회고 설문 한계**: 「중간고사 전」을 지금 돌아보며 답했다는 점과 그 영향(부풀 수 있음)이 결과 옆에 적혀 있어야 한다. 없으면 ③ −3.
5. **재미 ≠ 학습**: 흥미 · 참여 자료만 있고 이해 · 성취 자료(첫 시도 정답률 · 형성평가 · 오답 극복)가 없으면 B 위원은 ⑤를 반으로 깎는다.
6. **기술 = 수단**: 기술 설명이 교육적 까닭 없이 한 쪽을 넘으면 C 위원은 ①에서 깎는다. AI 를 어디에 썼는지 · 무엇은 사람이 했는지 적혀 있으면 가산.
7. **실패 기록**: 실패와 고친 점이 구체적(무엇이 · 몇 건 · 어떻게 고침)이면 ④ 가산. 성공만 있으면 오히려 신뢰를 깎는다.
8. **학생 보호**: 학생 말 인용은 익명 · 동의 언급 · 게임 기록이 성적이 아니라는 문장이 있어야 한다. 없으면 ⑥ −2.
9. **남은 자리**: [대기] · [출처 대기] · 메모 · ⚠ 가 하나라도 남으면 ⑦ 0점 + 「제출 불가」 표시.
10. **인용 정직성**: 본문에서 실제로 쓰지 않은 이론을 참고문헌에 늘어놓으면 ⑦ 감점. 이론 표의 「적용」 칸이 실제 규칙과 맞는지 하나씩 확인.

### 6-5. 심사 순서와 결과 양식

1. **10분 첫인상**: 요약서만 읽고 「한 문장으로 무슨 연구인가」를 적는다. 못 적으면 ① · ②에서 깎을 준비.
2. **정독 채점**: 6-3 표로 위원별 점수 + 깎은 까닭(쪽 · 문장 인용).
3. **반론 질문**: 위원마다 면접에서 물을 날카로운 질문 2개 = 8개(→ 면접 예상 질문으로 씀).
4. **결과 표**:

| 항목 | A | B | C | D | 평균 | 깎은 까닭 (쪽 · 문장) | 고치면 오를 점수 |
|---|---|---|---|---|---|---|---|

5. 마지막 줄: 총점 · 예상 등급(대상 / 최우수 / 우수 / 장려 / 입선 밖) · **고칠 것 상위 5개**(점수가 많이 오르는 순).
