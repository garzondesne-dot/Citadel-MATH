# 로드맵 — v0.9.4 → v1.0 → 그 뒤 (2026-11-02 작성)

**v1.0 = 「집합 단원 전체를 게임으로 한 학기 운영할 수 있는 판」**
집합 1~6차시(2~6차시 레이드) + 집합 중단원평가 던전 + 영상 · 학습지 · 설명서까지 갖추고, 회귀 시험으로 지킨다.

진행 방식: **버전 하나 = 새 대화방 하나** 를 권장 (긴 대화는 사용량이 커지고 요약 때 세부가 빠진다).
새 방에서는 「HANDOVER · ROADMAP 읽고 v0.9.x 진행」 이라고만 하면 된다. 제작 도구는 `tools/` (README 참고).
