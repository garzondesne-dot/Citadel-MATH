### 4-2. 규칙 (확정안 초안)

| 항목 | 내용 |
|---|---|
| 공명 | 용사는 **자기 속성 + 자기 큰 계열의 공통 특화** 두 가지와 공명한다 (이펙트 조금 크게 + 용사 빛 · 지금과 같은 효과). |
| ⚡ 필살기 | 자기 속성 = 지금 그대로 **Ⅲ 이상** + 퍼펙트 / 공통 특화 = **Ⅳ** + 퍼펙트 (선생님 예시대로 · 자기 속성이 한 단계 먼저 터져서 속성의 값이 남음). |
| 🌟 진필살기 | 지금 조건 그대로 (건드리지 않음). |
| 다른 큰 계열 것 | 근접 용사가 🔮 마법, 원거리 용사가 ⚔ 베기를 끼우면 지금처럼 쓸 수는 있지만 공명 없음. |
| 자기 속성 = 공통 특화인 용사 | 로안(⚔) · 누아(🔮)는 하나뿐 → 보상 없이 그대로 (「기본기의 검」 이야기와 맞음). |
| 결정석 | 지금처럼 한 번 열면 모든 용사에 끼울 수 있음 → **베기(또는 마법) 한 줄만 Ⅳ 까지 키우면 그 계열 어느 용사로 바꿔도 필살기**. |
| 고정 규칙 | 연출만 · 데미지 · 보상 · 시간 그대로. |

### 4-3. 기존 시스템과 부딪히는 점 · 좋아지는 점

- 👍 2절에서 속성이 바뀌는 옛 용사 가운데 **녹스(흑기사 · ⚔ → 🌑)** 는 베기가 공통이라 공명이 안 꺼진다. 발도르 · 바르코 · 볼트도 베기를 끼우면 공명.
- 👍 학생이 용사를 바꿔도 키운 결정석이 헛되지 않음 → 새 용사 10명을 여는 부담이 줄어듦.
- ⚠ 필살기가 지금보다 자주 나옴(종합실 컷인이 늘어남) — 지금도 컷인은 차례로 보여 주는지 손발 방 확인 필요.
- ⚠ 🏰 디펜스는 공명이 진짜 힘에 들어감 → 공통 특화 공명도 넣으면 디펜스 균형이 조금 달라짐(추천: 같이 넣고 지도 계수는 손발 방이 다시 맞춤).
- ⚠ 원거리 공통을 🔮 마법으로 하면 사제(✨ → ☀)는 옛 ✨ 결정석 공명이 꺼짐 · ✨ 별로 하면 사제는 지켜지지만 「기본 탄」 느낌은 약함.
- 3절 근접 스킬 1차(베기 Ⅲ · Ⅳ 다시 그리기)가 곧 근접 공통 필살기의 얼굴이 됨 → 1차의 값이 커짐.

## 5. 🌟 각성한 로안 = 금발 변신 (2026-11-11 선생님 확정 · DECISIONS)

| 항목 | 내용 |
