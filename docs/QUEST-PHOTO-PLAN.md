## 3. 원칙과 맞추기
- 정답: AI 두 번 풀이가 같을 때만 통과 · 다른 학생에게 나가는 🔵 · 🟣 는 **반드시 선생님 확인** (「게임 안 정답 = 검산」 원칙).
- 사진은 **저장하지 않음** · AI가 옮긴 글 · 식만 저장 (사진 채점과 같음).
- 교과서는 저장하지 않음 · 학생이 교과서 문제를 같이 찍는 2장 방식.
- 「🏛 명예의 전당」 = **학생 문제 전시관**(GLOSSARY 에 넣을 때 확정 · 옛 ROADMAP 의 「명예의 전당 = 공개 랭킹」 뜻은 쓰지 않음).
- 공개: 캐릭터 + 칭호 + 반 기본 · **이름은 학생이 직접 켤 때만** · 범위 = **학년 전체**.
- 그림 · 그래프 문제는 첫 판에선 몬스터화 안 함(🟣 안건으로만).
- AI 「독창」 = 후보일 뿐 · 결정은 선생님.
- 생기부 문장 초안(지금 공방 기능)을 사진 출제에도: 「교과서 ○쪽 문제를 바탕으로 조건을 바꿔 …」(활동 사실만).
