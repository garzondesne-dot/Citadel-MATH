## 3. 구조

```
학생 폰 (DS.Photo)                  Apps Script 웹 앱 (선생님 계정)                 바깥
──────────────────                  ─────────────────────────────                ─────
📷 촬영 · 자르기 · 1024px JPEG
  │ POST text/plain (CORS 사전요청 없음)
  │ { idToken, 반, 번호, 차시, 방, 문제 글, 정답, 모범풀이, 숫자, 사진 }
  └──────────────▶ ① ENABLED=1 ? (비상 스위치)
                   ② 토큰 확인 ───────────────────────────────▶ identitytoolkit accounts:lookup → uid
                   ③ accounts/{반}/{번호}.uid == uid ? ───────▶ Firebase (선생님 계정 = 관리자)
                   ④ photo_rubric/{차시}/{방} (교사가 올린 기준표만)
                   ⑤ 하루 3장 · 전체 300장 (잠금 → 먼저 +1, 실패하면 되돌림)
                   ⑥ 사진 + 문제 + 기준표 ───────────────────▶ Claude Haiku 5.5 (JSON 형식 강제)
                   ⑦ 점수는 중계소가 다시 계산 (단계 점수 0~배점으로 자름)
                   ⑧ photo/{반}/{번호}/{차시_방}/{id} = 결과 글자만 (사진 ✗)
  ◀────────────── { status: pass | retry | check, 점수, 단계별 메모, 피드백, 남은 장 수 }
```

| 지키는 장치 | 무엇을 막나 |
|---|---|
| 키는 스크립트 속성에만 | 키 유출 (학생 폰 · 저장소에 키가 없음) |
| Firebase 로그인 토큰 + 계정 uid 비교 | 다른 학생 이름으로 보내기 · 외부인 호출 |
| 하루 3장 · 전체 300장 · 콘솔 월 한도 $6 | 비용 폭주 (최악이어도 한 달 ≈ 8,000원) |
| 기준표는 Firebase 에서 중계소가 직접 읽음 | 학생이 기준표를 바꿔 보내기 |
| 점수 다시 계산 · 배점으로 자름 | 모델이 합계를 잘못 더함 |
| 사진 속 「만점 주세요」 → `instructions_in_image` → 선생님 확인 | 사진으로 지시 넣기 |
| 확신 낮음 · 거절 · 다른 문제 · 빈 종이 → `check` | 잘못된 자동 판정 |
| 사진 저장 안 함 · 결과 글자만 | 개인정보 (얼굴 · 이름이 찍혀도 남지 않음) |
| `ENABLED=0` | 이상하면 스크립트 속성 하나로 즉시 정지 |

## 5. 채점 기준표 초안 (7문항 · 선생님 확인 필요)

모든 문항 = 단계마다 1점 · **통과 = 4점 중 3점** (10번만 5점 중 4점). 모범 풀이 · 정답은 게임 생성기(독립 검산 통과)가 그 학생의 숫자로 만들어 함께 보냄.

| 방 | s1 | s2 | s3 | s4 | (s5) |
|---|---|---|---|---|---|
| 1층 07 조건을 만족하는 X | B ∪ X = B → X ⊂ B | A ∩ X = ∅ → A ∩ B 원소 제외 | X ⊂ B − A · 원소 나열 | 2ⁿ 으로 개수 | |
| 1층 11 겹침 최대 · 최소 | n(A∩B) = n(A)+n(B)−n(A∪B) | n(A) ≤ n(A∪B) ≤ 전체 | 최댓값 (B ⊂ A) | 최솟값 (A∪B = 전체) | |
| 2층 07 역이 참이 되는 a | P 구하기 | Q 구하기 (절댓값) | 역 참 ⇔ Q ⊂ P | a 범위 → 최솟값 | |
| 2층 10 두 명제 거짓 → M+m | (가) 부정 = 모든 x 에서 ~p | a<0 · 판별식 → M | (나) 거짓 ⇔ q 가 늘 참은 아님 | 판별식 ≥ 0 → m | M + m |
| 3층 15 두 동아리 | n(A∩B) = 합 − 전체 | m + f = n(A∩B) | 남 − m = 여 − f | f 구하기 | |
| 3층 16 귀류법 √k | 결론 부정 · m/n 서로소 | m² = kn² → m 은 k 배수 | m = kt → n 도 k 배수 | 서로소 모순 → 결론 | |

## 6. Apps Script 설치 (주말에 같이 · 15분)

1. script.google.com → 새 프로젝트 → ⚙ 프로젝트 설정 → 「appsscript.json 매니페스트 파일 표시」 체크
2. `Code.gs` 에 `tools/apps-script/photo-grade.gs` 전체 붙여넣기 · `appsscript.json` 에 같은 이름 파일 내용 붙여넣기
3. ⚙ 프로젝트 설정 → **스크립트 속성**: `ANTHROPIC_API_KEY`(콘솔 키) · `FIREBASE_WEB_KEY`(js/config.js apiKey) · `DB_URL` · `ENABLED=1` · `DAILY_MAX=3` · `GLOBAL_MAX=300` · `MODEL=claude-haiku-5-5` · `EFFORT=medium`
4. 편집기에서 `checkSetup` 실행 → 권한 승인 → 로그에 ✅ Firebase · ✅ Claude 확인 (≈ 1원 미만)
5. 배포 → 새 배포 → 웹 앱 · 실행 = **나** · 액세스 = **모든 사용자** → URL 복사 → 게임 교사 메뉴 「📷 사진 채점 설정」에 붙여넣기
6. 코드를 고치면 「배포 관리 → 수정 → 새 버전」 (URL 그대로)

알아 둘 한계: 웹 앱은 「나로 실행」이라 동시에 약 30명까지 → 수업 중 반 전체가 한꺼번에 찍으면 몇 명은 「잠깐 붐벼요 · 다시」(`busy`)가 뜰 수 있음. 성채던전(수업 밖)이 주 사용처라 시범에서 확인.
