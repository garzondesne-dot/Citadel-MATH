# 결정 목록

새 아이디어는 이 목록과 먼저 대조한다. 기존 결정과 부딪히면 반영하기 전에 알린다.
진행 방식: **논의 → 확정안 → "진행"이라고 하면 구현.**

## ✅ 확정
| 결정 | 이유 |
|---|---|
| DIMENSION SLASHER 번외편 엔진을 복사해 시작 | 사용자: "여기서 개발하던 내용에서 조금 비튼 컨셉". 저장 키는 `citadel-math-*` 로 분리 |

## ❓ 미결 질문 (컨셉)
1. 무엇을 비트나? (수학 단원 / 핵심 메커니즘 / 이야기·장르 "Citadel(성채)")
2. 대상·시간·기기 (학년, 수업 분량, 폰·태블릿·PC)
3. 엔진에서 유지할 것 / 버릴 것
4. 마감(수업 날짜)
5. 실시간 현황: DIMENSION SLASHER 와 같은 시트를 쓸지, 새 시트를 만들지
