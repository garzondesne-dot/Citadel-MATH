# 결정 목록 (Citadel-MATH)

새 아이디어는 이 목록과 먼저 대조한다. 기존 결정과 부딪히면 반영하기 전에 알린다.
진행 방식: **논의 → 확정안 → "진행"이라고 하면 구현.**
엔진(DIMENSION SLASHER)의 결정은 `docs/origin/DS-DECISIONS.md` 에 있고, 따로 바꾸지 않는 한 그대로 따른다.

## ✅ 확정
| 결정 | 이유 |
|---|---|
| 게임 기본 형태 = **citadel 교실 레이드**, 엔진 = **DIMENSION SLASHER** | 사용자 지정 ("두 개 짬뽕") |
| citadel 저장소 코드는 **참고만** (복사·수정·푸시 안 함) | 운영 중인 주소·기록 보존 |
| 서버 = **Firebase Realtime Database** (Apps Script 아님) + 이 기기 체험 모드 | Apps Script 는 반응이 너무 느림 |
| 그래픽 에셋을 코드와 분리 (`assets/` + 배치표 `assets/manifest.js`) | 나중에 나만의 에셋으로 갈아 끼우기 |
| 내용은 **집합 3차시 「집합 사이의 포함 관계」** 학습지 부분만. 차시는 하나씩 추가할 수 있게 | 사용자 지정, 기한 없이 차분히 |
| **카드는 수업 밖 "대장간"(번외 특전)에서만** — 모루 연성(엄격 연성 + 처음 만든 카드는 예제를 맞혀야 완성). 수업 중엔 카드를 받지도 쓰지도 않는다 | 사용자 확정 (2026-10-31, "연성 필수"에서 변경) |
| 전투 = **답 제출만**. 카드 고르기 없음 — **카드로 공격하는 개념 삭제** | 사용자 확정 (2026-10-31) |
| 카드의 쓰임 = 공격 이펙트·외형 꾸미기 **특전**만 | 사용자 확정 (2026-10-31) |
| 보스(형성평가) = 폰 입력 자동 채점. 사진·Gemini 채점은 나중에 | 사용자 확정 (추천안) |
| 첫 결과물 = 가상 학생 체험판(`demo.html`) | 사용자 확정 |
| 대상 기기: 학생·교사 = 스마트폰, 종합상황실 = 교실 PC | 사용자 확정 |
| **스탠드얼론 PWA** (0.1.1): 홈 화면 설치 · 코드는 인터넷 먼저 · 그림은 캐시 먼저 | 사용자 확정 (v0.1 에서 빠졌던 것을 되살림) |

## 👤 계정 (논의 중 — "진행" 전)
| 결정 | 상태 |
|---|---|
| 온라인 게임처럼 **가입 → 로그인**. 데이터는 Firebase 에 저장 | 사용자 확정 |
| 아이디 = **반 + 번호** 선택. 이름은 교사가 미리 올린 **명단에서 자동 표시** (학생이 이름을 직접 입력하지 않음 — 장난 방지) | 사용자 확정 |
| 같은 반·번호 **중복 가입 막음** | 사용자 확정 |
| 비밀번호 = **숫자 4자리**. 잊으면 교사가 **0000 으로 초기화** | 사용자 확정 |
| 학생 명단(이름)은 저장소에 넣지 않는다 — Firebase 에만, 교사 화면에서 올린다 | 규칙 (개인정보) |

## 🛠 대장간 (모루 · 번외 특전, 논의 중 — "진행" 전)
| 결정 | 상태 |
|---|---|
| 연성법 = **집합 단원 연성법 초안** (2026-10-31, 카드 31장): 원리 유도가 아니라 **기호를 써 보고 외우는** 연성, **모든 카드는 연산을 최소 한 번** | 초안 (사용자 검토 중) |
| 선반 = 집합 단원 재료·연산 **전부** (명제는 넣지 않음) | 사용자 확정 |
| 정식으로 남는 카드 = **배운 차시까지**. 그 뒤 차시 카드도 연성은 되지만 "지금은 사용할 수 없어요" 안내 후 삭제 | 사용자 확정 |
| 퀴즈처럼: 힌트는 **감춰진 레시피 밑 힌트 한 줄이 전부** (조합법 목록·단계 힌트 없음) | 사용자 확정 |
| 처음 만드는 카드: 공식 완성 → 마력(예제) → 망치 → 카드. 망치 = **도장 찍듯 위에서 쾅** + 번쩍 | 사용자 확정 |
| 모루 = 위에서 내려다본 모양, 홈 3개 (한 칸 연산은 가운데 + 오른쪽 홈) | 사용자 확정 |
| 카드 이름 = 교과서 용어 그대로 | 사용자 확정 |
| 교사 화면 = 학생별 **도감 수만** (예: 32/45, 분모 = 배운 차시까지 카드 수) | 사용자 확정 |
| 레시피는 차시 파일이 아니라 **단원 공통 파일**(예: `lessons/unit-set.js`) | 사용자 확정 |
| 한 칸짜리 연산(ᶜ · n( ) 등) 판정을 엔진에 추가 | 합의 |
| 교사 폰 단순화 시안의 미결정 4개 | 사용자가 전체 수정 후 결정 |

## 🗑 폐기 (2026-10-31 변경으로 없어진 것)
| 폐기 | 대신 |
|---|---|
| 소환 조건 "모두 맞는 카드가 있어야" · 전투의 "맞는 카드 고르기" · 정답 = 카드 + 답 | 교사 진행으로 소환, 정답 = 답만 |

| 다음 후보 "전투 중 개인 카드 턴" | 카드로 공격하지 않음 |

| 개인정보 | 개인 정답·오답은 종합상황실 큰 화면에 띄우지 않는다 (교사 폰·본인 폰에만) |
| 참여 | 교사가 수업 시작 때 참여 명단 확정. 결석·기기 문제는 교사 폰에서 참여 끄기 |
