| 재도전: **2번까지**. 틀린 소문제를 표시해 주고 **소문제 전부 새 숫자로** 다시. 데미지는 **늘어난 만큼만** (학생마다 최대 = 소문제 수) | 사용자 확정 |

| 필드 판정: 체력이 0이어도 **전원이 한 번 이상 제출**해야 판정 (상호작용 안 한 용사가 없게). 못 넘으면 교사가 기준%를 낮춰 해결 | 사용자 확정 |

| 성공하면 [모루에서 연성하기] 활성화. 모루는 **던전 대기실 · 모닥불에서만** 사용 (그 밖의 수업 중엔 금지). 모루에서 나오는 것은 카드 | 사용자 확정 |
| 마무리: 교사 [수업 마무리] → 학생 폰에 오늘 수업 피드백 한마디 → 종합상황실 캐릭터 머리 위 말풍선. **욕설 필터** + 교사 버튼: 말풍선 일시 숨김 / 그 학생 피드백 계속 잠금(다음 차시에도) | 사용자 확정 |
| 종료: 접속 차단 → 모닥불로 돌아감. 던전 입구는 꺼지고, 모닥불 옆 모루 → 연성창 | 사용자 확정 |
