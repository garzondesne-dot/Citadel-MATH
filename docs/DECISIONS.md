# 결정 목록 (Citadel-MATH 협동 수업 도구)

새 아이디어는 이 목록과 먼저 대조한다. 부딪히면 반영 전에 알린다.
`docs/origin/` 의 이전 결정(DIMENSION SLASHER)은 **참고안**이며 여기 적힌 것만 이 프로젝트의 결정이다.

## ✅ 확정
| 결정 | 이유 |
|---|---|
| 새 목표: 집합·포함 관계 **협동 수업 도구** (학생 폰 · 교사 제어 · PC 공개 화면) | 사용자 새 지침 (2026-10-31) |
| 저장소: `Citadel-MATH` 재사용, 이전 복사본 코드는 삭제 | 사용자 선택 |
| 배포·서버: **Cloudflare Pages + Functions + D1** (무료) | 사용자 선택. 비공개 저장소 자동 배포, 비밀값을 저장소 밖에 둠 |
| 기존 저장소·Apps Script·시트와 연결하지 않음 | 사용자 지침 |
| 개발 순서: 흐름 확정 → 최소 배포 → 자동 반영 검증 → 수업 생성·입장·제출·공개 반영 → 핵심 기능 → 디자인·에셋 → 사진 채점·PWA | 사용자 지침 (이전 시행착오) |

## 💡 참고할 아이디어 (선택적으로 재설계, 필수 아님)
- 학생·교사·공개 화면 역할 구분
- 카드 획득과 수학 개념 학습 연결
- 학생 참여를 모아 실행하는 협동 공격
- 오답 후 설명·재도전
- 공개 화면에 학생별 오답·도움 요청 비노출
- 수식 가독성, 모바일 조작 편의

## ❓ 미결 질문 (1단계: 핵심 흐름·첫 구현 범위)
1. 한 차시 수업 흐름 (몇 분, 몇 문제, 어떤 순서)
2. 학생 입장 방식 (수업 코드 + 이름/번호? 반 명단?)
3. 응답 형식 (객관식 · 기호 넣기 · 숫자 · O/X …) 과 협동 공격의 규칙
4. 교사 제어 범위 (다음 문제, 잠금, 정답 공개, 초기화)
5. 공개 화면에 무엇을 보여 줄지 (전체 진행률, 보스 체력 등)
6. 첫 실제 수업 날짜
