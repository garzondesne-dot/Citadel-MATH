## 1. 구조 (설계안에 맞춘 판)

### 1-1 시계 · 동기화 (첫 메모 그대로 유효)
- 모든 시각 = 서버 시각(`S.now()` · `clock.svelte.ts serverNow`) · 게이지 값은 방에 계속 쓰지 않음 → `{ t0, spd }` 만 쓰고 각 폰이 계산.
- **작전 시간**(파티당 1번 · 25초) = 지금 `state/bp` + `meta/board/paused` 길 재사용 → 아군 ATB · 예고 중 보스 공격이 같이 멈춤(설계안 4절 「남은 시간 보존」과 같은 뜻). 이미 발동한 공격은 처리 뒤 멈춤 = 진행 폰이 발동 처리 끝난 뒤 `bp` 를 씀.
- 감속(약 3초) · 행동 불능(약 2초) = 그 용사 `spd` 칸에 `{ until, x }` 덧칸 → 계산식에 구간 곱.

### 1-2 누가 무엇을 쓰나 (중복 · 동시 입력 막기)
| 칸 | 쓰는 쪽 | 이유 |
|---|---|---|
| 보스 HP · 실드 칸 · 예고 · 보스 ATB · 용사 HP · 상태이상 | **진행 폰 하나**(지금 `bdrv` 맡기 그대로) | 한 곳에서만 계산 = 동시 피해 · 부활 두 번 막음 |
| 내 행동(타이밍 결과 · 스킬 사용 · 대상) | **나만** · 번호 붙은 줄(`act/{pid}/{n}`) | 진행 폰이 번호 순서로 한 번만 적용 · 재접속 때 다시 보내도 같은 번호 = 한 번 |
| 내 충전 · 풀이 진행 · 오답 수 | **나만** | 문제 꼴은 학생마다 다른 변형 |
| 묻기 · 힌트 · 작전 시간 | 지금 `help` · `bh` · `bp` 칸 | 이미 규칙 있음 |

### 1-3 화면 (가로)
- 전투만 가로(모집 · 대기실 · 결과 · 지도는 세로 그대로) · 왼쪽 용사 1줄(원근 · 전위/중위/후위) · 오른쪽 보스 · 명령 = 공격 · 스킬 · 스킬 충전.
- 문제창 = **오른쪽 영역 위아래 끝까지** 덮음 · 왼쪽 용사 HP/ATB · 보스 예고는 보임 · 지금 `QItem` · `MonsterForm`/`ChainView` 를 그 칸 안에 그대로(📈 🏹 함수 꼴도 자동으로 들어옴).
- 보스 공격은 문제 본문 · 보기 · 입력 · 저장 충전을 건드리지 않음 → 레이드의 글자 흔들기(glitch 등) 연출은 게시판 문제창에 **끄고** 용사 쪽에만.

## 2. 새로 만들 덩어리 (1차 / 2차는 3절)
① **문항 공급기**: 차시 팩 → 원문항 목록 · 학생마다 변형 · 소문항 묶음 = 충전 1회 · 4번째 확정 오답 → 같은 원문항 새 변형 · 퍼펙트 판정(그 충전 시작 뒤 오답 0) · 7차시 = 6차시 미풀이 · 오답 원문항 먼저.
② **전투 규칙(순수 함수)**: ATB · 타이밍 바 판정 · 피해식(성장 배율 · 배치 · 실드 중 감소 · 파괴 뒤 증가) · 실드 칸(인원 × 난이도 표) · 담당자 배정(속성 최대 2 · 혼합 파티 = 각 쪽 1명) · 보스 행동표(유형 4 · 예고 · 간격) · 승패(HP 1 에서 멈춤).
③ **역할 스킬 4종**: 강타 · 엄호 · 광역 회복 · 격려 + 응급 지원(회복 / 부활 용사당 1회).
④ **전투 화면(가로)** · 타이밍 바 · 실드 칸 금 · 파괴 연출 · 결과창(개인별 실드 · 엄호 · 회복 · ATB 지원 · 결정타).
⑤ **모집 확장**: 용사 고르기(해금한 용사) · 배치 · 난이도 · 빈자리 초대 · 올드윈(교사) 자리.
⑥ **보상 · 별 · 랭킹 새 식**(7절) + 기존 기록 옮기기 범위.
⑦ **교사 연습방**: 올드윈 + 봇 3 / 봇 4 관전 · 봇 4종 · 시작 지점 4개 · 고정 씨앗(변형 · 봇 · 보스 패턴) · 결과(승패 · 사람당 원문항 · 마지막 실드 시각 · 남은 HP).
⑧ **재접속**: 유예 · 계속하기 / 재시작 · 남은 실드 재배정.

## 4. 구현 전에 정해야 할 것

### 4-1 설계안 8절 「테스트로 정함」 (손발이 정하지 않음 · 연습방으로 재서 선생님께)
ATB 속도 · 타이밍 바 성공 · 치명 구간과 실패 처리 · 실드 등장 HP · 실드 중 피해율 · 브레이크 시간 · 피해 증가율 · 역할 · 배치 보너스 · 응급 지원 비용 · 부활 HP · 재접속 유예 · 이어가기 HP 처리 · 보스별 기준 HP · 대표 공격 위력 · 예고 · 간격 · 「연습에서 두 번째 충전 쓸 시간」 · 「도전에서 4~7문제」 · 「1~3인 도전 가능」.
→ 1차는 **숫자를 한 파일(`src/board/atb-tune.ts` 가칭)** 에 모아 연습방에서 바꿔 가며 재기.

### 4-2 설계안에 답이 없거나 겹치는 것 (❓ 머리 · 선생님)
1. 수호자 힌트 횟수 · 조건(지금 「먼저 다 맞힘 · 문제당 1번」 유지?) · 1인 길잡이 남김?
2. 🤝 구조 보상(+5 / +3) · 「완전 구조」를 없애나, 새 보상과 같이 두나
3. 옛 ⭐(등급 기준) 기록 → 새 ⭐ 로 옮김? 옛 학기 랭킹 · 명성 · 칭호 3개 · S~C 등급은?
4. 1인 판 = 서버 방 or 이 폰 메모리 방
5. 「핵심 원문항」 = 차시 팩의 어떤 칸? (지금 팩엔 원문항 구분 칸 없음 · 몬스터 = 원문항으로 볼지)
6. 「원문항 7 × 7 변형」 = 지금 팩 버전 0~6 과 같은 뜻인지 (같다면 팩 꼴 그대로 됨)
7. 빈자리 초대 = 같은 반만? 다른 반도(지금 게시판은 다른 반 합류 됨)? 진도 안 나간 친구 초대는 막나
8. TV 표시 여부 (설계안 8절도 미정)
9. 교사 연습방 결과 기록 자리(학생 기록과 분리 · 어디에 남길지)
10. 독립 차시팩 9개 = 손발 #7 몫인지 (1 · 7차시는 팩 없음)

| `rooms/$code/state/*` (보스 · 용사 HP · 실드) | 진행 폰 | **지금 T 방 = 누구나 씀 → 변경 없음** (다만 학생 아무나 HP 를 바꿀 수 있음 = 지금과 같은 수준 · 좁힐지 ❓) | |

| `school/board/posts/$pid/mem/$uid` | 지금 그대로 + 초대받은 학생은 PIN 없이 | `boardLock` 비교 조건에 「`invite/$uid/$pid` 있음」 OR 추가 | 초대 수락 = PIN 생략 |
| `school/board/posts/$pid/{diff,pick}` | 방장 · 각자 | 지금 글 아래 칸은 `mem` 외엔 「없을 때만」 → 칸 추가 | 난이도 · 용사 · 배치 |
| `school/board/wk/$week/$cls/$pid` | 본인만 | `rk2` 와 같은 꼴 | 주간 협력 랭킹(친구 수) |
| `bonus/.../board/pair/...` | 본인만 | 지금 bonus 규칙 | 첫 협력 조합 1번 |
| 교사 연습방 | 교사(admins) | 방 코드 머리글자 따로(예: `P…`) · 기록 · 보상 · 랭킹 칸엔 안 씀 | 학생 기록과 분리 |

→ 1차에 꼭 필요한 것 = `act` · `chg` 두 줄 + 초대(1차에 넣는다면). 운영 서버 게시는 선생님 콘솔 · 머리 경유.
