# ⚔ 게시판 던전 ATB — 1차 구현 (교사 연습방 · 2026-11-20 · 손발 #2)

> 순서(결정 #11): 엔진 → **교사 연습방(여기까지)** → 선생님이 3판 해 보고 OK → 학생 판(모집 · 서버 방 · 보상) → 옛 판과 1주 나란히 → 옛 판 내림

## 여는 곳
- 교사 폰 「📦 차시 팩」 탭 → **⚔ 게시판 던전 연습방 (새 판 · ATB)** · 또는 주소 `?role=atb`
- 이 폰에서만 돎(서버 0 · 💎 0) · 결과 = 이 폰 최근 5판

## 파일
| 자리 | 내용 |

| `src/ui/board/atb/*` | 화면: 전투 무대 · 문제 카드 · 타이밍 바 · 모았다 놓기 고리 · 컷인 · 결과 · 용사 고르기 · 연습방 |

## 시안에서 고친 7개 (결정 11)
① 실드 칸 = 파티 인원수만큼 · 그 용사 계열 문양 ② 금색 ⚡ = 테두리 반짝 ③ 방어 「0%」 · 딜러 ATB 8.0초 ④ 딜러 아이콘 = 임시 과녁(바꿔 끼우기 쉬움) ⑤ 원근 100 → 70% · 내 용사 맨 아래 가장 크게 · 발은 모두 바닥(화면 45% 아래 · e2e 검사) ⑥ 고르는 창 = 실제 용사 초상 ⑦ GPT 글자 실수 무시

## 아직 비워 둔 것 (설계 방 → tune.ts)
- 1 · 2인 숫자(지금 출발값 · 모의: 2인 승률 30% · 1인 15% = 설계 방 경고와 같음)
- 역할 스킬 넣은 모의실험 값(힐 25 · 엄호 50% 등 = 초안 값)
- 3 · 4 · 6 · 8 · 9 · 10차시 공격 묶음(지금 = 기본 공격 · 그림 · 약점만 · 연습방 차시 칩에 「·초안」)
- 부활 HP 30% · 타이밍 바 · 모았다 놓기 구간 = 「테스트로 정함」 값
