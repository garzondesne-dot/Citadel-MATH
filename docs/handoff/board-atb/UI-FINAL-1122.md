## 2. 문제 카드 열림 (55 : 45)
- 「문제 풀이」를 누르면 카드가 **아래에서 0.3초 올라오며** 전투가 왼쪽 55% 로 밀림(DECISIONS 11/21 「55 : 45 · 최소 360px」).
- 왼쪽 칸: 보스 = 오른쪽 위 작게(약 104px) · 용사 = 왼쪽 아래 **지그재그 2 × 2**(x 10 · 31 · 14 · 35% · 높이 190 · 162 · 90 · 62) · 아래 = 「⚔ 공격 · 자동 중」(흐림 · 누르지 않아도 됨) · 「스킬」 · 번개 구슬 줄.
- 카드: 맨 위 손잡이 · 「문제 n · 제목」 + 소문항 점(✔ · 지금 · 남음) · 문제 · 보기 2 × 2.
- **제출 단추 없음**: 보기 = 0.5초 꾹 → 금빛이 왼쪽부터 차오르고 다 차면 제출(짧게 = 고르기만) · 숫자 · 식 = 룬 키패드 「⏎」 0.5초 꾹 · **여러 개 고르는 문제(원소 칩 · 짝 맞추기 · 순서 · 그래프)** = 카드 아래 「⏎ 꾹」 띠 단추(같은 0.5초 · 금빛).
- 접기 = 손잡이 끌기 · 전투 칸 빈 곳 · 충전 4칸 가득. 열기 = 충전 0 이 되는 순간.

## 4. 연출
- **눈빛 컷인 = 스킬 2 · 각성만**(0.9초): 하얀 번쩍 0.18초 → 어두워짐 → 비스듬한(−7°) 금빛 띠가 튕겨 들어옴 + 속도선 + 빛 줄기 → 용사 크게 → 큰 기울임 금빛 글자 「스킬 이름!」 + 작은 줄(용사 · 단계) → 불꽃 조각. 각성은 띠 색 · 크기 한 단계 더.
- 역할 스킬(컷인 없음): 엄호 = 탱커가 잔상을 남기며 표적 앞으로 → 방패 금빛 막기 호 + 부딪힘 불꽃 → 「🛡 막았다! ○○ 대신」 → 제자리 · 강타 = 보스 앞 돌진 → 큰 한 방 + 살짝 흔들림 · 힐 · 응급붕대 = 대상 위 초록 빛기둥 + 「+회복량」(자동 대상 = 체력 비율 가장 낮은 살아 있는 용사) · 격려 = 음표 · 빛이 날아가 대상 ATB 확 차오름 「+30%」.
- 홀리 방패 = 파티 4명을 모두 덮는 금빛 반구(있는 그림 `board-atb/fx/rage-barrier.webp` 6칸 · 은은히 반복) + 발동한 용사 위 금빛 방패(`aura-guardshield-v1.webp` 12칸 · **한 번만**) + 위 띠 + 보스 회색 · 「🗿 6초」.
- 실드 칸 = 있는 그림 `board-atb/atb-shield-slots-v1.webp`(5속성 × 온전 · 금 감 · 산산조각) · 깨질 때 금 감 → 조각 → 사라짐.
