# ⚔ 기사단 토벌 주간 — 게시판 던전 반 대항전 v1 (2026-11-21 · 메타인지 8 · 선생님 확정)

## 이야기
- 왕국 변두리에 「균열」이 열리고 학습지 속 몬스터가 쏟아져 나온다. 왕은 학년의 반마다 **기사단**을 세웠다.
- 반 = 기사단 하나. 이름 · 문장은 반이 고름(처음 값: 1-1 붉은 사자단 · 1-2 푸른 매단 · 1-3 황금 곰단 · 1-4 은빛 늑대단 · 1-5 초록 사슴단 · 교사 = 왕실 근위대 · 1-6 테스트 반 = 순위에서 뺌).
- 게시판 던전 = 균열 토벌 의뢰. 다른 반 친구와도 **연합 원정대**로 함께 갈 수 있고, 공적은 각자 **자기 기사단 깃발**에 쌓인다.
- 매주 월요일 0시 「토벌 주간」 시작 → 일요일 23:59 마감 → 공적이 가장 많은 기사단이 **왕의 깃발**을 차지(한 주 동안 종합실 TV · 모든 학생 캠프 · 게시판 맨 위에 깃발).

## 공적(포인트) — 한 판 끝날 때 각자 계산 · 자기 반에 더함
| 행동 | 공적 |
|---|---|
| 클리어(보스 처치) | +10 |
| 별 1개 | +5 (최대 +15) |
| 한 번에 맞힌 소문항 | +1 |
| 막기 · 구조 · 끊기 · 속성 브레이크 | 1번 +2 |
| 역할 임무 완수 | +5 |
반 점수 = 반 학생 공적의 **합 그대로**(선생님 고름). 🧪 테스트 · 연습방 = 공적 없음. 1-6 = 순위 밖.

## 판당 💎
맞힌 소문항 ×3(최대 30) · 클리어 +10 · 수호 보너스 1번 +2(최대 +10) ≈ 판당 40~60 · **하루 게시판 💎 한도 200**.

## 화면
- 게시판 맨 위 = 「⚔ 토벌 주간 · 남은 n일」 + 5개 기사단 깃발 막대(공적) · 우리 반 강조 · 지난주 왕의 깃발.
- 판 결과 = 「🚩 우리 기사단 +n 공적」 줄(내 공적 세부 펼치기).
- 종합실 대기 화면 · 학생 캠프 = 왕의 깃발 기사단 표시 · 우리 반 순위.
- 교사 = 반 이름 · 문장 바꾸기 · 주간 보상 켜기/끄기(베타 = 💎 지급 끔 · 정식 배포 때 켬).

## ⭐ 골고루 돌기 (2026-11-21 · 선생님 「이 컨텐츠에서 별이 쌓이는데 이거 중요하거든. 애들이 자기가 편한 차시만 계속 돌아서 마정석을 확보하려고 하면 안 돼 · 골고루 돌아야지 · 별이 그 역할이야」 → 고름)
- 차시 정복 지도의 ⭐(차시별 최고 별 · 별 규칙 그대로)가 보상의 열쇠.
- 그 차시 ⭐3 을 다 모으면 = 그 차시 판당 💎 절반 · 공적 절반 · 지도 칸에 「다 모음 → 다른 차시로!」.
- 반 대항전 「별 1개 +5」 = **처음 얻는 별만**(이미 가진 별 = 0) · 처음 얻는 별 1개마다 💎 +20.
- 판 결과에 「⭐ 새 별 +n · 공적 +n」 / 「이 차시는 다 모았어요 · 보상 절반」 한 줄.
