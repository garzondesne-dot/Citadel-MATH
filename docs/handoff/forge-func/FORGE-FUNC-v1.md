## 5. 실수 안내 (틀린 조합을 올렸을 때)

| 올린 것 | 안내 |
|---|---|
| Y 〔→〕 X | 함수는 정의역이 왼쪽이에요: X → Y (X 의 원소마다 Y 의 원소가 하나씩) |
| x 〔( )에 넣기〕 f | 순서가 거꾸로예요. 함수가 왼쪽, 넣는 값이 오른쪽: f(x) |
| f 〔( )에 넣기〕 y | f 에 넣는 것은 정의역의 원소 x 예요. y 는 나오는 값! |
| f 〔( )에 넣기〕 [함숫값] | f(f(x)) 도 합성이지만, 이번 카드는 g 에 f(x) 를 넣어요: g(f(x)) |
| [함숫값] 〔( )에 넣기〕 g | 순서가 거꾸로예요. 나중 함수 g 가 왼쪽: g(f(x)) |
| [합성함수] 〔=〕 [순서를 바꾼 합성함수] | g∘f 와 f∘g 는 보통 같지 않아요. ≠ 로 놓아 보자 (교환법칙 ✕) |
| [합성함수] 〔≠〕 [합성함수] | 같은 카드 두 장은 서로 같아요. f∘g 카드를 따로 만들어 견주자 |
| ⁻¹ ← f | 역함수는 f 가 일대일대응일 때만 있어요. 일대일대응 카드에 ⁻¹ 을 붙여 보자 |
| ⁻¹ ← [일대일함수] | 일대일함수만으로는 모자라요. 치역 = 공역 까지 갖춘 일대일대응이어야 역함수가 있어요 |
| ⁻¹ ← [함수] | 모든 함수에 역함수가 있는 것은 아니에요. 일대일대응일 때만! |
| [역함수] 〔( )에 넣기〕 x | 역함수 f⁻¹ 는 Y 에서 X 로 가요. 넣는 것은 y ! |
| [치역] 〔=〕 [정의역] | 치역은 공역과 견줘요 (둘 다 Y 쪽). 정의역은 X 쪽! |
| x 〔=〕 [함숫값] | 함숫값을 왼쪽에: f(x) = x |
| c 〔=〕 [함숫값] | 함숫값을 왼쪽에: f(x) = c |
| 치역 ← [함숫값] | 치역은 함수 카드(f : X → Y)에서 구해요 |
| x ↔ y ← [함수] | x ↔ y 는 식 y = f(x) 나 그래프에 써요 |
| [합성함수] 〔∘〕 h | 이번 카드는 h 를 왼쪽에: h∘(g∘f) |

| f(x) | `(?<![∘⁻¹A-Za-z가-힣)])[fgh]\((?=[^)]*\))` | 함숫값 | x 를 넣었을 때 나오는 값 |

- 찾는 순서 = 표 위에서부터(긴 낱말 먼저: 일대일대응 → 일대일함수 · 합성함수 · 역함수 · 항등함수 · 상수함수 → 정의역 …) · 「f(x)」는 (g∘f)(x) 나 f⁻¹(x) 의 일부가 아닐 때만.
- 「함수」 한 낱말은 줄로 안 만듦(거의 모든 문제 글에 나와 화면이 온통 밑줄이 됨) — 「f : X → Y」 꼴만.

## 8. 선생님이 정한 것 (2026-11-21)

1. **역함수 사슬 = 그대로**(일대일대응 → 역함수) + **지름길 안내**: 재료 카드가 없으면 「먼저 만들 카드: ○○」를 눌러 바로 그 카드로 가게 한다(손발: 모루 화면에 더할 것).
2. **f∘g 카드를 따로 만든다**(compose2) → 「교환법칙 ✕」 = g∘f 카드 ≠ f∘g 카드. 카드 23장.
3. 구성 · 등급 = 초안대로.
4. 교과서 쪽수(page) = 빈칸으로 먼저 넣고, 선생님이 나중에 한 번에 알려 주시면 채운다.
