# ✍ 서술 칸(say) 되살림 · 대조 (2026-11-23 · 📚 차시팩 #1)

선생님 말씀: 「11차시 서술형 풀이 과정이 안 나옴」.

## 원인

드라이브 v3 은 팩 꼴(`mons`)이었고, 여기에는 say(나의 풀이)와 why(근거 줄)가 없었어요. 서버에는 11/19 손발 방이 더한 say 와 why 가 있었는데, v4(열쇠) 를 드라이브 v3 위에 만들면서 이 둘이 빠졌어요. v5(혼자풀리게) 도 v4 를 이어받아 0 이었어요.

11/22 의 fix2 는 원인이 아니에요. 아래 대조표에서 보듯 그날 고친 다른 팩들은 say 수가 그대로예요.

## 고침

`(11차시) 차시팩_v6_서술.json` (드라이브 08) 은 v5 를 바탕으로 m3 · m4 소레이드 문항마다 say 와 why 만 넣은 판이에요.

- 출처는 베타 저장소 `tools/pack-upload/official/set-11.json` 이에요(11/22 · say 가 모든 칸에 있음).
- 판은 첫 문항의 끝줄 + 정답 · 보기로 짝짓고, 단계는 같은 자리끼리 짝지었어요. 단계마다 정답과 보기가 같은지도 확인했어요.
- 검산: 사슬 몬스터 say 에 그 판 정답(식 · 대우 · 포함 관계 · 고른 기호)이 들어 있는지 봤어요. 근거 줄은 정답이 「대우」 · 「참」인지 봤어요.
- say 와 why 말고 다른 칸은 하나도 바뀌지 않았어요.
- 앱 업로드 검사기: v5 = 오류 0 · 알림 2(✍ 서술 칸 없음 × 2) → v6 = 오류 0 · 알림 0.

도구: `make_11v6.py` · `count_say.py`
