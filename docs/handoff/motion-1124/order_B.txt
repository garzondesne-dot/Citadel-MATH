제목 자막: 「함수 = 알까기」

[1 질문 · 0~4초] 큰 자막 「이 대응은 함수일까?」 · 왼쪽 알 판 X(파랑 알 3개: 1, 2, 3) · 오른쪽 과녁판 Y(칸 4개: a, b, c, d).
[2 룰 1 · 4~11초] 자막 「룰 1 : 무조건 쏜다」. 알 1 → b, 알 2 → b 로 쏨(화살표 날아감). 알 3 은 가만히 있음 → 빨강 ✕ 「쏘지 않은 알이 있으면 함수 ✕」. 다시 알 3 → d 쏨 → 초록 ✔.
[3 룰 2 · 11~17초] 자막 「룰 2 : 한 방향으로만」. 알 2 가 화살을 두 개(b 와 c) 쏘는 장면 → 빨강 ✕ 「한 알이 두 칸 = 함수 ✕」 → 하나 지우고 b 만 남김 → 초록 ✔. 작은 자막 「두 알이 같은 칸(b)을 맞혀도 OK」.
[4 이름 붙이기 · 17~30초] 
- 알 판 전체가 노랑으로 빛남 → 라벨 「쏘는 쪽 = 정의역 X = {1, 2, 3}」
- 과녁판 전체 테두리 → 라벨 「과녁판 전체 = 공역 Y = {a, b, c, d}」 (「과녁」의 「과」 → 「공역」 글자 연결 연출)
- 맞은 칸 b, d 만 초록으로 빛남 → 라벨 「맞은 칸만 = 치역 {b, d}」 (「쳤으니까 치역」 말풍선)
- 안 맞은 칸 a, c 는 회색: 「공역에는 있지만 치역에는 없음」 · 「치역 ⊂ 공역」
[5 요약 카드 · 30~38초]
함수 = ① 무조건 쏜다 ② 한 방향으로만
쏘는 애들 = 정의역 · 과녁판 = 공역 · 맞은 애들 = 치역 (치역 ⊂ 공역)
예시: X = {1, 2, 3}, Y = {a, b, c, d}, 1 → b, 2 → b, 3 → d (학습지 = {1, 2, 3, 4} → {a, b, c, d} 와 다르게).
