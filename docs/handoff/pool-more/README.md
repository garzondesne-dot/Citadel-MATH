# 🔁 바뀐 판 늘리기 (🌊 설계 방 · 묶음 #5 건 2 · 2026-11-21)

> 게시판 던전이 세트0(수업에서 푼 숫자)을 빼고 내므로, 학생이 만나는 판 = 「바뀐 판」뿐. 바뀐 판이 적은 팩부터 늘림.
> 원칙: 학습지 문항 꼴 그대로 · 숫자만 · 답은 생성기(`gen_more.py`)가 계산해 넣고 **검산 도구(`check.py`)가 문제 글에서 따로 다시 계산**해 맞춰 봄.

## 1. 지금 판 수 → 늘린 판 수

| 팩 | 어디 | 원문항마다 바뀐 판(세트0 빼고) | 늘린 뒤 | 한 일 |
|---|---|---|---|---|
| 2 ~ 10차시 | 앱 안(gen 생성기) | **모름** — 생성기 코드가 베타 저장소에만 있어 이 방에서 못 읽음 | — | 3절 「손발에 줄 요청 글」 |
| 11 · 12 · 13차시 | 서버 팩 | 6 (보스 5 · 짝 세트 2) | 6 그대로 | 넉넉함 · 손 안 댐 |
| 성채 1 · 2 · 3층 | 서버 팩 | 6 (판 7) | 그대로 | 넉넉함 |
| **14차시 함수** | 드라이브(v3 묶음) | **3** (몬스터 3 · 보스 4문항 모두) | **6** | `out/ex14-more.json` |
| **15차시 함수의 그래프** | 드라이브(v2 묶음) | **3** | **6** | `out/ex15-more.json` |
| **16차시 합성함수** | 드라이브(v3 묶음) | **3** | **6** | `out/ex16-more.json` |
| **17차시 역함수** | 드라이브(v2 묶음) | **3** | **6** | `out/ex17-more.json` |
| 성채 4층 | 드라이브(v1) | 6 (판 7) | 그대로 | 넉넉함 |

- 14 ~ 17차시는 팩이 「세트0 + 바뀐 판 3」이라 게시판에서는 **판이 3개뿐** → 세 번 돌면 같은 숫자를 다시 만남. 6으로 늘림(11 ~ 13차시와 같은 수).
- 늘린 것: 몬스터마다 `retry.pool` +3 · 소레이드 몬스터는 `chain.pool` 에도 같은 3판(서술 문장 say 포함) · 보스 `pool` 문항마다 +3. 보스 짝 세트(`sets`) · 세트0 · 영상 · 열쇠 · 도움말은 손 안 댐. 팩 `v` 는 +1.
- 새 판의 숫자가 있던 판 · 학습지와 겹치지 않는지 = 검산 도구가 「판끼리 문제 · 보기가 같음」으로 검사(0건).

## 2. 소문항 수 (늘린 뒤 · 검산 도구가 다시 계산해 본 수)

| 차시 | 소문항 | 다시 계산해 맞춘 것 | 나머지(글 문항 = 눈으로) |
|---|---|---|---|
| 14 | 161 | 63 | 정의역 · 공역 고르기처럼 답이 글인 문항 |
| 15 | 147 | 105 | 그래프 고르기 일부(세로선 판정) |
| 16 | 140 | 98 | 소레이드 1 ~ 3단계(식 세우기 글) |
| 17 | 154 | 92 | 소레이드 2 · 3단계(식 쓰기) · 뜻 고르기 |

- 「다시 계산」 = 문제 글에서 함수식 · 숫자를 읽어 합성 값 · 합성 식 · 역함수 · 연립 · 치역 · 대응 판정 · 점 그래프 · 화살표 정답을 따로 계산해 팩의 정답과 견줌. 오답 보기가 정답과 같은 식인지도 봄.
- 결과: **고칠 것 0건**(늘린 팩 4개) · 정답 자리 분포 ①191 · ②167 · ③180.

## 3. 앱 팩(2 ~ 10차시 · gen 생성기) — 손발 #1 · #2 에 줄 요청 글

```
[요청] 2 ~ 10차시 앱 팩 생성기의 「바뀐 판 수」 세기 + 적은 것 넓히기 (설계 방 묶음 #5 건 2)
1. 세기: 생성기 이름마다(set02.r0 … set10.boss · 50개) 씨앗 1 ~ 200 을 넣어 나온 문항 묶음을 글(문제 + 보기)로 비교 → 서로 다른 판 수를 표로.
   세트0(수업 숫자)과 글이 같은 판은 빼고 셈.
2. 기준: 서로 다른 판 6개 미만 = 넓히기 대상(손발 #2 가 본 8차시 문제 3 포함).
3. 넓히는 법(문항 꼴은 그대로 · 숫자만):
   · 숫자 범위를 넓힘(예: 원소 1 ~ 6 → 1 ~ 9) · 집합 이름 · 조건의 수를 바꿈 · 보기 순서만 다른 것은 같은 판으로 셈
   · 답이 음수 · 분수 · 0 이 되어 학습지 수준을 넘는 판은 버림(조건으로 거름)
   · 넓힌 뒤 다시 1번으로 세어 6개 이상인지 확인
4. 검산: 생성기가 낸 정답을 문제 글에서 따로 다시 계산하는 시험 하나씩(집합 연산은 파이썬 set · 명제는 진리집합 포함).
5. 결과 = 「생성기 이름 | 지금 판 수 | 넓힌 뒤 판 수 | 바꾼 범위」 표를 메인에.
```

## 4. 파일

| 파일 | 내용 |
|---|---|
| `gen_more.py` | 14 ~ 17차시 새 판 생성기(판 3개씩의 숫자가 맨 아래 NEW 표) + 있던 문항 표기 고침 |
| `check.py` | 독립 검산(원본 · 늘린 팩 모두) |
| `fnlib.py` | 식 글자 ↔ 계산 공용 |
| `out/ex14 ~ 17-more.json` | 늘린 팩(서버에 올릴 꼴 그대로 · 영상 · 학습지는 드라이브 묶음의 것을 그대로 씀) |

다시 만들기: 드라이브 묶음 4개를 `z14 … z17` 폴더에 풀고 `python3 gen_more.py <부모 폴더> out` → `python3 check.py out/*.json`.
