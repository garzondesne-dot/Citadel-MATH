## 2. 입구 · 층

- 게시판 지도(board-map-v2) 오른쪽 위 **🔒 성문 칸**. 잠김 = 자물쇠 + 「⭐ n개면 열려요 (지금 m개)」 · 열림 = 문이 열리고 횃불 · 처치 = 문 위 깃발.
- 성문을 누르면 **층 고르기 판**: 1층 · 2층 · 3층 카드(보스 그림 · 열림 조건 · 내 최고 별 · 실드 속성 미리 보기).
- 층 = 성채 평가 팩 하나 = 보스 하나.

| 층 | 문항 팩 | 단원 차시 | 보스(이름 = 초안) | 열림 조건(제안) |
|---|---|---|---|---|
| 1층 | eval-1 집합 | 2 ~ 7 | 겹침의 성문지기 (벤 다이어그램 고리 골렘) | 2 ~ 7차시 지도 별 **10개**(최대 18) + 여섯 차시 모두 ⭐1 이상 |
| 2층 | eval-2 명제 | 8 ~ 13 | 참과 거짓의 쌍두 기사 | 8 ~ 13차시 지도 별 **10개**(최대 18) + 모두 ⭐1 이상 |
| 3층 | eval-3 대단원 | 2 ~ 13 | 증명의 용왕 ∎ | 1 · 2층 처치 + 2 ~ 13차시 별 **24개**(최대 36) |
| (4층) | 성채 4층 함수(아직 서버에 없음) | 14 ~ 17 | 나중 | 14 ~ 17차시 별 7개(최대 12) — 팩이 올라온 뒤 |

- n 의 까닭: 「모두 ⭐1」 = 골고루 돌기(한 차시만 파서는 안 열림) · 「10개」 = 여섯 차시를 다 깨고(6) 정확도 별을 4개 더 = 절반쯤은 70% 이상으로 푼 학생. 최대의 55% 선. 3층 = 67%.
- 3층만 「앞 층 처치」를 요구(대단원 = 마무리). 1 · 2층은 서로 독립(명제 진도 중에도 1층 가능).

## 3. 🛡 실드 2막 · 😡 분노

| | 1막 | 2막 |
|---|---|---|
| 뜨는 때 | 보스 체력 **80%** | 보스 체력 **50%** |
| 칸 수 · 속성 | **3칸** = 약점 계열 2 + 다른 계열 1 | **4칸** = 1막과 **다른 순서 · 네 계열**(1막에 없던 계열 포함) |
| 실드 중 피해 | ×0.3(일반과 같음) | **×0.2**(더 단단) |
| 모습 | 지금 속성 방패 | **금 간 붉은 판**(`raid-shield2` 주문) · 보스도 2막 모습으로 바뀜 |
| 깨는 법 | 스킬 2(구슬 2 · 속성 맞음) 1칸씩 · 없는 속성 = 📜 도움표 — 일반과 같음 | 같음 |
| 다 깨면 | 무방비 12초(피해 ×2 · ATB ×2) | 무방비 12초 + **보스 「갑옷 깨짐」 모습**(끝까지) |
| 😡 분노 | 아직 없음 | **2막 실드가 뜨는 순간 분노 시작**(공격 간격 12 → 9초 · 피해 ×1.2 · 들어갈 때 특수 한 번) · 팀 퍼펙트 2번 = 8초 진정 그대로 |

- 체력바 눈금 = 80% 「실드」 · 50% 「실드 Ⅱ · 분노」(일반의 70 · 30 눈금 자리에).
- 정찰 카드에 **1막 3칸 · 2막 4칸 속성을 모두** 미리 보여 줌 → 출발 전 용사 바꾸기로 맞춤(다섯 계열 가운데 넷이 2막에 나오므로 팀 구성이 작전이 됨).
- 머리 뼈대 「1막 4칸」 → **3칸** 으로 낮춤. 까닭: 지금 일반 판이 2칸(11/22)이라 2 → 3 → 4 로 한 칸씩 늘어나야 「더 어렵다」가 읽히고, 1막 4칸은 모의에서 1막 깨는 데만 72초(3칸 64초 · 일반 2칸 약 48초)로 초반이 늘어짐. 2막 4칸 = 뼈대 그대로.

## 4. 수치 — 모의 실험 결론 (`모의표.md`)

**가장 큰 발견: 어려운 문항 + 보스 공격 ×1.5 는 같이 못 씀.**
- 문항이 어려우면 정답률이 떨어지고 소문항이 느려져 **구슬이 절반 가까이 덜 모임** → 회복 · 부활 · 실드 깨기가 한꺼번에 막힘. 뼈대 그대로(공격 ×1.5 · 구슬 그대로)면 보스 체력을 아무리 낮춰도 승률 20%(표 1절 A).
- 그래서 두 가지를 바꿈: ① **큰 구슬**(성채 문항 첫 시도 정답 = 구슬 2) ② **공격 ×1.1**. 어려움은 「문항 · 실드 2막 · 긴 체력」에서 오게 함.
- 큰 구슬의 뜻 = 「어려운 문제는 한 방이 크다」. 찍기 막기(틀리면 ½ · 0)는 그대로라 한 번 틀려도 +1.

| 고른 값(R) | 값 | 민감도(4명 · 65% · 승률 50% 기준) |
|---|---|---|
| 보스 체력 | 일반 3800 → **5700(×1.5)** | +15% → 37% · −15% → 62% |
| 보스 공격 | **×1.1** | ×1.0 → 68% · ×1.3 → 24% · ×1.5 → 11% |
| 큰 구슬 | **2** | 1.5 → 11% · 1(없음) → 0% |
| 2막 분노 | 2막부터 | 30% 에서만 → 67% |
| 도망 | 10분 | 8분 → 43%(도망 7%) · 12분 → 51% |

| 사람 수(나머지 봇) | 정답률 50% | 65% | 80% | 이긴 판(분) |
|---|---|---|---|---|
| 4명 | 4% | 50% | 96% | 4.0 ~ 6.5 |
| 2명 | 16% | 36% | 73% | 5.1 ~ 6.7 |
| 혼자(봇 3) | 26% | 42% | 58% | 5.6 ~ 6.4 |

- 2막 실드: 뜨는 시각 약 2.4분 · 깨는 데 약 78초(1막 62초) · 2막을 깬 판의 86% 가 이김 → **2막 실드가 승부처**.
- 혼자 판은 봇이 평균을 잡아 줘 못하는 학생에게 오히려 쉬움(26%) · 잘하는 학생은 봇이 발목(58%) → v1.2 「📣 작전 명령」과 짝이 맞음.
- **문항 어려움에 매우 민감**(문항이 일반 난도면 97% · 더 어려우면 9%) → 층마다 체력을 따로 맞춰야 함(표 5절: 1층 ×2.0 · 2층 ×1.5 · 3층 ×1.2 는 「어려움 가정」에 따른 어림). 손발 할 일: 진짜 엔진 · 봇으로 층마다 「보통 봇 4명 승률 50% · 이긴 판 5.5 ~ 6분」이 되게 체력만 맞춤.
- ⚠ **정답률 50% 팀은 거의 못 이김(4%)** — 고난도라 의도이긴 하나 좌절이 큼 → 10절 컨펌 ③ 「🕯 성채의 균열」 제안.

## 10. 선생님 컨펌 필요한 곳

1. **큰 구슬**(성채 문항 첫 시도 정답 = 구슬 2) — 이게 없으면 어려운 문항 판이 성립하지 않음(모의 0 ~ 11%). 다른 길 = 문항을 덜 어렵게.
2. **보스 공격 ×1.1**(뼈대 ×1.5 → 낮춤) · 체력 ×1.5 · 실드 1막 3칸 → 2막 4칸.
3. **🕯 성채의 균열**(제안): 같은 층에서 지거나 도망칠 때마다 다음 판 보스 체력 −10%(최대 −30% · 이기면 원래대로 · 균열로 이긴 판은 ⭐ 최대 2개). 정답률 50% 팀 승률 4% 를 그대로 둘지.
4. 열림 조건: 1 · 2층 = 별 10개 + 모든 차시 ⭐1 · 3층 = 1 · 2층 처치 + 별 24개.
5. 목표 승률 = 보통 팀 50%(일반 70%) · 길이 5.5 ~ 6분 · 도망 10분.
6. 보상: 💎 2배(하루 200 안) · 공적 3배 · 층별 칭호 · 첫 처치 깃발.
7. 레이드 별 = 성문 칸에 따로 · 단원 별 합에는 안 셈 · 숙련 안 씀.
8. 보스 이름 · 모습(겹침의 성문지기 · 참과 거짓의 쌍두 기사 · 증명의 용왕).
