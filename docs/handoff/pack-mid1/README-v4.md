# 무안행복중 중1 통계 1 · 2차시 차시팩 v4 (2026-11-23 · 📚 차시팩 #1)

## 선생님 결정 (같은 날)

선생님 말씀: 「학습지를 보고 문제를 풀 수 있게 해 주고, 문제의 변형은 그 같은 문항의 학습지 도수분포표를 다르게 해석하는 문항으로」.

먼저 자료를 문항 글로 옮겨 적은 초안을 만들었다가 이 결정으로 바꿨어요(초안은 git 기록에 있어요).

## 꼴

- **문항 글**: 첫 줄에 어느 학습지 자료인지와 기준 정보를 적고, 줄을 바꿔 물음을 적어요.
  - 예: 「학습지 문제 1) 통학 시간 도수분포표(합계 34명 · 10분 이상 20분 미만의 도수는 ?)를 보고 답하시오.」 ⏎ 물음
  - 표 · 줄기와 잎 · 히스토그램은 옮겨 적지 않고, 학습지와 몬스터 칸 학습지 그림을 보고 풀어요.
  - 「위 표」처럼 다른 칸을 가리키는 말은 쓰지 않아요.
  - 합계가 바로 판 0 정답인 자료(영화 편 수 · 나무 그루 수)에는 합계를 적지 않아요.
- **판**:
  - 판 0 은 학습지 물음 그대로예요.
  - 판 1 ~ 6 은 숫자를 바꾸지 않고, 같은 자료에서 다른 것을 물어요. 한 몬스터의 21물음이 모두 달라요.
  - 판마다 문항 꼴(type)은 판 0 과 같아요.
- **형성평가**: 7판이고, 같은 학습지 자료에서 다른 것을 물어요. O/X 는 개념 문장을 판마다 바꿔요.
  - links: 1차시 [m1, m1, m1, "", ""] · 2차시 [m3, m3, "", "", ""]
- **넣지 않은 것**: [[graph]] · 표 마크업 · 입장 열쇠 · 소레이드 · 오개념 · 성취기준 (학교판 원칙)

## 검사 (`verify_v4.py` · 표 = `check_v4.md`)

- **독립 검산**: 학습지 PDF 글에서 따로 옮긴 원자료로 물음 글을 읽어 다시 풀었어요(gen_v4.py 를 쓰지 않아요). 196문항이 모두 맞았고, 그중 개념 O/X · 개념 선다 39문항은 눈으로 확인했어요.
- **답 하나**: 계급 고르기 보기 중 조건에 맞는 것은 정답 하나뿐이고, 같은 도수가 둘인 물음은 쓰지 않았어요. 숫자 답은 0 ~ 99, % 는 정수로 나와요.
- **판 0**: v3 판 0 과 정답 · 보기 · 물음이 같아요.
- **판끼리**: 같은 물음이 없어요.
- **풀 자료**: 자료를 보는 문항은 「학습지 자료 필요 ✔」(PACK-GUIDE 검사 9 의 예외 · 학습지 자료를 보는 차시)로, 개념 문항은 「혼자 풀림 ✔」로 표시했어요.
- **앱 업로드 검사기**: 오류 0 · 알림 0 이에요.
