① 문제 풀기

  • 그림 · 체력 막대 · 아이콘 없음 · 공책 줄 위에 문제
  • 고른 답 = 파란 펜 · 빈칸 밑줄에 「답 {5, 6}」
  • 아래 줄 자리(힌트 · 다음 · 서술형)는 게임과 같음 · 글자만

② 정찰 (문제 나오기 전)

  • 그림자 몬스터 대신 안내 두 줄

③ 소레이드 (단계 문제)

  • 졸개 · 대장 대신 「단계 1 / 3」 네모 칸
  • 앞 단계 답 줄은 그대로(검정 글자)

④ 형성평가

  • 보스 대신 시험지 문항 꼴
  • 「⭐ 보너스」 → 「보너스 문항」 글자

⑤ 채점 (빨간 펜)

  • 선생님 채점처럼 빨간 ○ ✗ + 비스듬한 점수
  • 💎 · EXP 알림 없음 (뒤에서는 쌓임)

⑥ 다 맞힘 (기력)

  • ⚡ 카드 · 기력 이름 대신 「더 해 볼 것」 두 줄
  • 묶기 · 진필살기 · 전리품 표시 없음

⑦ 수업 밖 = 오늘 할 일

  • 캠프 그림 대신 체크 목록 · 아이콘 없음
  • ❓ 이름 = 게임 이름(허수아비 · 성채 던전) 대신 학습 이름(복습 · 단원 평가) — 11/12 「용어 통일」과 부딪힘 → 정하실 것
