AI 도우미 설치 안내 (한 번만 하면 그다음부터는 파일만 올리고 한 줄로 부탁)
AI 를 다시 학습시키는 것이 아니라, AI 에 「고정 지침 + 참고 파일」을 저장해 두는 방법이에요.

[어디에 넣나요]
| AI | 만드는 곳 | 고정 지침 칸 | 참고 파일 칸 |
| Gemini | 왼쪽 메뉴 「Gem 관리자」 → 「새 Gem」 | 「요청 사항(안내)」 | 「지식」 |
| ChatGPT | 「GPT 탐색」 → 「만들기」 → 「구성」 | 「지침」 | 「지식」 |
| Claude | 「프로젝트」 → 「새 프로젝트」 | 「프로젝트 지침」 | 「프로젝트 지식」 |
(무료 계정에서 위 메뉴가 없으면: 새 대화를 열고 지침 글 전체를 첫 메시지로 붙여 넣은 뒤 참고 파일을 같이 올려도 돼요.)

1. 학습지 도우미
- 이름: 「학습지 도우미」
- 고정 지침: 01_학습지도우미_지침_v2.txt 글 전체
- 참고 파일: 05_예시_학습지_10차시.html
- 쓰는 법: 교과서 쪽 사진(또는 PDF) + 「과목 · 학년 · n차시 · 범위 · 지난 차시」 한 줄 → 「학습지 만들어 줘」 → 나온 HTML 을 저장해 브라우저로 열기 → 인쇄 → PDF 로 저장 → 정답 표로 숫자 · 정답 확인(선생님 몫).

2. 차시 팩 도우미
- 이름: 「차시 팩 도우미」
- 고정 지침: 03_차시팩도우미_지침_v3.txt 글 전체
- 참고 파일: 06_예시_차시팩.json · 07_도감_ID_목록.txt
- 쓰는 법: 학습지 PDF 올리기 → 「차시 팩 만들어 줘」 → zip 이 나오면 그대로, json 만 나오면 exNN.json 으로 저장해 학습지 PDF(이름은 영어 · 숫자)와 함께 zip → 앱 「📦 차시 팩 올리기」.
- 고칠 칸이 나오면: 앱의 「📋 AI 에 붙일 문구 복사」 → 같은 대화에 붙여 넣기 → 고친 팩으로 다시 올리기.

[알아 두기]
- 정답 확인은 선생님 몫이에요(앱 검사기는 꼴과 일부 계산만 봐요).
- 몬스터 · 배경 그림은 비워 두면 앱이 던전을 입혀요. 바꾸고 싶으면 앱 차시 카드 「🎲 던전」에서 골라요.
- 영상: 영상 파일이 있으면 이름을 영어 · 숫자로 바꿔(예: ex09-video1.mp4) 팩 도우미에게 이름을 알려 주고 zip 에 같이 넣어요.
