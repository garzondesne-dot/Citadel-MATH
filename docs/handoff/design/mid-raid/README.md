## 소레이드 스스로 검사 (SORAID-RULES 5절) ✔
- 「나의 풀이」 첫 판(집합): ① 드모르간의 법칙에 의해 Aᶜ ∩ Bᶜ = (A ∪ B)ᶜ 이다. ② A = {6, 12, 18, 24, 30} 이므로 n(A) = 5, B = {1, 2, 3, 4, 6, 8, 12, 24} 이므로 n(B) = 8 이다. ③ A ∩ B = {6, 12, 24} 이므로 n(A ∪ B) = 5 + 8 − 3 = 10 이다. ④ 그러므로 n(Aᶜ ∩ Bᶜ) = n(U) − n(A ∪ B) = 30 − 10 = 20 이다.
- 「나의 풀이」 첫 판(명제): ① x² − 10x + 9 = (x − 1)(x − 9) ≤ 0 이므로 P = {x | 1 ≤ x ≤ 9} 이다. ② p 가 q 이기 위한 충분조건이려면 p ⇒ q, 즉 P ⊂ Q 이어야 한다. ③ Q = {x | x ≤ a} 가 P 를 모두 포함하려면 P 에서 가장 큰 수(9)가 Q 에 들어가야 한다. ④ 그러므로 구하는 a 의 값의 범위는 a ≥ 9 이다.
- S1 졸개 하나 = 개념 하나 ✔ · S2 조건의 뜻 졸개(드모르간 · P ⊂ Q)가 계산보다 먼저 ✔ · S3 결론 앞 「무엇이 들어가야 하나」 ✔ · S5 ○/✕ 없음 ✔ · S7 4단계 ✔ · S8 산 1개 · 맨 뒤 ✔ · S10 links ✔ · R1 법칙 이름(드모르간)이 풀이 문장에 ✔ · R2 근거 줄은 그 단계 뒤 ✔ · T1 함정 = 포함 방향 반대 · 드모르간 기호 그대로 · 범위 방향 ✔ · T3 판마다 보기 겹침 없음(검산) ✔ · P1 한 번 더 판에도 문제 전체가 맨 위 ✔.

## 바꾼 점 · 선생님 컨펌이 필요한 곳
1. **명제 차시 ⏱ 48.5분(처음 값 기준) → 45분을 넘음.** 몬스터 1 · 2 의 소문제가 6 + 7개라서. 고를 것: ㉮ 그대로(수업에서 넘치면 몬스터 2 를 🎯 복습으로 → 형성평가 3번도 같이 빠짐) ㉯ STEP 2 개념 칸을 빼고 한 장 정리로 대신(44.5분) ㉰ 문제 4(04 충분 · 필요 3칸)를 허수아비로 미리 뺌(44분).
2. **명제 몬스터 3(08)을 소레이드 4단계로 짰음**(묶음 글에는 「산」만 적혀 있었음). 숫자 하나만 묻는 몬스터는 결론을 갑자기 묻게 돼서(S3). 싫으시면 한 문항으로 되돌림.
3. **08 의 물음 = 교과서대로 「a 의 값의 범위」**(a ≥ 9 · 4지선다). 성채 2층은 「최솟값」(숫자)으로 바꿔 놓았던 것.
4. **형성평가 01(집합) = 「집합인 것을 모두 고르시오」 한 문항**(교과서는 ⑴⑵⑶ 에 ○ ×) · **01(명제) = 「명제를 찾고 참 · 거짓을 바르게 판별한 것은?」 4지선다 한 문항**. 보스는 문항 하나 = 칸 하나라서.
5. **05 부정 · 03 역 · 대우 = 「문장 + 참 · 거짓」을 한 칸에서 고름**(성채 03 과 같은 꼴 · 05 는 성채에서 2칸이던 것을 1칸으로 줄임 = 시간).
6. **형성평가 07 · 10(명제)은 교과서 서술형 · 발전 문항** → 폰에는 답만, 풀이는 학습지에. 형성평가 4문항 중 2문항이 어려움(반 통과율이 낮게 나올 수 있음).
7. **집합 형성평가 2번(04 n(A ∩ B))의 짝 = m1**(묶음대로) — 내용은 몬스터 2 · 3(원소의 개수)에 더 가까움. 바꾸려면 links 한 칸.
8. **한 번 더 판 6개의 숫자**는 성채 1 · 2층 팩의 어느 판과도 겹치지 않게 골랐음(verify.py 가 대조). 첫 판(교과서 숫자)은 성채의 한 번 더 판에 드물게 나올 수 있음.
9. **덧칸(💡 도움 3단 · 🔎 익명 풀이 · ✔ 개념 체크) 없음** = 기본 팩. 필요하면 다음 묶음으로.
