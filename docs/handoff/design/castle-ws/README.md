## 지킨 것
- 문항 = 성채 팩 **첫 판 그대로**(게임과 같은 숫자). 스크립트가 방마다 문제 글 조각 · 정답을 팩과 대조(다르면 멈춤).
- 문항마다 꼬리표 「🏰 n층 NN번 방 · k차시 뒤 열림」(k = 팩의 방 열림 값) · 👑 보스 방 = 「열린 방의 60%를 처치하면 열림」 · 서술형 방 = 「📷 성채에서 사진으로 내기」 · ✏ 풀이 칸.
- 머리말 = 우리 학교 · 레이드용 학습지 틀(wslib) · 맨 위에 쓰는 법 3줄.

## 바꾼 점 · 선생님 컨펌이 필요한 곳
1. **폰용 물음 → 종이용 물음으로 되돌려 적음**(숫자 · 정답은 그대로): 「원소를 모두 고르시오」 → 「원소나열법으로 나타내시오」 · 4지선다 → 「쓰시오 · 구하시오」 · 소레이드 방(1층 07 · 08 · 09 · 10 · 11 · 12)은 단계 없이 문제 전체 한 줄 + 풀이 칸(문장 틀 = 교과서 중단원 마무리).
2. **1층 01 · 2층 01 · 03 · 05**: 게임은 칸마다 따로 묻지만 종이에는 교과서처럼 한 문항에 ⑴⑵⑶ 로 묶음.
3. **2층 08** = 게임 첫 판대로 「실수 a 의 최솟값」(교과서 원문은 「a 의 값의 범위」).
4. **📷 방 = 1층 07 · 11 · 2층 07 · 10**(팩의 사진 방 표시 그대로). 풀이 칸을 넓게 줌.
5. **쓰는 법 문장**에 「한 번 틀리면 방의 숫자가 바뀌어요」를 넣음 → 종이 답이 두 번째부터는 안 맞는다는 안내. 싫으시면 뺌.
6. **교사용 정답은 첫 판에만 맞음**(교사용 맨 위에 적음).
7. 머리말 제목 = 「🏰 성채 1층 · 집합」 · 작은 글씨 줄에 「집합 중단원 · 성채던전 1층과 같은 문제 (12문항)」(「성채 1층 · 집합 중단원」은 제목 칸에서 두 줄로 꺾여서 나눔).
8. 확인 도장 칸이 2쪽 끝에 있음(양식 기본) — 나눠 주기만 하는 용도라 빼도 됨.
