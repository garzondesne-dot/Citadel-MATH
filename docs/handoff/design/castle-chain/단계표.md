## 2층 07 · 07 역이 참이 되는 a (서술형) — ⚔ 소레이드 · 5단계 · 📷 서술형

> 07 실수 x 에 대하여 두 조건 p: x² − 9a² ≤ 0, q: |x − 2| ≤ 7 일 때, 명제 p → q 의 역이 참이 되는 자연수 a 의 최솟값은?

| 단계 | 묻는 것 | 답 꼴 | 정답 | 💡 근거 줄 | 「나의 풀이」에 쌓일 한 줄 | 기준표 |
|---|---|---|---|---|---|---|
| 졸개 1 | ① 조건 p 의 진리집합 P 는? | 고르기(3) | {x | −3a ≤ x ≤ 3a} | — | x² − 9a² ≤ 0 에서 (x + 3a)(x − 3a) ≤ 0 이므로 P = {x | −3a ≤ x ≤ 3a} 이다. | s1 |
| 졸개 2 | ② 조건 q 의 진리집합 Q 는? | 고르기(3) | {x | −5 ≤ x ≤ 9} | — | |x − 2| ≤ 7 에서 −7 ≤ x − 2 ≤ 7 이므로 Q = {x | −5 ≤ x ≤ 9} 이다. | s2 |
| 졸개 3 | ③ 「명제 p → q 의 역이 참」을 진리집합 P, Q 로 나타내면? | 고르기(3) | Q ⊂ P | ∵ 명제 p → q 의 역은 ( q → p )  | 명제 p → q 의 역 q → p 가 참이려면 Q ⊂ P 이어야 한다. | s3 |
| 졸개 4 | ④ Q ⊂ P 가 되기 위해 맞는 식을 모두 고르시오. | 모두 고르기(5) | −3a ≤ −5 · 9 ≤ 3a | — | Q ⊂ P 이려면 −3a ≤ −5 이고 9 ≤ 3a 이어야 한다. | s4 |
| 👑 대장 | 👑 그러므로 자연수 a 의 최솟값은? | 숫자 칸 | 3 | — | 두 식에서 a ≥ 5/3, a ≥ 3 이므로 a ≥ 3 이다. 그러므로 자연수 a 의 최솟값은 3 이다. | s4 |

| 단계 | 묻는 것 | 답 꼴 | 정답 | 💡 근거 줄 | 「나의 풀이」에 쌓일 한 줄 | 기준표 |
|---|---|---|---|---|---|---|
| 졸개 1 | ① (가) 「어떤 실수 x 에 대하여 p 이다」가 거짓이라는 것은? | 고르기(3) | 모든 실수 x 에 대하여 ax² + 4x − 2 < 0 이다 | ∵ 「어떤 x 에 대하여 p」의 부정은 ( 「모든 x 에 대하여 ~p」 )  | (가)가 거짓이므로 그 부정 「모든 실수 x 에 대하여 ax² + 4x − 2 < 0」 이 참이다. | s1 |
