# (초안) PACK-GUIDE 17절 · 🔑 입장 열쇠 `keys` — 설계 방 제안 · 머리 검토 전

## 17. 🔑 입장 열쇠 `keys` (선수 학습 점검)
맨 위 칸 `keys` = 그 차시 문제를 막는 **중학교 내용** 2~3개. 없으면 앱은 열쇠 없이 예전처럼 움직인다.
```json
"keys": [
  { "id": "k1", "name": "완전제곱식", "grade": "중3 · 인수분해 공식",
    "help": "x² ± 2kx + k² = (x ± k)² · 가운데 항의 절반을 제곱하면 끝 항이에요.",
    "vers": [ 문항, 문항, 문항 ],
    "uses": [ { "at": "m2", "n": 2 }, { "at": "boss", "n": 3 } ] }
]
```
| 칸 | 자료형 | 규칙 |
|---|---|---|
| `id` | 글자 | `k1` · `k2` · `k3` (팩 안에서 겹치지 않게) |
| `name` | 글자 | 열쇠 이름 = 개념 이름(12자 안쪽) · 학생 화면 · 학습지에 그대로 나옴 |
| `grade` | 글자 | 「중n · 단원」 — 교사 화면 · 대시보드용 |
| `help` | 글자 | 💡 한 줄(틀렸을 때) · 그 문제의 정답을 쓰지 않음 · 60자 안쪽 |
| `vers` | 문항 목록 | 6절 문항 꼴 그대로 · **판 0(대기실 · 쪽지) + 판 1 · 2(허수아비 열쇠 연습) = 3개** · 꼴은 판 0(수업 소문제)을 따름 — `choice` · `ox` · `number` · 1문제 30초 · 판끼리 꼴이 같아야 함 |
| `uses` | 목록 | 이 열쇠가 쓰이는 칸 · `at` = 몬스터 id 또는 `"boss"` · `n` = 그 칸의 소문제 번호(1부터 · 소레이드는 단계 번호 · 형성평가는 문항 번호) |

검사(올리기 창):
1. `keys` 는 3개까지 · `id` 겹침 없음 · `vers` 1개 이상(권장 3) · 꼴 같음 · 정답이 보기 범위 안.
2. `uses` 의 `at` 이 실제 있는 몬스터(또는 boss) · `n` 이 그 칸의 소문제 수 안.
3. 한 소문제에는 열쇠 하나만(같은 `at` · `n` 이 두 열쇠에 있으면 오류 = 상자가 두 번 열림).
4. 열쇠마다 `uses` 에 몬스터 칸이 하나는 있어야 함(형성평가만 가리키는 열쇠는 경고).
5. `later: true` 몬스터만 가리키는 열쇠 = 경고(수업에서 쓰일 일이 없음).

쓰이는 곳(2026-11-18 정정 2 · 「지금 배우는 내용에 집중 · 도구로라도 쓰게」): **대기실 = 판 0 한 문제씩만**(틀리면 💡 한 줄 + 답을 보여 주고 바로 🔑 · 다시 풀기 없음) · **허수아비 「🔑 열쇠 연습」 = 판 1~**(필요한 학생만).

만들 때:
- **판 0 = 그 열쇠가 쓰이는 수업 소문제(학습지 · 첫 판)와 같은 물음 · 같은 숫자 · 같은 보기**(2026-11-18 선생님 「숫자도 똑같이 · 눈높이」) · 여러 칸에 쓰이면 가장 먼저 나오는 칸 · 그 문제가 혼자 읽히지 않으면 앞에 조건 한 줄만 붙임. **판 1 · 2 = 같은 꼴 · 숫자만 다르게 = 🎯 허수아비 「🔑 열쇠 연습」 전용**(대기실에서는 쓰지 않음). 💡 한 줄 끝에 「이 열쇠는 문제 n 의 (m)에서 써요.」
- 숫자는 암산 한 번 · 보기는 정답 + 실제 착각 2개.
- 학습지에는 넣지 않고 **따로 쪽지**로 나눔(차시마다 A4 한 장에 6장 · 열쇠마다 판 0 문제 그대로).

## 팩 도우미 지침(PACK-HELPER · 팩 도우미 v3)에 넣을 줄
- 「차시 팩을 만들 때 `keys` 를 2~3개 넣는다: 이 차시 문제를 풀다 막히는 중학교 내용을 고르고(문제 풀이의 첫 계산 · 낱말 · 공식), 열쇠마다 3지선다 30초 문제를 판 3개로 쓴다.」
- 「`uses` 에는 그 내용을 실제로 쓰는 소문제만 적는다(`at` 몬스터 id · `n` 1부터). 한 소문제에 열쇠는 하나.」
- 「열쇠의 판 0 은 그 열쇠가 처음 쓰이는 수업 소문제를 그대로 옮기고, 판 1 · 2 는 숫자만 바꾼다. 💡 한 줄에는 정답을 쓰지 않고 끝에 「이 열쇠는 문제 n 의 (m)에서 써요」를 붙인다.」
- 「검산 표에 열쇠 문항도 넣는다(k1-0 · k1-1 · k1-2).」
