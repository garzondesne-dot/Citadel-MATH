# 🔑 입장 열쇠 · 화면 문구 초안 (설계 방 제안 · 숫자 · 규칙은 DECISIONS 「🔑 입장 열쇠」 그대로)

| 곳 | 때 | 문구 |
|---|---|---|
| 학생 대기실 단추 | 열쇠를 아직 다 못 얻음 | 「🔑 열쇠 얻기 (0 / 3)」 · 아래 작은 글 「친구들을 기다리는 동안 · 오늘 쓸 중학교 내용 3문제」 |

| 맞힘 | — | 「🔑 열쇠 획득! · 완전제곱식」 → 「다음 열쇠 ▶」 |
| 틀림 | — | 「💡 (help 한 줄)」 → 「다시 풀기」(숫자 바뀐 판 · 칼 · 벌 없음) |
| 두 번 더 틀림(판 3개를 다 씀) | — | 「💡 함께 봐요 — (help 한 줄)」 + 정답 풀이 한 줄 → 「알겠어요 · 🔑 열쇠 받기」(못 받는 학생 없게) |
| 대기실을 놓친 학생 | 첫 몬스터 등장 전 | 화면 위 띠 「🔑 열쇠 얻기 — 첫 몬스터 전까지」 |

| TV(종합실) | 상자 열림 | 「🎁 ○○ · 열쇠로 보물상자!」(짧은 띠 · 정답 · 오답 글자 없음) |
| TV 대기실 | — | 「🔑 열쇠 12 / 24」(반 합계만) |

| 리모컨 「지금」 칸을 누른 창 | — | 열쇠마다 「이름 · 얻음 n · 한 번에 n · 틀린 뒤 n」 + 「📺 이 열쇠 문제 TV 에 띄우기」 |
| 대시보드 | 수업 뒤 | 「🔑 열쇠 획득률 88% · 한 번에 61% · 사용률(🔑 문제 첫 시도 정답) 54%」 · 열쇠별 줄 |
