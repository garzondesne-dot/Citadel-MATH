## 0. 한눈에

- 설계안 v1 은 선생님이 정한 11가지 방향(가로 · ATB · 타이밍 바 · 문제 = 스킬 · 전원 생존)을 모두 담고 있고, **지금 문제 엔진 · 팩 · 그림을 그대로 씀** → 방향은 그대로 가도 됩니다.
- 정할 것은 **11개 + 덧 3개**. 그중 선생님 판단이 꼭 필요한 것은 **4개**(①-3 옛 기록 처리 · ①-1 설명 시간 · ①-7 초대 범위 · 덧-A 대체냐 추가냐). 나머지 7개는 「추천대로」 한 줄로 끝낼 수 있습니다.
- 가장 큰 걱정 1개: **「문제를 안 풀고 타이밍 바만 눌러도 되는가」**. 설계안은 실드(문제로만 깨짐)로 막고 있으나, 숫자가 느슨하면 다시 「그냥 누르다 끝」이 됩니다 → 2절 걱정 ①.
