## 3. 전투 규칙

| 항목 | 정한 것 |
|---|---|
| 일반 공격 | ATB 가 차면 타이밍 바(문제 없음) · 실패 0 · 성공 ×1 · 치명 ×1.5 |
| ⚡ 충전 | 소문항 정답 = ⚡ 1 · 소레이드 대장 단계 = ⚡ 2 · 최대 5개 |
| 스킬 | 가진 ⚡ 를 한 번에 다 씀 · 1개 ×1.0 · 2개 ×2.1 · 3개 ×3.3 · 4개 ×4.6 · 5개 ×6.0 |
| 스킬 손맛 | 「모았다 놓기」(꾹 눌러 차오르면 뗌) + 진동 · 빗나가도 100% · 성공 125% · 딱 맞음 150% (아이폰은 진동 대신 흔들림 + 소리) |
| 퍼펙트 | 첫 시도 정답 = 금색 ⚡(1.5배 값) · 원문항을 오답 없이 끝내면 내 ATB 즉시 가득 · 금색이 많을수록 「딱 맞음」 칸이 넓어짐 |
| 필살기 | ⚡ 5개를 가득 모아 쏘는 한 방(전체 화면 연출 + 긴 진동) · 팀 합동 필살기 = 2차 |
| 각성 스킬 | 내 강화 🔨 +10 만으로 열림(강화는 계정 하나라 모든 용사에 적용) · ⚡ 5개 필살기가 각성 필살기(×6.5)로 · 한 판 1번 · 용사별 각성 이펙트 · 덧효과: 딜러 약점 시간 +3초 / 탱커 팀 전원 다음 공격 −30% / 힐러 전원 +15 회복 / 서포터 팀 전원 ATB +30% |
| 실드 | 보스 HP 70% 에서 펼쳐짐 · **각자 1칸**(4 · 3 · 2 · 1인 = 4 · 3 · 2 · 1칸) · 원문항 「완주」로만 깨짐 · 실드가 남으면 보스 HP 가 1에서 멈춤 |
| 속성 상성 | 5계열 · 보스마다 약점 2계열 · 약점 계열 용사는 완주 한 번에 자기 칸 + 친구 칸 하나 |
| 약점 시간 | 마지막 실드가 깨지면 12초 · 받는 피해 2배 · ATB 2배(몰아치기) · 보스 공격 멈춤 |
| 막힘 안전망 | 도전자의 실드용 원문항 = 그 차시 가장 쉬운 칸 + 힌트 바로 열림 · 90초가 지나도 남은 칸은 다른 사람이 완주 2번으로 대신 깸 |
| 틀렸을 때 | HP · ATB 안 깎음 · 4번째 오답이면 같은 원문항의 새 숫자 판 |
| 보스 공격 | 12초마다 · 2초 전 표적 예고 · 단일은 살아 있는 용사 중 같은 확률 · 세 번째마다 광역 · 문제 글 · 보기 · 입력은 건드리지 않음 |
| 쓰러짐 | 스스로 못 일어남 · 친구가 ⚡ 1개로 살림 · **팀 부활 한 판 3번** · 다 쓰면 한 명만 쓰러져도 실패 · 쓰러진 학생은 문제를 풀어 친구 ATB 를 채움 · 1인 판은 쓰러지면 실패 |
| 승리 | 실드 전부 파괴 + 보스 HP 0 + 전원 생존 |
| 자리 | 전 · 중 · 후위 없음 · 서는 순서는 수치에 영향 없음 |

## 4. 용사

| 항목 | 정한 것 |
|---|---|
| 역할 4종 | 딜러(강타 = 스킬 ×1.5) · 탱커(엄호 = 친구가 받는 다음 공격 −50%) · 힐러(광역 회복 = 전원 +12 · 초안 +25 에서 낮춤 · 확인 전) · 서포터(격려 = 친구 ATB 가득) |
| 역할별 수치 | 딜러 HP 100 · 방어 0% · ATB 8.0초 / 탱커 130 · 20% · 8.9초 / 힐러 90 · 0% · 8.4초 / 서포터 95 · 0% · 7.3초 |
| 성장 식 | 전부 로그: 레벨 → 공격 · HP(Lv.10 에서 +20%) · 강화 → 공격만(+10 에서 +30%) · 스킬 등급 → 스킬(Ⅳ 에서 +25%) · 레벨 → ATB 속도(Lv.10 에서 +10%) · 기준 뒤로도 조금씩 오름 |
| 공부 기록 | 🛡 끈기(틀린 문제를 고친 수) → 방어율 최대 +10% · 🎯 집중(퍼펙트 수) → 치명 배율 최대 +0.2 |
| 계정 하나인 것 | 강화 · 레벨은 계정 하나(용사를 바꿔도 같음) → 용사마다 다른 것은 역할 수치 · 계열 · 장착 스킬 등급 |
| 격차 | 새내기 대 다 키운 용사 = 일반 공격 1.5배 · 스킬 1.75배 |
| 안 만드는 것 | 명중 · 회피 · 마나 · 원거리 차이 · 장비 |
| 용사 바꾸기 | 대기실(출발 전) + 결과 화면 「용사 바꿔 다시」 · 전투 중 못 바꿈 |
| 용사별 저장 | 스킬 + 칭호가 용사마다 저장 · 용사를 바꾸면 같이 바뀜 · 모든 화면(게시판 · 내 용사 · 수업 레이드 · 허수아비 · 성채) 같게 |
