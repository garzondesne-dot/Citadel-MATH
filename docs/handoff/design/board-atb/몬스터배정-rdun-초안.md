## 생각

- 차시마다 **테마 하나**(배경도 그 테마) · **난이도마다 다른 몬스터**: 연습 = 작은 놈 · 일반 = 중간 · 도전 = 그 테마의 가장 큰 놈 → 난이도를 올리면 새 몬스터를 만나는 보람.
- 테마의 나머지 2마리 = 2차(같은 난이도에서 번갈아 나오게 등).
- 몬스터마다 방향이 다를 수 있음 → 손발 #2 의 「늘 왼쪽을 봄」 표(flip)를 새 시트에도.

1. `BOSSES[차시]` 의 sprite · name · 배경을 난이도별로(연습 · 일반 · 도전) 바꿈 · 자세 칸 = 대기 2 · 공격 · 맞음 · 쓰러짐.

4. 옛 차시 보스(흑표범 · 드래곤 · 두꺼비 …)는 게시판 던전에서 안 씀(수업 레이드에서는 그대로).
