# 🐉 쉼터 놀이 「용이 잠든 사이」 확정안 (설계 방 · 2026-11-17)

선생님 말(설계 방에 직접): 「3분안에 끝나는 미니게임 기획해줘. 직관적이고 재미있으면 돼」 → 시안 → 「용이잠든사이 채택 진행해」 → 「꾹누르고 있는걸로.」(조작 = 꾹 누르기).
상태: ⏳ 아직 안 만듦 · 손발 요청은 메인이 보냄 · 아래 수치는 설계 방 처음 값(선생님이 바꿀 수 있음).

## 1. 한 줄 규칙
용이 잘 때 단추를 꾹 누르고 있으면 달리고, 용이 눈을 뜨면 손을 뗀다. 보물 상자에 먼저 닿으면 이긴다. (「무궁화 꽃이 피었습니다」 던전판)

## 2. 흐름 (2분 30초 · 시계가 저절로 · 리모컨 ⏭ 로 건너뜀)
| 순서 | 시간 | 내용 |
|---|---|---|
| 안내 | 10초 | 종합실 한 줄 규칙 + 3 · 2 · 1 |
| 1판 | 45초 | 잠 2~5초 ↔ 눈 뜸 1.5~3초 (무작위 반복) |
| 결과 | 10초 | 1~3등 승리 자세 |
| 2판 | 45초 | + 속임수: 눈꺼풀만 떨다 다시 잠(예고만 나오고 눈을 안 뜸 · 판마다 2~3번) |
| 결과 | 10초 | |
| 결승 | 30초 | 잠 1.5~3.5초 ↔ 눈 뜸 1.5~2.5초 · 속임수 있음 |
| 시상 | — | 세 판 합산 1~3등 + 「한 번도 안 걸린 용사」 · 리모컨 ■ 로 쉼터 복귀 |
판마다 모두 출발선에서 다시 시작. 한 판은 시간이 다 되거나 인원의 절반이 들어오면 끝.

| 학생 폰 | 큰 단추 하나 「👣 꾹 눌러 달리기」(화면 아래 절반 · 누르는 동안 단추가 눌린 모양 + 발자국 물결) · 위에 내 자리 막대(출발 ━●━ 상자) · 내 순위 「7 / 24」 · 용 상태 띠 「💤 자는 중」 / 「👁 눈 떴다! 손 떼!」(빨강) |
| 리모컨 | ▶ 시작 · ⏭ 다음 판 · ■ 끝내기 · 「들어옴 n / 인원」 |

## 4. 수치 (처음 값)
| 항목 | 값 |
|---|---|
| 결승선 | 60칸 |
| 누르고 있는 동안 | 초당 5칸(모두 같은 속도 → 승부 = 얼마나 늦게 떼고 빨리 다시 누르나) · 60칸 = 쉬지 않으면 12초 |
| 눈 뜨기 예고 | 0.6초 전 · 종합실 = 용 코 위 「…!」 + 눈꺼풀 떨림 · 폰 = 진동 한 번 |
| 눈 뜬 동안 누르고 있음(또는 새로 누름) | 불길에 맞음 → 10칸 뒤로(0칸 아래로는 안 감) · 맞음 그림 0.8초 동안 못 움직임 · 눈 뜬 한 번에 한 번만 밀림 |
| 판정 여유 | 눈 뜬 뒤 0.3초 안에 떼면 봐줌(지연 몫) · 맞은 뒤에는 손을 뗐다 다시 눌러야 달림 |
| 판 점수 | 들어온 순서대로 인원 − (순위 − 1) · 못 들어오면 끝 위치 칸 수 ÷ 60 × (인원 ÷ 2) 내림 |
| 최소 인원 | 2명(1명이면 「친구를 기다려요」) |

## 5. 보상
- 다른 쉼터 놀이와 같은 💎 양 · 규칙(하루 한도 100 포함): 합산 1~3등 + 「한 번도 안 걸린 용사」(세 판 모두 안 밀림 · 여러 명 가능). 양 = 손발이 지금 쉼터 놀이 값에 맞춤.
- 성적 · 기록 아님 · 대시보드에 안 남김.

## 6. 지킬 것 · 예외
| 상황 | 처리 |
|---|---|
| 걸림 | 탈락 없음 · 밀리기만(「틀려도 벌 없음」) · 「탈락 · 실패」 글자 없음 → 「앗 뜨거!」 |
| 이름 | 종합실에 이름 전부 표기(11/16 결정) · 걸린 학생을 따로 크게 띄우지 않음(용사가 밀리는 연출만) |
| 접속 끊김 | 용사는 그 자리에 그대로 + 📶✕ · 다시 들어오면 이어서(11/17 끊김 규칙) |
| 중간 입장 | 다음 판부터 |
| 판정 | 각 폰에서 함(용의 잠 · 눈 뜸 시각표를 판 시작 때 한꺼번에 내려보냄 · 서버 시각 기준) → 느린 와이파이에서도 같은 순간 |
| 집중 모드 · 수업 닫힘 | 놀이 즉시 끝 · 보상 없음 |
| 줄이기 모드 | 불길 · 흔들림 없이 밀리기만 |
| 소리 | 종합실만(발소리 · 용 코골이 · 눈 뜰 때 「쿵」) · 폰은 진동만 |
| 교사 시연 · 🧪 테스트 모드 · 체험판 | 같은 길 · 가상 친구가 같이 뜀(체험판 4명 · 교사 판 약 20명 · 가끔 걸림) |
| 학교판 | 그대로 켬(과목 내용 없음) |
| ⚙ 스위치 | 쉼터 놀이 묶음에 「🐉 쉼터 · 용이 잠든 사이」 · 처음 값 = 켬 |

## 7. 조작 = 꾹 누르기 (선생님 확정)
- 두드리기 판은 쓰지 않음(교실 연타 소리 · 책상 흔들림 없음).
- 손가락이 단추 밖으로 미끄러지면 = 뗀 것 · 두 손가락 · 다른 곳 누르기는 무시 · 화면 꺼짐 · 앱 전환 = 뗀 것.
- 속도가 모두 같아 순위가 붙어 나오므로 동점 = 같은 등수(보상도 같이).
