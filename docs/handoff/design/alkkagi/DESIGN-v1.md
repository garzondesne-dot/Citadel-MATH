## 1. 한 줄 규칙

**내 알을 당겼다 놓아 남의 알을 판 밖으로 떨어뜨린다. 쏘면 4초 쉬고, 떨어지면 3초 뒤 무적으로 돌아온다. 150초 동안 점수가 가장 높은 사람이 이긴다.**

## 2. 한 판의 흐름 (약 3분)

| 구간 | 시간 | 하는 일 |
|---|---|---|
| 모이기 | 방장이 「시작」 누를 때까지(2명부터) | 쉼터에서 방을 열고 친구가 들어옴 · 중간에 들어와도 됨 |
| 준비 | 5초 | 내 알 자리 보여 줌 |
| 진행 | 150초 | 실시간 · 각자 쿨타임마다 쏨 |
| 결과 | 15초 | 순위 · 보상 |

## 3. 규칙

1. **쏘기**: 내 알을 누르고 뒤로 당겼다 놓음(새총). 당긴 방향 반대로 날아가고, 당긴 길이 = 세기(약 · 중 · 강 3단).
2. **궤적 미리 보기**: 당기는 동안 내 폰에만 점선이 뜸 — 멈출 자리까지, 그리고 **처음 부딪히는 알과 그 알이 밀려갈 방향**까지. 점선이 판 밖으로 나가면 빨간색(「이대로 쏘면 떨어짐」).
3. **쿨타임 4초**: 쏜 뒤 4초 동안 못 쏨(내 알 둘레에 고리가 차오름). 이때 맞으면 그대로 밀림 — 쏘는 것이 곧 빈틈.
4. **떨어짐**: 알 중심이 판 밖으로 나가면 떨어짐 → 3초 뒤 빈자리에 되살아남.
5. **무적 2초**: 되살아난 알은 반투명 · 다른 알과 **서로 통과**(밀지도 밀리지도 않음). 2초가 지나거나 **내가 쏘는 순간** 끝남.
6. **점수**: 남의 알을 떨어뜨리면 **+3**(마지막으로 건드린 사람 · 3초 안) · 남의 알을 맞히기만 해도 **+1**. 혼자 떨어지면 점수는 그대로(3초 못 노는 것이 벌).
7. **👑 왕관**: 지금 1등 알에 왕관 표시 · 왕관 알을 떨어뜨리면 +3 대신 **+5**.
8. **가만히 있는 학생**: 저절로 쏘지 않음. 과녁이 될 뿐(떨어져도 다시 돌아옴).

읽는 법
- 한 사람이 150초에 28 ~ 30번 쏨(5초에 한 번) → 기다리는 느낌 없음.
- **인원이 많을수록 떨어뜨리기가 어려워짐**(판 둘레는 천천히 늘고 사람은 빨리 늘어 가운데 알은 가장자리에서 멂) → 28명 판에서는 14% 가 한 번도 못 떨어뜨림. 그래서 **맞히기만 해도 +1**(규칙 6)을 넣어 0점을 없앰.
- 혼자 떨어지는 비율 2 ~ 8% → 궤적 미리 보기가 있으면 더 줄어듦.
- 쿨타임 3초 = 더 정신없음 / 5초 = 한가함 → **4초**.
- 판 반지름 = 알 반지름의 약 8배(8명까지) ~ 12배(28명) : `max(5.5, 2 + 1.2 × √인원)` (알 반지름 0.7 기준).

## 5. 스스로 찾은 빈틈과 막은 법

| 빈틈 | 막은 법 |
|---|---|
| 되살아난 자리에서 바로 또 맞음 | 무적 2초 + 빈자리에 되살아남 |
| 무적인 동안 남을 밀고 다님 | 무적 = 서로 통과 · 쏘면 무적 끝 |
| 일부러 떨어져 위험한 자리에서 탈출 | 3초 못 놀고, 떨어뜨린 사람에게 점수가 감 |

| 1등이 계속 달아남 | 👑 왕관 알 = +5 → 저절로 몰림 |
| 친한 친구끼리 한 명 밀어 주기 | 하루 보상 3판 · 보상이 작음 → 굳이 할 까닭이 적음 |
| 한 학생만 계속 노림 | 무적 2초 + 떨어뜨려도 3초 뒤 돌아옴 · 같은 사람을 연달아 떨어뜨리면 두 번째부터 +1 만(제안) |
| 인터넷이 느린 학생이 불리 | 8절 「1초 박자」 방식이면 차이가 거의 없음 |

### 설계 방이 채운 것 (컨펌 전)
- 편 = 자동으로 반반(인원이 홀수면 적은 편이 먼저 쏨) · 같은 편 알끼리도 부딪힘(실수로 우리 편을 밀어 떨어뜨릴 수 있음 = 겨누는 데 집중).

- 점수 = 라운드 승패만(개인 점수 · 왕관 없음). 보상은 지금 규칙 그대로(이긴 편 · 참가).
- 안 고르면 제자리(쏘지 않음).
