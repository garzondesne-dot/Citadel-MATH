# 🧙 용사 세밀화 v4 · GPT 주문 카드 (🌊 설계 묶음 #1 · 2026-11-17 · 설계 방)

지킨 결정: DECISIONS 2026-11-17 「🧙 용사 세밀화 v4」 · 「🫁 숨쉬기만 PixelLab · 나머지 GPT」 · CLAUDE.md 「🎨 에셋 주문 = 그림 한 장 · 주문 한 장 · 붙여 넣기 한 번」.

## 규칙 3줄
1. **1줄 = 서 있는 1칸만**(가장 세밀하게 · PixelLab 숨쉬기의 기본 그림) · 반복 동작 낱말(breathing 등)은 주문에 없음.
2. **모든 칸 = 서로 다른 자세**(12줄 28칸) · 2칸짜리 줄은 두 칸의 다른 점을 글로 적음(눈 뜸 / 감음 · 뛰어오름 / 내려섬).
3. **카드 한 장 = 혼자 완결** · 첨부 3장(① 세밀 참고 로안 ② 그 용사 지금 시트 2배 ③ 그 용사 초상) · 다른 카드를 참고하지 않음.

## 파일
| 파일 | 무엇 |
|---|---|
| `cards.json` | 작업대 카드 33장 `{ id, name, use, prompt, ref[3] }` |
| `refs/` | 첨부 그림 33 × 2 = 66장 (`ref-v4-hNN-sheet-nb.png` 640×1536 투명 · `ref-v4-hNN-port.png` 256×256) |
| `gen_cards.py` | 카드 만들기(용사별 겉모습 · 공격 · 승리 · 힐 · 앉기 글이 여기 표에 있음) → `cards.json` · `heroes.json` |
| `make_refs.py` | 첨부 그림 만들기 `python3 make_refs.py <art/heroes 폴더>` |
| `heroes.json` | 번호 · 시트 파일 · 초상 칸 [열, 행] · 배경색 |

세밀 참고 `style-roan-v4.png` 는 작업대에 이미 있는 것을 그대로 씀(여기 없음).
원본 그림 = 정식 사이트 `art/heroes/`(베타 public/art/heroes 와 같은 파일 · 베타 저장소는 이 방에서 붙이기가 거절돼 정식 것으로 만듦 · 로안 2장은 작업대의 기존 첨부와 픽셀까지 같음).

## 로안 카드 다듬은 점 (선생님 컨펌 대상)
| # | 옛 카드 | 새 카드 | 까닭 |
|---|---|---|---|
| 1 | 긴 문단 5개 | 번호 붙은 규칙 4개(같은 디자인 · 더 고운 픽셀 · 칸 엄격 · 칸마다 다른 그림) + 줄 목록 | GPT 가 뒤쪽 조건을 놓치지 않게 |
| 2 | 「같은 자세 유지」와 「다른 자세로」가 떨어져 있음 | 「28칸 · 같은 그림을 두 번 붙이지 않음」을 규칙 4로 따로 | 선생님 말씀(반복 칸이 질을 낮춤) |
| 3 | 2칸 줄 = 「2 frames」 | 칸마다 (1) (2) 로 다른 점을 적음 · 12줄 둘째 칸 = 「몸을 펴며 이마 닦기」(옛 「어깨 올라감」은 첫 칸과 거의 같아 베끼기 쉬움) | 같은 까닭 |
| 4 | 캔버스 640×1536 만 적음 | + 「캔버스가 더 넓으면 시트는 왼쪽 끝 · 나머지는 배경색」 | GPT 는 1024×1536 으로 내놓는 일이 많음 |
| 5 | 승리 = 「칼을 높이」 | 지금 시트대로 「뛰어올라 주먹 → 내려서서 웃음」 | 「지금 자세 그대로」와 어긋나던 곳 |
| 6 | 맞음 · 쓰러짐 설명 한 낱말 | 눈 · 입 · 몸 방향까지 한 줄 | 칸이 비거나 선 자세로 나오는 것 막기 |

## 메인이 정할 것 · 알릴 것
| # | 무엇 | 설계 방 추천 |
|---|---|---|
| 1 | **카드 33장**(34 아님): 지금 판 용사 데이터에 16번이 없음(초상 「각성한 로안」 칸은 있으나 시트 없음). | 16번은 로안 시트 색 바꾸기로 따로(지금 방식 그대로면 주문 없음). |
| 2 | **배경색**: 지정대로 1 · 4 · 10 · 20 · 25 = 초록. 그런데 18 흑기사(진홍 망토 · 진홍 칼빛) · 24 마검사(보라 망토 · 보랏빛 마법진) · 33 별점술사(연보라 머리)도 마젠타와 가까움. | 세 명도 초록으로(`gen_cards.py` 의 `GREEN` 한 줄 · 자르기 쪽이 배경색을 용사별로 읽으면). |
| 3 | 초록 배경 용사의 힐 빛 = 「연한 민트 흰빛 + 짙은 청록 테두리」로 적음(초록 빛이 배경에 묻히지 않게). | 그대로. |
| 4 | **넓은 칸 안**(지금은 안 씀): GPT 결과가 1024×1536 으로 오면 칸을 256×128 로 넓히고 첨부 시트도 같은 비율로 주는 편이 칸을 더 잘 지킴(자르기 = 칸 가운데 160). | 로안 1장을 뽑아 본 뒤 칸이 어긋나면 그때. |
| 5 | 흑기사 = 투구를 벗지 않음(앉기 · 생각 · 헉헉도 자세와 눈빛으로) · 19 · 20 · 17 · 22 · 27 · 29 · 33 = 「글자 · 숫자 없음」 덧줄(지금 시트 힐 빛에 숫자가 보이는 용사가 있음). | 그대로. |
