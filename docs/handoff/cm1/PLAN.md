## 읽는 법

- ⏱ = 도입 3분 + 개념 5 ~ 6분씩 + 문항 형식별 시간(고르기 1.3 · 숫자 1.9 · ○✕ 0.7분, 산은 × 1.3) 으로 어림한 값 — 실제 수업으로 맞춰 봐야 함.
- 여유 + = 일찍 끝난 반 · 학생용 「여유 문제」 시간.
- 「산」 = 차시마다 1개. 본문에 어려운 문제가 있으면 그것, 없으면 중단원 마무리 수준에서 1개.
- 판 0 = 학습지에 실을 문항(시안), 판 1 ~ 6 = 숫자 바꾼 판.
