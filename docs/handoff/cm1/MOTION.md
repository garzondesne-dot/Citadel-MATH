## 1차시 · 다항식의 덧셈과 뺄셈 — 🎬 뺄셈 = 부호를 모두 바꿔 더하기

```

쓰는 곳: 1차시 개념 c2 설명

장면:

  3. 같은 차수끼리 세로로 줄이 맞춰진다.
  4. 세로로 더해 x³ + x² + 3x − 2 가 내려온다.
마지막 화면: A − B = A + (−B)
```

## 2차시 · 다항식의 곱셈과 곱셈 공식 — 🎬 (a + b)³ 은 왜 3이 붙을까

```
제목: (a + b)³ 은 왜 3이 붙을까
쓰는 곳: 2차시 개념 c2 설명
핵심 한 줄: (a + b)³ = (a + b)(a + b)² 를 분배하면 a²b 와 ab² 이 세 개씩 모인다.
장면:
  1. 카드에 (a + b)(a² + 2ab + b²) 가 뜬다.
  2. 커서가 a 를 끌어 뒤 식에 곱한다 → a³ + 2a²b + ab².
  3. 커서가 b 를 끌어 곱한다 → a²b + 2ab² + b³.
  4. 같은 색 항끼리 모여 3a²b, 3ab² 이 된다.
마지막 화면: (a + b)³ = a³ + 3a²b + 3ab² + b³
```
