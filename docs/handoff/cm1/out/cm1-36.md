# 36차시 · 행렬의 곱셈의 성질 — 시안 (공통수학1 · Ⅳ-1 행렬과 그 연산)

> 교과서 132 ~ 133쪽 · 목표: 행렬의 곱셈의 성질을 이해하고, 수의 곱셈과 다른 점을 설명할 수 있다.

## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 35차시: (i, j) 성분 = 제i행 × 제j열
- 💭 생각 열기: 수는 2 × 3 = 3 × 2. 행렬도 AB = BA 일까? 직접 곱해 보면 답이 나온다.
- 📘 c1 교환법칙은 성립하지 않는다: 일반적으로 AB ≠ BA. 결합법칙 (AB)C = A(BC), 분배법칙 A(B + C) = AB + AC 는 성립한다. 그래서 (A + B)² = A² + AB + BA + B². · ✔ 개념 체크: 모든 정사각행렬 A, B 에 대하여 AB = BA 이다. → X
- 📘 c2 단위행렬 E 와 거듭제곱: E = (1  0 ; 0  1) 은 AE = EA = A (수의 1 과 같은 역할). A² = AA, A³ = A²A. · ✔ 개념 체크: A² 은 A 의 각 성분을 제곱한 행렬이다. → X

- 👾 m1 문제 1 · AB 와 BA (⏱ 3.6분)
  - (m1-1) [number] A = (1  2 ; 0  1), B = (1  0 ; 3  1) 일 때, BA 의 (1, 1) 성분은? (AB 가 아니라 BA 임에 주의) (; 는 행을 나누는 표시)  → **1** · B 의 제1행과 A 의 제1열: 1 × 1 + 0 × 0.
  - (m1-2) [ox] A = (1  2 ; 0  1), B = (1  0 ; 3  1) 일 때, AB = BA 이다. (; 는 행을 나누는 표시)  → **X** · AB = (7  2 ; 3  1), BA = (1  2 ; 3  7) → 다르다 (곱셈은 순서를 바꾸면 달라질 수 있다).
- 👾 m2 문제 2 · A² 과 단위행렬 (⏱ 4.2분)
  - (m2-1) [number] A = (2  1 ; −1  3) 일 때, A² = AA 의 (1, 2) 성분은? (; 는 행을 나누는 표시)  → **5** · A 의 제1행과 A 의 제2열: 2 × 1 + 1 × 3. (성분을 제곱하는 것이 아니다)
  - (m2-2) [choice] A = (2  −3 ; 4  5), E = (1  0 ; 0  1) 일 때, AE 는? (; 는 행을 나누는 표시)  〔보기: (3  −3 ; 4  6) / (2  −3 ; 4  5) / (2  0 ; 0  5) / (1  0 ; 0  1)〕  → **(2  −3 ; 4  5)** · E 는 단위행렬 — 수의 1 처럼, 곱해도 A 가 그대로다 (AE = EA = A).
- 👾 m3 문제 3 · 성립하는 법칙 가리기 (⏱ 3.6분)
  - (m3-1) [number] A = (1  2 ; 3  4), B = (2  0 ; 1  1), C = (−1  1 ; 0  2) 일 때, AB + AC 의 (1, 1) 성분은? (; 는 행을 나누는 표시)  → **3** · AB + AC = A(B + C). B + C = (1  1 ; 1  3) 를 먼저 구해 한 번만 곱한다.
  - (m3-2) [ox] 곱셈을 할 수 있는 정사각행렬 A, B, C 에 대하여 「(A + B)² = A² + 2AB + B²」 는 항상 성립한다.  → **X** · (A + B)² = A² + AB + BA + B². AB 와 BA 가 다를 수 있어 2AB 로 묶지 못한다.
- 👾 m4 문제 4 · 거듭제곱의 규칙 ⛰ (⏱ 5.9분)
  - (m4-1) [number] A = (1  2 ; 0  1) 일 때, A² 의 (1, 2) 성분은? (; 는 행을 나누는 표시)  → **4** · 제1행 (1  2) 와 제2열 (2, 1): 1 × 2 + 2 × 1 = 4.
  - (m4-2) [number] A = (1  2 ; 0  1) 일 때, A², A³ 을 구해 규칙을 찾으면 A 를 10번 곱한 행렬의 (1, 2) 성분은? (; 는 행을 나누는 표시)  → **20** · (1, 2) 성분이 2, 4, 6, … 로 2 씩 변한다 → 10 × 2.
- 👾 m5 🌱 여유 문제 · 곱이 영행렬 (⏱ 1.7분)
  - (m5-1) [ox] A = (1  0 ; 2  0), B = (0  0 ; 1  3) 일 때, AB 는 모든 성분이 0 인 영행렬이다. (; 는 행을 나누는 표시)  → **O** · A ≠ O, B ≠ O 인데 AB = O 가 될 수 있다 — 수의 곱셈과 다른 점.
- 👑 형성평가 4문항 (⏱ 7.8분) · 짝 = ['m1', 'm2', 'm2', 'm3']
  - (b-1) [number] A = (1  2 ; 0  1), B = (1  0 ; 3  1) 일 때, BA 의 (1, 1) 성분은? (AB 가 아니라 BA 임에 주의) (; 는 행을 나누는 표시)  → **1** · B 의 제1행과 A 의 제1열: 1 × 1 + 0 × 0.
  - (b-2) [number] A = (2  1 ; −1  3) 일 때, A² = AA 의 (1, 2) 성분은? (; 는 행을 나누는 표시)  → **5** · A 의 제1행과 A 의 제2열: 2 × 1 + 1 × 3. (성분을 제곱하는 것이 아니다)
  - (b-3) [choice] A = (2  −3 ; 4  5), E = (1  0 ; 0  1) 일 때, AE 는? (; 는 행을 나누는 표시)  〔보기: (3  −3 ; 4  6) / (1  0 ; 0  1) / (2  0 ; 0  5) / (2  −3 ; 4  5)〕  → **(2  −3 ; 4  5)** · E 는 단위행렬 — 수의 1 처럼, 곱해도 A 가 그대로다 (AE = EA = A).
  - (b-4) [ox] 곱셈을 할 수 있는 정사각행렬 A, B, C 에 대하여 「(A + B)² = A² + 2AB + B²」 는 항상 성립한다.  → **X** · (A + B)² = A² + AB + BA + B². AB 와 BA 가 다를 수 있어 2AB 로 묶지 못한다.
