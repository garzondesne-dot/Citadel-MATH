## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 4차시: A = BQ + R · 방정식과 항등식 구별(중학교): 2x + 3 = 5 는 방정식
- 💭 생각 열기: 봉지를 2장씩 x명에게, 3명이 더 오면? 2x + 6 = 2(x + 3) — x 가 무엇이든 늘 맞는 등식.
- 📘 c1 항등식의 성질: ax² + bx + c = 0 이 항등식 ⟺ a = b = c = 0 · ax² + bx + c = a′x² + b′x + c′ 이 항등식 ⟺ 계수가 각각 같다. · ✔ 개념 체크: 등식 2x + 3 = 5 는 x에 대한 항등식이다. → X
- 📘 c2 미정계수법 (계수 비교 · 수 대입): 모르는 계수를 정하는 두 방법: ① 양변을 정리해 같은 차수의 계수를 비교 ② 식이 간단해지는 수를 x에 대입.

- 👾 m1 문제 1 · 항등식 찾기 (⏱ 4.5분)
  - (m1-1) [multi] x에 대한 항등식인 것을 모두 고르시오.  〔보기: 2x + 6 = 2(x + 3) / 2x + 3 = 5 / (x + 3)² = x² + 6x + 9 / x² = 3x〕  → **2x + 6 = 2(x + 3) · (x + 3)² = x² + 6x + 9** · 항등식 = x에 어떤 값을 넣어도 성립 · 양변을 정리하면 똑같은 식이 된다.
  - (m1-2) [number] 등식 (a − 2)x + (b + 1) = 0 이 x에 대한 항등식일 때, a + b 의 값은? (a, b 는 상수)  → **1** · x의 계수와 상수항이 모두 0 → a = 2, b = −1.
- 👾 m2 문제 2 · 계수 비교하기 (⏱ 4.8분)
  - (m2-1) [number] 등식 ax² + bx + 1 = (2x − 1)(x + 1) + c 가 x에 대한 항등식이다 (a, b, c 는 상수). b 의 값은?  → **1** · 우변의 x 계수 = 2 + (−1) → 양변의 x 계수를 비교.
  - (m2-2) [number] 등식 ax² + bx + 1 = (2x − 1)(x + 1) + c 가 x에 대한 항등식이다 (a, b, c 는 상수). c 의 값은?  → **2** · 상수항 비교: 1 = (−1) + c.
- 👾 m3 문제 3 · 수 대입하기 (⏱ 4.8분)
  - (m3-1) [number] 등식 a(x − 1)² + b(x − 1) + c = x² + 5x 이 x에 대한 항등식이다 (a, b, c 는 상수). 양변에 x = 1 을 대입하여 c 의 값을 구하면?  → **6** · x = 1 이면 좌변은 c 만 남고, 우변은 6.
  - (m3-2) [number] 등식 a(x − 1)² + b(x − 1) + c = x² + 5x 이 x에 대한 항등식이다 (a, b, c 는 상수). b 의 값은?  → **7** · x 의 계수 비교: −2 + b = 5.
- 👾 m4 문제 4 · 세 수를 차례로 대입 ⛰ (⏱ 10.1분)
  - (m4-1) [number] 등식 2x(x − 1) + ax(x + 1) + b(x + 1)(x − 1) = cx² + 3ax − 1 이 x에 대한 항등식이다 (a, b, c 는 상수). 양변에 x = 0 을 대입하여 b 의 값을 구하면?  → **1** · x = 0: 좌변 = b × 1 × (−1) = −b, 우변 = −1.
  - (m4-2) [choice] 등식 2x(x − 1) + ax(x + 1) + b(x + 1)(x − 1) = cx² + 3ax − 1 이 x에 대한 항등식이다 (a, b, c 는 상수). 양변에 x = 1 을 대입한 식은?  〔보기: a = c + 3a − 1 / 2a = c + 3a − 1 / 2a = c + 3a + 1 / 2a + b = c + 3a − 1〕  → **2a = c + 3a − 1** · x = 1: x − 1 = 0 인 항이 사라지고 a × 1 × 2 = 2a 만 남는다.
  - (m4-3) [number] 등식 2x(x − 1) + ax(x + 1) + b(x + 1)(x − 1) = cx² + 3ax − 1 이 x에 대한 항등식이다 (a, b, c 는 상수). 양변에 x = −1 을 대입하면 좌변의 값은?  → **4** · x = −1: x + 1 = 0 인 항이 사라지고 2x(x − 1) 에서 (−2) × (−2) = 4.
  - (m4-4) [number] 등식 2x(x − 1) + ax(x + 1) + b(x + 1)(x − 1) = cx² + 3ax − 1 이 x에 대한 항등식이다 (a, b, c 는 상수). a 의 값은?  → **-1** · x = 1 과 x = −1 을 대입한 두 식을 연립한다 → a = −1, c = 2.
- 👾 m5 🌱 여유 문제 · 연속하는 세 수의 곱 (⏱ 2.3분)
  - (m5-1) [choice] 연속하는 세 자연수 x − 1, x, x + 1 의 곱에 가운데 수 x 를 더한 식 (x − 1)x(x + 1) + x 를 정리하면?  〔보기: x³ + 2x / x³ + x / x³ − x / x³〕  → **x³** · (x − 1)(x + 1) = x² − 1 → x(x² − 1) + x = x³ − x + x.
- 👑 형성평가 4문항 (⏱ 9.6분) · 짝 = ['m1', 'm2', 'm3', 'm4']
  - (b-1) [number] 등식 (a − 2)x + (b + 1) = 0 이 x에 대한 항등식일 때, a + b 의 값은? (a, b 는 상수)  → **1** · x의 계수와 상수항이 모두 0 → a = 2, b = −1.
  - (b-2) [number] 등식 ax² + bx + 1 = (2x − 1)(x + 1) + c 가 x에 대한 항등식이다 (a, b, c 는 상수). b 의 값은?  → **1** · 우변의 x 계수 = 2 + (−1) → 양변의 x 계수를 비교.
  - (b-3) [number] 등식 a(x − 1)² + b(x − 1) + c = x² + 5x 이 x에 대한 항등식이다 (a, b, c 는 상수). 양변에 x = 1 을 대입하여 c 의 값을 구하면?  → **6** · x = 1 이면 좌변은 c 만 남고, 우변은 6.
  - (b-4) [number] 등식 2x(x − 1) + ax(x + 1) + b(x + 1)(x − 1) = cx² + 3ax − 1 이 x에 대한 항등식이다 (a, b, c 는 상수). 양변에 x = 0 을 대입하여 b 의 값을 구하면?  → **1** · x = 0: 좌변 = b × 1 × (−1) = −b, 우변 = −1.
