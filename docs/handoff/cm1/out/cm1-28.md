## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 27차시: 합의 법칙 · 곱의 법칙 · 중학교: 소인수분해
- 💭 생각 열기: 약수가 몇 개인지 다 쓰지 않고 세는 법? 지수를 고르는 「곱의 법칙」.
- 📘 c1 약수의 개수 · 자연수 만들기: N = pᵃ × qᵇ 의 양의 약수의 개수 = (a + 1)(b + 1). 자릿수 문제는 제한이 큰 자리(맨 앞 0 불가 · 일의 자리 조건)부터 정한다. · ✔ 개념 체크: 12 = 2² × 3 의 양의 약수는 2 × 1 = 2 개이다. → X
- 📘 c2 색칠 · 길 고르기: 이웃한 칸을 다르게 칠하기 = 앞 칸의 색만 피한다. 길 고르기 = 잇달아 가면 곱, 갈라지는 경로는 합.

- 👾 m1 문제 1 · 약수의 개수 (⏱ 4.2분)
  - (m1-1) [choice] 72 을 소인수분해 하면?  〔보기: 2³ × 5² / 2² × 3³ / 2⁴ × 3 / 2³ × 3²〕  → **2³ × 3²** · 2 로 나누어떨어질 때까지, 그다음 3 으로.
  - (m1-2) [number] 72 = 2³ × 3² 의 양의 약수의 개수는?  → **12** · 2 의 지수 0 ~ 3 (4가지) × 3 의 지수 0 ~ 2 (3가지).
- 👾 m2 문제 2 · 세 자리 자연수 만들기 (⏱ 4.8분)
  - (m2-1) [number] 숫자 0, 1, 2, 3 가 하나씩 적힌 카드 4장 중에서 서로 다른 3장을 뽑아 만들 수 있는 세 자리 자연수의 개수는?  → **18** · 백의 자리(0 제외) 3가지 × 십의 자리 3가지 × 일의 자리 2가지.
  - (m2-2) [number] 숫자 0, 1, 2, 3 가 하나씩 적힌 카드 4장 중에서 서로 다른 3장을 뽑아 만들 수 있는 세 자리 자연수 중 짝수의 개수는?  → **10** · 일의 자리가 0 인 경우와 0 이 아닌 짝수인 경우로 나누어 센 뒤 더한다(백의 자리에 0 불가).
- 👾 m3 문제 3 · 색칠하기 (⏱ 4.8분)
  - (m3-1) [number] 한 줄로 나란히 붙어 있는 4개의 칸을 3가지 색으로 칠하려고 한다. 같은 색을 여러 번 써도 되지만 이웃한 칸은 서로 다른 색으로 칠하는 방법의 수는?  → **24** · 첫 칸 3가지, 그다음 칸부터는 앞 칸과 다른 2가지씩 → 3 × 2³.
  - (m3-2) [number] 3개의 칸을 4가지 색 중에서 골라 모두 서로 다른 색으로 칠하는 방법의 수는?  → **24** · 4 × 3 × 2 — 한 번 쓴 색은 다시 못 쓴다.
- 👾 m4 문제 4 · 길 고르기 (⏱ 6.7분)
  - (m4-1) [number] 집에서 서점으로 가는 길이 3가지, 서점에서 학교로 가는 길이 2가지, 집에서 학교로 바로 가는 길이 2가지 있다. 집에서 서점을 거쳐 학교로 가는 방법의 수는?  → **6** · 잇달아 일어난다 → 3 × 2.
  - (m4-2) [number] 집에서 서점으로 가는 길이 3가지, 서점에서 학교로 가는 길이 2가지, 집에서 학교로 바로 가는 길이 2가지 있다. 집에서 학교로 가는 방법의 수는? (서점을 거쳐도 되고 바로 가도 된다)  → **8** · 서점을 거치는 6가지 + 바로 가는 2가지 (동시에 일어나지 않음).
  - (m4-3) [number] 집에서 서점으로 가는 길이 3가지, 서점에서 학교로 가는 길이 2가지, 집에서 학교로 바로 가는 길이 2가지 있다. 집에서 서점을 거쳐 학교에 갔다가, 서점을 거치지 않고 바로 집으로 돌아오는 방법의 수는?  → **12** · 가는 방법 6가지 × 돌아오는 방법 2가지.
- 👾 m5 🌱 여유 문제 · 소인수가 셋인 수 (⏱ 2.9분)
  - (m5-1) [number] 90 = 2 × 3² × 5 의 양의 약수의 개수는?  → **12** · (1 + 1)(2 + 1)(1 + 1).
- 👑 형성평가 4문항 (⏱ 9.6분) · 짝 = ['m1', 'm2', 'm3', 'm4']

  - (b-2) [number] 숫자 0, 1, 2, 3 가 하나씩 적힌 카드 4장 중에서 서로 다른 3장을 뽑아 만들 수 있는 세 자리 자연수의 개수는?  → **18** · 백의 자리(0 제외) 3가지 × 십의 자리 3가지 × 일의 자리 2가지.
  - (b-3) [number] 한 줄로 나란히 붙어 있는 4개의 칸을 3가지 색으로 칠하려고 한다. 같은 색을 여러 번 써도 되지만 이웃한 칸은 서로 다른 색으로 칠하는 방법의 수는?  → **24** · 첫 칸 3가지, 그다음 칸부터는 앞 칸과 다른 2가지씩 → 3 × 2³.
