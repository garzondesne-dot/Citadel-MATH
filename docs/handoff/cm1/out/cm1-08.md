# 8차시 · 인수분해 공식 — 시안 (공통수학1 · Ⅰ-2 나머지정리와 인수분해)

> 교과서 32 ~ 33쪽 · 목표: 인수분해 공식을 이용하여 다항식을 인수분해 할 수 있다.
> ⏱ 예상 39.4분(여유 문제 빼고) · 여유 문제 +2.3분 · 어려운 문제(산) = m4 · 산 = 본문 33쪽 문제 2 ⑴ 꼴(이미 어려운 문제가 있어 중단원에서 안 가져옴)
> 문항 105줄(판 0 ~ 6) · 계산 검산 ✅ 105 · 눈으로 확인 0 · ❌ 0 · 글 검사 걸림 0 · 같은 판 0

## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 2차시 곱셈 공식 세 줄 · 중학교 인수분해: x² + 5x + 6 = (x + 2)(x + 3)
- 💭 생각 열기: 곱셈 공식을 거꾸로 읽으면 인수분해 공식 — 전개의 되감기.
- 📘 c1 인수분해 공식: a² + b² + c² + 2ab + 2bc + 2ca = (a + b + c)² · a³ ± 3a²b + 3ab² ± b³ = (a ± b)³ · a³ ± b³ = (a ± b)(a² ∓ ab + b²). · ✔ 개념 체크: a³ + b³ = (a + b)³ 이다. → X
- 📘 c2 공통부분을 한 문자로: 공식을 바로 쓸 수 없으면 되풀이되는 부분을 X 로 놓고 인수분해 한 뒤 원래 식으로 되돌린다(되돌린 뒤 더 인수분해 되는지 확인).

- 👾 m1 문제 1 · 세제곱 꼴 (⏱ 3.6분)
  - (m1-1) [choice] x³ − 6x² + 12x − 8 을 인수분해 하면?  〔보기: (x + 2)³ / (x − 2)³ / (x − 8)³ / (x − 2)(x² + 2x + 4)〕  → **(x − 2)³** · x³ ± 3·x²·2 + 3·x·4 ± 8 꼴 = (x ± 2)³.
  - (m1-2) [choice] a³ + 9a²b + 27ab² + 27b³ 을 인수분해 하면?  〔보기: (a + 27b)³ / (3a + b)³ / (a + 3b)³ / (a − 3b)³〕  → **(a + 3b)³** · 양 끝이 (a)³ 과 (3b)³ — 가운데 두 항의 계수로 확인한다.
- 👾 m2 문제 2 · a³ ± b³ (⏱ 3.6분)
  - (m2-1) [choice] x³ − 1 을 인수분해 하면?  〔보기: (x − 1)³ / (x − 1)(x² + x + 1) / (x − 1)(x² − x + 1) / (x + 1)(x² + x + 1)〕  → **(x − 1)(x² + x + 1)** · a³ − b³ = (a − b)(a² + ab + b²), b = 1.
  - (m2-2) [choice] 27x³ + y³ 을 인수분해 하면?  〔보기: (3x + y)(9x² + 3xy + y²) / (3x − y)(9x² − 3xy + y²) / (3x + y)³ / (3x + y)(9x² − 3xy + y²)〕  → **(3x + y)(9x² − 3xy + y²)** · (3x)³ 과 (y)³ 으로 보고 공식에 넣는다(가운데 항 부호 반대).
- 👾 m3 문제 3 · 세 항의 제곱 · 공통부분 (⏱ 4.9분)
  - (m3-1) [choice] x² + y² + z² + 2xy − 2yz − 2xz 을 인수분해 하면?  〔보기: (x + y − z)² / (x − y − z)² / (x + y + z)² / (x − y + z)²〕  → **(x + y − z)²** · xy, yz, zx 항의 부호로 y, z 의 부호를 정한다(둘 다 음수인 문자가 − 이다).
  - (m3-2) [choice] (a + b)² + 6(a + b) + 5 에서 a + b = X 로 놓으면?  〔보기: 2X² + 6X + 5 / X² + 6X + 5 / X² + 6X − 5 / X² + 5X + 6〕  → **X² + 6X + 5** · 똑같이 들어 있는 a + b 를 한 문자로 바꾸면 X 에 대한 이차식.
  - (m3-3) [choice] (a + b)² + 6(a + b) + 5 를 인수분해 하면?  〔보기: (a + b + 2)(a + b + 4) / (a + b + 1)(a + b + 5) / (a + b − 1)(a + b − 5) / (a + b + 1)(a + b − 5)〕  → **(a + b + 1)(a + b + 5)** · X² 꼴을 (X + 1)(X + 5) 로 인수분해 한 뒤 X 를 a + b 로 되돌린다.
- 👾 m4 문제 4 · 공통부분을 놓고 끝까지 ⛰ (⏱ 6.1분)
  - (m4-1) [choice] (x² + 3x)(x² + 3x − 1) − 6 에서 x² + 3x = X 로 놓고 전개하면?  〔보기: X² − X + 6 / X² − 6 / X² − X − 6 / X² + X − 6〕  → **X² − X − 6** · X(X − 1) − 6 를 전개한다.
  - (m4-2) [choice] X² − X − 6 을 인수분해 하면?  〔보기: (X + 3)(X + 2) / (X + 3)(X − 2) / (X − 3)(X − 2) / (X − 3)(X + 2)〕  → **(X − 3)(X + 2)** · 곱이 −6, 합이 −1 인 두 수 = −3, 2.
  - (m4-3) [choice] (x² + 3x)(x² + 3x − 1) − 6 를 인수분해 하면?  〔보기: (x² + 3x − 3)(x − 1)(x − 2) / (x² + 3x + 3)(x − 1)(x − 2) / (x² + 3x − 3)(x² + 3x + 2)² / (x² + 3x − 3)(x + 1)(x + 2)〕  → **(x² + 3x − 3)(x + 1)(x + 2)** · X 를 되돌리면 (x² + 3x − 3)(x² + 3x + 2) — 뒤 괄호는 한 번 더 인수분해 된다.
- 👾 m5 🌱 여유 문제 · 수 계산에 쓰기 (⏱ 2.3분)
  - (m5-1) [choice] 98³ + 3 × 98² × 2 + 3 × 98 × 4 + 8 의 값은?  〔보기: 941200 / 10000 / 1000000 / 1000001〕  → **1000000** · a³ + 3a²b + 3ab² + b³ = (a + b)³ 꼴 → (98 + 2)³ = 100³.
- 👑 형성평가 4문항 (⏱ 7.2분) · 짝 = ['m1', 'm2', 'm3', 'm3']
  - (b-1) [choice] x³ − 6x² + 12x − 8 을 인수분해 하면?  〔보기: (x + 2)³ / (x − 2)³ / (x − 2)(x² + 2x + 4) / (x − 8)³〕  → **(x − 2)³** · x³ ± 3·x²·2 + 3·x·4 ± 8 꼴 = (x ± 2)³.
  - (b-2) [choice] x³ − 1 을 인수분해 하면?  〔보기: (x − 1)(x² − x + 1) / (x − 1)(x² + x + 1) / (x + 1)(x² + x + 1) / (x − 1)³〕  → **(x − 1)(x² + x + 1)** · a³ − b³ = (a − b)(a² + ab + b²), b = 1.
  - (b-3) [choice] x² + y² + z² + 2xy − 2yz − 2xz 을 인수분해 하면?  〔보기: (x + y − z)² / (x − y + z)² / (x + y + z)² / (x − y − z)²〕  → **(x + y − z)²** · xy, yz, zx 항의 부호로 y, z 의 부호를 정한다(둘 다 음수인 문자가 − 이다).
  - (b-4) [choice] (a + b)² + 6(a + b) + 5 를 인수분해 하면?  〔보기: (a + b + 1)(a + b − 5) / (a + b − 1)(a + b − 5) / (a + b + 1)(a + b + 5) / (a + b + 2)(a + b + 4)〕  → **(a + b + 1)(a + b + 5)** · X² 꼴을 (X + 1)(X + 5) 로 인수분해 한 뒤 X 를 a + b 로 되돌린다.
