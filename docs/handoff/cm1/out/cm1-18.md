## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 중학교: y = a(x − p)² + q 의 꼭짓점 · 완전제곱식 만들기
- 💭 생각 열기: 불꽃의 최고 높이처럼, x 의 범위가 정해지면 최댓값 · 최솟값은 꼭짓점과 양 끝에서 정해진다.
- 📘 c1 실수 전체에서의 최대 · 최소: y = a(x − p)² + q: a > 0 이면 최솟값 q(최댓값 없음), a < 0 이면 최댓값 q(최솟값 없음). · ✔ 개념 체크: 이차함수 y = −(x − 1)² + 4 의 최솟값은 4 이다. → X
- 📘 c2 제한된 범위 α ≤ x ≤ β 에서의 최대 · 최소: 꼭짓점의 x좌표 p 가 범위 안이면 f(α), f(p), f(β) 중에서, 범위 밖이면 f(α), f(β) 중에서 가장 큰 값 · 작은 값.

- 👾 m1 문제 1 · 꼴 고치기와 최대 · 최소 (⏱ 3.6분)
  - (m1-1) [choice] 이차함수 y = x² − 4x + 1 을 y = a(x − p)² + q 꼴로 고치면?  〔보기: y = (x + 2)² − 3 / y = (x − 2)² − 3 / y = (x − 2)² + 1 / y = (x − 2)² + 3〕  → **y = (x − 2)² − 3** · 완전제곱식으로 고친다: x 의 계수의 절반을 제곱해 더하고 뺀다.
  - (m1-2) [choice] x 가 실수 전체일 때, 이차함수 y = x² − 4x + 1 의 최댓값 · 최솟값은?  〔보기: 최댓값 −3 (최솟값은 없다) / 최솟값 2 (최댓값은 없다) / 최댓값 2, 최솟값 −3 / 최솟값 −3 (최댓값은 없다)〕  → **최솟값 −3 (최댓값은 없다)** · y = (x − 2)² − 3 → 아래로 볼록, 꼭짓점 (2, −3).
- 👾 m2 문제 2 · 범위가 있을 때 (⏱ 6.1분)
  - (m2-1) [choice] 1 ≤ x ≤ 5 일 때, 이차함수 y = x² − 4x + 1 의 꼭짓점의 x좌표 2 는 이 범위에 포함되는가?  〔보기: 포함된다 / 포함되지 않는다 / 알 수 없다〕  → **포함된다** · 1 ≤ 2 ≤ 5 이 성립한다 → 꼭짓점 값도 후보.
  - (m2-2) [number] 1 ≤ x ≤ 5 일 때, 이차함수 y = x² − 4x + 1 의 최댓값은?  → **6** · f(1) = −2, f(5) = 6, 꼭짓점 −3 중 가장 큰 값.
  - (m2-3) [number] 1 ≤ x ≤ 5 일 때, 이차함수 y = x² − 4x + 1 의 최솟값은?  → **-3** · f(1) = −2, f(5) = 6, 꼭짓점 −3 중 가장 작은 값.
- 👾 m3 문제 3 · 범위가 있을 때 한 번 더 (⏱ 4.8분)
  - (m3-1) [number] 0 ≤ x ≤ 3 일 때, 이차함수 y = −x² + 6x + 7 의 최댓값은?  → **16** · y = −(x − 3)² + 16 · 꼭짓점 x = 3 ∈ 범위 · 끝값 7, 16.
  - (m3-2) [number] −1 ≤ x ≤ 2 일 때, 이차함수 y = 3x² − 6x − 1 의 최솟값은?  → **-4** · y = 3(x − 1)² − 4 · 꼭짓점 x = 1 ∈ 범위 · 끝값 8, −1.
- 👾 m4 문제 4 · 최댓값으로 k 찾기 ⛰ (⏱ 6.9분)
  - (m4-1) [choice] 0 ≤ x ≤ 3 일 때, 이차함수 y = x² − 4x + k 의 최댓값이 7 이다 (k 는 상수). 이 함수의 그래프는 아래로 볼록하고 꼭짓점의 x좌표는 2 이다. 최댓값은 x 가 얼마일 때인가?  〔보기: x = 3 / x = 0 / x = 2 / x = 1〕  → **x = 0** · 아래로 볼록 → 꼭짓점에서 멀수록 값이 크다. 2 에서 더 먼 끝은 0.
  - (m4-2) [choice] 0 ≤ x ≤ 3 일 때, 이차함수 y = x² − 4x + k 의 최댓값이 7 이다 (k 는 상수). x = 0 을 대입하여 세운 식은?  〔보기: 0 + k = 7 / 0 − k = 7 / −4 + k = 7 / 1 + k = 7〕  → **0 + k = 7** · (0)² − 4 × (0) + k = 7.
  - (m4-3) [number] 0 ≤ x ≤ 3 일 때, 이차함수 y = x² − 4x + k 의 최댓값이 7 이다 (k 는 상수). k 의 값은?  → **7** · x = 0 일 때 최대: 0 + k = 7.
- 👾 m5 🌱 여유 문제 · 같은 함수의 최솟값 (⏱ 2.9분)
  - (m5-1) [number] 0 ≤ x ≤ 3 일 때, 이차함수 y = x² − 4x + 7 의 최솟값은?  → **3** · 꼭짓점 x = 2 가 범위 안 → 최솟값 = 꼭짓점의 y좌표.
- 👑 형성평가 4문항 (⏱ 9.0분) · 짝 = ['m1', 'm2', 'm2', 'm3']
  - (b-1) [choice] x 가 실수 전체일 때, 이차함수 y = x² − 4x + 1 의 최댓값 · 최솟값은?  〔보기: 최댓값 −3 (최솟값은 없다) / 최솟값 2 (최댓값은 없다) / 최댓값 2, 최솟값 −3 / 최솟값 −3 (최댓값은 없다)〕  → **최솟값 −3 (최댓값은 없다)** · y = (x − 2)² − 3 → 아래로 볼록, 꼭짓점 (2, −3).
  - (b-2) [number] 1 ≤ x ≤ 5 일 때, 이차함수 y = x² − 4x + 1 의 최댓값은?  → **6** · f(1) = −2, f(5) = 6, 꼭짓점 −3 중 가장 큰 값.
  - (b-3) [number] 1 ≤ x ≤ 5 일 때, 이차함수 y = x² − 4x + 1 의 최솟값은?  → **-3** · f(1) = −2, f(5) = 6, 꼭짓점 −3 중 가장 작은 값.
  - (b-4) [number] −1 ≤ x ≤ 2 일 때, 이차함수 y = 3x² − 6x − 1 의 최솟값은?  → **-4** · y = 3(x − 1)² − 4 · 꼭짓점 x = 1 ∈ 범위 · 끝값 8, −1.
