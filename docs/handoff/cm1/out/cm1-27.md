# 27차시 · 합의 법칙과 곱의 법칙 — 시안 (공통수학1 · Ⅲ-1 경우의 수)

> 교과서 102 ~ 104쪽 · 목표: 합의 법칙과 곱의 법칙을 이해하고, 경우의 수를 구할 수 있다.
> ⏱ 예상 46.4분(여유 문제 빼고) · 여유 문제 +2.9분 · 어려운 문제(산) = m4 · 산 = 중단원 마무리 09번 꼴(주사위 3개 · 본문에 어려운 문제가 없어 가져옴)
> 문항 98줄(판 0 ~ 6) · 계산 검산 ✅ 98 · 눈으로 확인 0 · ❌ 0 · 글 검사 걸림 0 · 같은 판 0

## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 중학교: 경우의 수 · 「또는」은 더하고 「그리고(동시에)」는 곱한다
- 💭 생각 열기: 패턴 암호는 몇 가지일까? 빠짐없이 · 겹치지 않게 세는 두 가지 규칙.
- 📘 c1 합의 법칙: 두 사건 A, B 가 동시에 일어나지 않을 때, A 또는 B 가 일어나는 경우의 수 = m + n. · ✔ 개념 체크: 1 부터 10 까지의 자연수 중 2 의 배수 또는 3 의 배수의 개수는 5 + 3 = 8 이다. → X
- 📘 c2 곱의 법칙: 사건 A 가 m 가지, 그 각각에 대하여 사건 B 가 n 가지로 일어날 때, A, B 가 잇달아(동시에) 일어나는 경우의 수 = m × n.

- 👾 m1 문제 1 · 합의 법칙 (⏱ 4.8분)
  - (m1-1) [number] 서로 다른 주사위 두 개를 동시에 던질 때, 나오는 눈의 수의 합이 4 또는 7 인 경우의 수는?  → **9** · 합이 4 인 경우 3가지, 7 인 경우 6가지 — 동시에 일어나지 않으므로 더한다.
  - (m1-2) [number] 1 부터 27 까지의 자연수 중에서 4 의 배수 또는 7 의 배수의 개수는?  → **9** · 4 의 배수 6개, 7 의 배수 3개 — 27 이하에서 겹치는 수(28 의 배수)가 없으므로 더한다.
- 👾 m2 문제 2 · 곱의 법칙 (⏱ 4.8분)
  - (m2-1) [number] 상의 3벌, 하의 4벌 가 있을 때, 하나씩 골라 입는 방법의 수는?  → **12** · 3 × 4 — 상의마다 하의를 모두 고를 수 있다(동시에 일어남 → 곱).
  - (m2-2) [number] (x + y)(a + b + c) 를 전개했을 때 생기는 항의 개수는?  → **6** · 앞 괄호의 2개 항마다 뒤 괄호의 3개 항과 곱해진다 → 2 × 3.
- 👾 m3 문제 3 · 순서쌍의 개수 (⏱ 4.8분)
  - (m3-1) [number] 음이 아닌 정수 x, y 에 대하여 x + y ≤ 3 을 만족시키는 순서쌍 (x, y) 의 개수는?  → **10** · x + y = 0, 1, …, 3 인 경우가 각각 1, 2, …, 4가지 → 모두 더한다.
  - (m3-2) [number] 자연수 x, y 에 대하여 x + 2y = 9 을 만족시키는 순서쌍 (x, y) 의 개수는?  → **4** · y = 1, 2, … 를 차례로 넣어 x 가 자연수인 것만 센다(계수가 큰 y 부터).
- 👾 m4 문제 4 · 전체에서 빼기 ⛰ (⏱ 8.4분)
  - (m4-1) [number] 서로 다른 주사위 3개를 동시에 던질 때, 나오는 눈의 수의 곱이 짝수인 경우의 수를 구하려고 한다. 일어날 수 있는 모든 경우의 수는?  → **216** · 주사위 하나마다 6가지 → 6 을 3번 곱한다.
  - (m4-2) [number] 서로 다른 주사위 3개를 동시에 던질 때, 나오는 눈의 수의 곱이 짝수인 경우의 수를 구하려고 한다. 곱이 짝수가 「아닌」 경우, 곧 3개 모두 홀수의 눈이 나오는 경우의 수는?  → **27** · 홀수의 눈은 3가지 → 3 를 3번 곱한다.
  - (m4-3) [number] 서로 다른 주사위 3개를 동시에 던질 때, 나오는 눈의 수의 곱이 짝수인 경우의 수는?  → **189** · (전체) − (짝수가 아닌 경우) = 216 − 27.
- 👾 m5 🌱 여유 문제 · 지불하는 방법의 수 (⏱ 2.9분)
  - (m5-1) [number] 500 원짜리 동전 2개와 100 원짜리 동전 3개의 일부 또는 전부를 사용하여 지불할 수 있는 방법의 수는? (0 원을 지불하는 경우는 제외)  → **11** · 500 원 동전을 쓰는 개수 3가지 × 100 원 동전 4가지 − (둘 다 0개) 1.
- 👑 형성평가 4문항 (⏱ 9.6분) · 짝 = ['m1', 'm2', 'm2', 'm3']
  - (b-1) [number] 서로 다른 주사위 두 개를 동시에 던질 때, 나오는 눈의 수의 합이 4 또는 7 인 경우의 수는?  → **9** · 합이 4 인 경우 3가지, 7 인 경우 6가지 — 동시에 일어나지 않으므로 더한다.
  - (b-2) [number] 상의 3벌, 하의 4벌 가 있을 때, 하나씩 골라 입는 방법의 수는?  → **12** · 3 × 4 — 상의마다 하의를 모두 고를 수 있다(동시에 일어남 → 곱).
  - (b-3) [number] (x + y)(a + b + c) 를 전개했을 때 생기는 항의 개수는?  → **6** · 앞 괄호의 2개 항마다 뒤 괄호의 3개 항과 곱해진다 → 2 × 3.
  - (b-4) [number] 음이 아닌 정수 x, y 에 대하여 x + y ≤ 3 을 만족시키는 순서쌍 (x, y) 의 개수는?  → **10** · x + y = 0, 1, …, 3 인 경우가 각각 1, 2, …, 4가지 → 모두 더한다.

### 27-01 · 또는 = 더하기, 그리고 = 곱하기

```
[영상] 공통수학1 27차시 「합의 법칙과 곱의 법칙」 개념 영상 1 — 또는 = 더하기, 그리고 = 곱하기
[형식] UI 데모 스타일 · 30초 루프 · 1280×720 · MP4 1MB 이내 · 웜그레이 캔버스 · 흰 카드 하나 · 커서 조작 · 잔잔한 배경음 + 클릭음 · 자막은 화면 글자로만(내레이션 없음)
[대상] 특성화고 1학년 · 기초가 약한 학생도 한 번에 따라오게 · 한 화면에 식 하나
[핵심 한 줄] 동시에 안 일어나면 더하고, 잇달아 일어나면 곱한다.
[장면]
1. 카드 왼쪽: 「버스 3 또는 지하철 2」 → 갈림길 5개가 나란히 펼쳐진다 (3 + 2).
2. 카드 오른쪽: 「상의 3 그리고 하의 2」 → 나뭇가지처럼 3 갈래마다 2 갈래 (3 × 2).
3. 두 그림 아래 5, 6 이 뜬다.
4. 「또는 → +」 「그리고 → ×」 딱지.
[마지막 화면] 합의 법칙 m + n · 곱의 법칙 m × n
[쓰지 말 것] 교과서 그림 그대로 · 실제 상표 · 빠른 깜박임
[파일 이름] cm1-27-01.mp4 → 팩 video 칸 c1
```
