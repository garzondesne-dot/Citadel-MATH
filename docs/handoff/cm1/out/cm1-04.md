# 4차시 · 다항식의 나눗셈 — 시안 (공통수학1 · Ⅰ-1 다항식의 연산)

> 교과서 18 · 20 ~ 21 (중단원 04 · 08 · 09)쪽 · 목표: 다항식의 나눗셈의 원리를 설명하고, 몫과 나머지를 구할 수 있다.
> ⏱ 예상 45.7분(여유 문제 빼고) · 여유 문제 +2.3분 · 어려운 문제(산) = m5 · 산 = 중단원 마무리 08번 꼴(나누어떨어질 조건) · 문제 4 = 09번 꼴
> 문항 119줄(판 0 ~ 6) · 계산 검산 ✅ 119 · 눈으로 확인 0 · ❌ 0 · 글 검사 걸림 0 · 같은 판 0

## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 자연수 나눗셈 17 ÷ 5 = 3 … 2 를 17 = 5 × 3 + 2 로 쓰기 · 2차시 분배법칙 전개
- 💭 생각 열기: 17 = 5 × 3 + 2 처럼 다항식도 「나누는 식 × 몫 + 나머지」로 쓸 수 있다.
- 📘 c1 다항식의 나눗셈 (세로셈): 두 식을 내림차순으로 정리하고(빈 차수는 자리를 비워 둠) 자연수 나눗셈처럼 맨 앞 항부터 지워 나간다. · ✔ 개념 체크: x³ + 2x − 1 을 세로셈으로 나눌 때는 x² 자리를 비워 두고 쓴다. → O
- 📘 c2 A = BQ + R: 다항식 A 를 B 로 나눈 몫 Q, 나머지 R: A = BQ + R (R 의 차수 < B 의 차수). R = 0 이면 「나누어떨어진다」. · ✔ 개념 체크: 다항식을 이차식으로 나눈 나머지는 항상 일차식이다. → X

- 👾 m1 문제 1 · 일차식으로 나누기 (⏱ 4.2분)
  - (m1-1) [choice] (3x³ − 5x² − 2x + 1) ÷ (x − 2) 의 몫은?  〔보기: 3x² − x / 3x² + x + 1 / 3x² + x / 3x + 1〕  → **3x² + x** · 3x³ ÷ x = 3x² 부터 차례로 맨 앞 항을 지워 나간다.
  - (m1-2) [number] (3x³ − 5x² − 2x + 1) ÷ (x − 2) 의 나머지는?  → **1** · 몫 3x² + x 를 구한 뒤 남는 상수가 나머지.
- 👾 m2 문제 2 · 이차식으로 나누기 (⏱ 3.6분)
  - (m2-1) [choice] (2x³ − 5x² + 3) ÷ (x² − 3x − 1) 의 몫은?  〔보기: 2x + 1 / 2x − 1 / 2x + 2 / 2x² + x〕  → **2x + 1** · 나누는 식이 이차식이면 몫은 (삼차) ÷ (이차) = 일차식.
  - (m2-2) [choice] (2x³ − 5x² + 3) ÷ (x² − 3x − 1) 의 나머지는?  〔보기: 4 / 5x + 4 / −5x + 4 / 5x − 4〕  → **5x + 4** · 이차식으로 나눈 나머지는 일차식 이하 — 더 나눌 수 없을 때 멈춘다.
- 👾 m3 문제 3 · A = BQ + R (⏱ 3.0분)
  - (m3-1) [choice] 3x² − 5x + 6 을 x − 1 로 나누면 몫이 3x − 2, 나머지가 4 이다. 이것을 A = BQ + R 꼴로 나타내면 3x² − 5x + 6 = ?  〔보기: (x + 3)(3x − 2) / (x − 1)(3x + 2) / (x − 1)(3x − 2) − 4 / (x − 1)(3x − 2) + 4〕  → **(x − 1)(3x − 2) + 4** · (나누는 식) × (몫) + (나머지) = (나누어지는 식).
  - (m3-2) [ox] x³ + 3x = (x + 1)(x² − x + 1) + 3x − 1 이므로, x³ + 3x 을 x + 1 로 나누었을 때의 나머지는 3x − 1 이다.  → **X** · 나머지의 차수는 나누는 식의 차수보다 낮아야 한다 → 일차식으로 나눈 나머지는 상수.
- 👾 m4 문제 4 · 나누는 식 찾기 (⏱ 3.6분)
  - (m4-1) [choice] 다항식 x³ − x² + 3x + 2 을 다항식 B 로 나누었더니 몫이 x − 1, 나머지가 2x + 3 이었다. B 를 구하는 식은?  〔보기: (x³ − x² + 3x + 2) × (x − 1) + (2x + 3) / {(x³ − x² + 3x + 2) + (2x + 3)} ÷ (x − 1) / (x³ − x² + 3x + 2) ÷ (x − 1) − (2x + 3) / {(x³ − x² + 3x + 2) − (2x + 3)} ÷ (x − 1)〕  → **{(x³ − x² + 3x + 2) − (2x + 3)} ÷ (x − 1)** · A = BQ + R → A − R = BQ → B = (A − R) ÷ Q.
  - (m4-2) [choice] (x³ − x² + x − 1) ÷ (x − 1) 를 계산하면? (나누어떨어진다)  〔보기: x² + x + 1 / x² + 2 / x² + 1 / x² − 1〕  → **x² + 1** · 세로셈으로 나누면 나머지 없이 이차식 몫이 나온다.
- 👾 m5 문제 5 · 나누어떨어질 조건 ⛰ (⏱ 8.5분)
  - (m5-1) [choice] 2x² − x − 1 + a 가 x² + x + 1 로 나누어떨어진다 (a 는 상수). 「나누어떨어진다」의 뜻은?  〔보기: 나머지가 a 이다 / 몫과 나머지가 같다 / 몫이 0 이다 / 나머지가 0 이다〕  → **나머지가 0 이다** · A = BQ 꼴, 곧 R = 0.
  - (m5-2) [choice] (2x² − x − 1 + a) ÷ (x² + x + 1) 를 세로셈으로 할 때 몫은? (a 는 상수)  〔보기: 2x − 2 / 2x − 3 / 2x − 4 / 2x + 3〕  → **2x − 3** · a 는 상수항에만 있으므로 몫은 앞의 세 항으로 정해진다.
  - (m5-3) [choice] (2x² − x − 1 + a) ÷ (x² + x + 1) 의 몫은 2x − 3 이다. 이때 나머지는? (a 는 상수)  〔보기: a − 3 / a / a + 3 / 3a〕  → **a + 3** · (x² + x + 1)(2x − 3) = 2x³ − x² − x − 3 를 빼면 상수만 남는다.
  - (m5-4) [number] 2x² − x − 1 + a 가 x² + x + 1 로 나누어떨어질 때, 상수 a 의 값은?  → **-3** · 몫 2x − 3, 나머지 a − (−3) = 0.
- 👾 m6 🌱 여유 문제 · 넓이와 가로로 세로 구하기 (⏱ 2.3분)
  - (m6-1) [choice] 넓이가 3x³ − 5x² − 2x 인 직사각형의 가로의 길이가 x − 2 일 때, 세로의 길이는?  〔보기: 3x² + x / 3x² + 2x / 3x² − x / 3x² + x + 1〕  → **3x² + x** · (세로) = (넓이) ÷ (가로) → 다항식의 나눗셈.
- 👑 형성평가 4문항 (⏱ 7.8분) · 짝 = ['m1', 'm2', 'm3', 'm5']
  - (b-1) [choice] (3x³ − 5x² − 2x + 1) ÷ (x − 2) 의 몫은?  〔보기: 3x² − x / 3x² + x / 3x + 1 / 3x² + x + 1〕  → **3x² + x** · 3x³ ÷ x = 3x² 부터 차례로 맨 앞 항을 지워 나간다.
  - (b-2) [choice] (2x³ − 5x² + 3) ÷ (x² − 3x − 1) 의 나머지는?  〔보기: 5x − 4 / 5x + 4 / 4 / −5x + 4〕  → **5x + 4** · 이차식으로 나눈 나머지는 일차식 이하 — 더 나눌 수 없을 때 멈춘다.
  - (b-3) [choice] 3x² − 5x + 6 을 x − 1 로 나누면 몫이 3x − 2, 나머지가 4 이다. 이것을 A = BQ + R 꼴로 나타내면 3x² − 5x + 6 = ?  〔보기: (x + 3)(3x − 2) / (x − 1)(3x − 2) + 4 / (x − 1)(3x − 2) − 4 / (x − 1)(3x + 2)〕  → **(x − 1)(3x − 2) + 4** · (나누는 식) × (몫) + (나머지) = (나누어지는 식).
  - (b-4) [number] 2x² − x − 1 + a 가 x² + x + 1 로 나누어떨어질 때, 상수 a 의 값은?  → **-3** · 몫 2x − 3, 나머지 a − (−3) = 0.
