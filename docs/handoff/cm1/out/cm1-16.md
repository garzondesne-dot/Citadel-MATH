## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 13차시: 판별식 D 와 근의 종류 · 중학교: 이차함수의 그래프(포물선)
- 💭 생각 열기: y = x² − 5x + 4 의 그래프가 x축과 만나는 곳의 x좌표 1, 4 = 방정식 x² − 5x + 4 = 0 의 근.
- 📘 c1 그래프와 x축이 만나는 점: y = ax² + bx + c 의 그래프와 x축이 만나는 점의 x좌표 = 이차방정식 ax² + bx + c = 0 의 실근. · ✔ 개념 체크: 이차함수 y = x² + 1 의 그래프는 x축과 만난다. → X
- 📘 c2 판별식과 위치 관계: D > 0 서로 다른 두 점에서 만난다 · D = 0 한 점에서 만난다(접한다) · D < 0 만나지 않는다.

- 👾 m1 문제 1 · x축과 만나는 점 (⏱ 4.2분)
  - (m1-1) [choice] 이차함수 y = x² − 2x − 3 의 그래프와 x축이 만나는 점의 x좌표를 모두 구한 것은?  〔보기: −3, 1 / −1, 3 / −1, −3 / 2, −3〕  → **−1, 3** · y = 0 으로 놓은 이차방정식 x² − 2x − 3 = 0 의 실근이 x좌표.
  - (m1-2) [number] 이차함수 y = −x² + 6x − 9 의 그래프와 x축이 만나는 점의 x좌표는?  → **3** · −x² + 6x − 9 = 0 → −1(x − 3)² = 0 → 중근(접점 하나).
- 👾 m2 문제 2 · x축과의 위치 관계 (⏱ 4.9분)
  - (m2-1) [choice] 이차함수 y = x² + 4x + 2 의 그래프와 x축의 위치 관계는?  〔보기: 서로 다른 두 점에서 만난다 / 한 점에서 만난다 (접한다) / 만나지 않는다〕  → **서로 다른 두 점에서 만난다** · x² + 4x + 2 = 0 의 판별식 D = 8 > 0.
  - (m2-2) [choice] 이차함수 y = 2x² − 3x + 2 의 그래프와 x축의 위치 관계는?  〔보기: 만나지 않는다 / 서로 다른 두 점에서 만난다 / 한 점에서 만난다 (접한다)〕  → **만나지 않는다** · 2x² − 3x + 2 = 0 의 판별식 D = −7 < 0.
  - (m2-3) [choice] 이차함수 y = −x² + 2x − 1 의 그래프와 x축의 위치 관계는?  〔보기: 한 점에서 만난다 (접한다) / 서로 다른 두 점에서 만난다 / 만나지 않는다〕  → **한 점에서 만난다 (접한다)** · −x² + 2x − 1 = 0 의 판별식 D = 0 = 0.
- 👾 m3 문제 3 · 위치 관계로 k 구하기 (⏱ 4.2분)
  - (m3-1) [choice] 이차함수 y = x² − 8x + k 의 그래프가 x축과 서로 다른 두 점에서 만나도록 하는 실수 k 의 값의 범위는?  〔보기: k > 16 / k ≥ 16 / k ≤ 16 / k < 16〕  → **k < 16** · D > 0: D/4 = 16 − k > 0.
  - (m3-2) [number] 이차함수 y = x² − 8x + k 의 그래프가 x축에 접하도록 하는 실수 k 의 값은?  → **16** · 접한다 ⟺ D = 0: 16 − k = 0.
- 👾 m4 문제 4 · 두 교점 사이의 거리 ⛰ (⏱ 7.2분)
  - (m4-1) [multi] 이차함수 y = x² − ax − 12 의 그래프가 x축과 만나는 두 점 사이의 거리가 8 이다 (a > 0). 두 교점의 x좌표를 α, β 라 할 때, 맞는 식을 모두 고르시오.  〔보기: α + β = a / α + β = −a / αβ = −12 / αβ = 12 / |α − β| = 8〕  → **α + β = a · αβ = −12 · |α − β| = 8** · x² − ax + (상수) = 0 의 두 근 → 합 a, 곱 = 상수항. 거리 = 두 근의 차.
  - (m4-2) [choice] 이차함수 y = x² − ax − 12 의 그래프가 x축과 만나는 두 점 사이의 거리가 8 이다 (a > 0). 두 교점의 x좌표 α, β 에 대하여 (α − β)² 을 α + β 와 αβ 로 나타내면?  〔보기: (α + β)² − 2αβ / (α + β)² − αβ / (α + β)² + 4αβ / (α + β)² − 4αβ〕  → **(α + β)² − 4αβ** · (α − β)² = α² − 2αβ + β² = (α + β)² − 4αβ.
  - (m4-3) [number] 이차함수 y = x² − ax − 12 의 그래프가 x축과 만나는 두 점 사이의 거리가 8 이다 (a > 0). a 의 값은?  → **4** · 8² = a² − 4 × (−12) → a² = 16 → a > 0 이므로 4.
- 👾 m5 🌱 여유 문제 · 교점으로 식 찾기 (⏱ 2.9분)
  - (m5-1) [number] 이차함수 y = x² + px + q 의 그래프가 x축과 만나는 두 점의 x좌표가 −1, 3 일 때, p + q 의 값은? (p, q 는 상수)  → **-5** · x² + px + q = (x − (−1))(x − (3)) → p = −2, q = −3.
- 👑 형성평가 4문항 (⏱ 7.8분) · 짝 = ['m1', 'm2', 'm3', 'm3']
  - (b-1) [choice] 이차함수 y = x² − 2x − 3 의 그래프와 x축이 만나는 점의 x좌표를 모두 구한 것은?  〔보기: −1, −3 / −1, 3 / 2, −3 / −3, 1〕  → **−1, 3** · y = 0 으로 놓은 이차방정식 x² − 2x − 3 = 0 의 실근이 x좌표.
  - (b-2) [choice] 이차함수 y = 2x² − 3x + 2 의 그래프와 x축의 위치 관계는?  〔보기: 만나지 않는다 / 서로 다른 두 점에서 만난다 / 한 점에서 만난다 (접한다)〕  → **만나지 않는다** · 2x² − 3x + 2 = 0 의 판별식 D = −7 < 0.
  - (b-3) [choice] 이차함수 y = x² − 8x + k 의 그래프가 x축과 서로 다른 두 점에서 만나도록 하는 실수 k 의 값의 범위는?  〔보기: k ≥ 16 / k > 16 / k ≤ 16 / k < 16〕  → **k < 16** · D > 0: D/4 = 16 − k > 0.
  - (b-4) [number] 이차함수 y = x² − 8x + k 의 그래프가 x축에 접하도록 하는 실수 k 의 값은?  → **16** · 접한다 ⟺ D = 0: 16 − k = 0.
