# 12차시 · 음수의 제곱근과 i 의 거듭제곱 — 시안 (공통수학1 · Ⅱ-1 복소수와 이차방정식)

> 교과서 50 ~ 51 · 61 (중단원)쪽 · 목표: 음수의 제곱근을 i 로 나타내고, i 의 거듭제곱의 규칙을 이용할 수 있다.
> ⏱ 예상 40.6분(여유 문제 빼고) · 여유 문제 +2.3분 · 어려운 문제(산) = m4 · 산 = 중단원 수준의 규칙 찾기(본문에 어려운 문제가 없어 넣음 · i 의 거듭제곱 합)
> 문항 98줄(판 0 ~ 6) · 계산 검산 ✅ 98 · 눈으로 확인 0 · ❌ 0 · 글 검사 걸림 0 · 같은 판 0

## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 10차시: i² = −1 · 11차시: 곱셈에서 i² 바꾸기
- 💭 생각 열기: √(−9) 는 무엇일까? i 의 거듭제곱 i, i², i³, i⁴ … 는 어떻게 돌아갈까?
- 📘 c1 음수의 제곱근: a > 0 일 때 √(−a) = √a i · −a 의 제곱근 = ±√a i. 음수의 제곱근끼리 곱할 때는 먼저 i 로 바꾼다. · ✔ 개념 체크: √(−2) × √(−3) = √6 이다. → X
- 📘 c2 i 의 거듭제곱: i, −1, −i, 1 이 네 개마다 되풀이된다(i⁴ = 1) → 지수를 4 로 나눈 나머지만 본다.

- 👾 m1 문제 1 · 음수의 제곱근 (⏱ 3.6분)
  - (m1-1) [choice] √(−9) 을 허수단위 i 를 써서 나타내면?  〔보기: −3 / 9i / 3i / −3i〕  → **3i** · a > 0 일 때 √(−a) = √a i → √9 i.
  - (m1-2) [choice] −5 의 제곱근을 모두 구한 것은?  〔보기: −√5 i / √5, −√5 / √5 i / √5 i, −√5 i〕  → **√5 i, −√5 i** · 제곱해서 −5 가 되는 수 = ±√5 i.
- 👾 m2 문제 2 · 음수의 제곱근의 계산 (⏱ 4.2분)
  - (m2-1) [number] √(−2) × √(−8) 를 계산하면?  → **-4** · √2 i × √8 i = √16 i² = 4 × (−1). (√16 로 바로 계산하면 틀림)
  - (m2-2) [choice] √12 ÷ √(−3) 를 계산하면?  〔보기: −2 / −2i / 2i / 2〕  → **−2i** · √12 / (√3 i) = 2/i = 2i/i² = −2i.
- 👾 m3 문제 3 · i 의 거듭제곱 (⏱ 4.2분)
  - (m3-1) [choice] i¹⁰ 의 값은?  〔보기: 1 / −i / i / −1〕  → **−1** · i⁴ = 1 → 10 을 4 로 나눈 나머지 2 만 본다.
  - (m3-2) [number] i + i² + i³ + i⁴ 의 값은?  → **0** · 잇따른 네 거듭제곱은 i, −1, −i, 1 이 한 번씩 → 합은 0.
- 👾 m4 문제 4 · i 를 쭉 더하기 ⛰ (⏱ 6.9분)
  - (m4-1) [choice] i + i² + i³ + … + i⁵⁰ 의 값을 구하려고 한다. 앞에서부터 네 개씩 묶을 때, 한 묶음 i + i² + i³ + i⁴ 의 값은?  〔보기: 0 / 1 / −1 / i〕  → **0** · i + (−1) + (−i) + 1 = 0.
  - (m4-2) [number] i + i² + i³ + … + i⁵⁰ 의 값을 구하려고 한다. 항 50개를 네 개씩 묶으면 몇 개가 남는가?  → **2** · 50 = 4 × 12 + 2.
  - (m4-3) [choice] i + i² + i³ + … + i⁵⁰ 의 값은?  〔보기: i / −1 + i / 0 / −1〕  → **−1 + i** · 묶음은 모두 0, 남는 2개는 앞의 2개(i, −1, −i 순)와 같다.
- 👾 m5 🌱 여유 문제 · 해가 허수인 이차방정식 (⏱ 2.3분)
  - (m5-1) [choice] 이차방정식 x² + 4 = 0 의 해는?  〔보기: x = 2i / 해가 없다 / x = 2 또는 x = −2 / x = 2i 또는 x = −2i〕  → **x = 2i 또는 x = −2i** · x² = −4 → x = ±√(−4) = ±2i.
- 👑 형성평가 4문항 (⏱ 7.8분) · 짝 = ['m1', 'm2', 'm3', 'm4']
  - (b-1) [choice] √(−9) 을 허수단위 i 를 써서 나타내면?  〔보기: 9i / 3i / −3i / −3〕  → **3i** · a > 0 일 때 √(−a) = √a i → √9 i.
  - (b-2) [number] √(−2) × √(−8) 를 계산하면?  → **-4** · √2 i × √8 i = √16 i² = 4 × (−1). (√16 로 바로 계산하면 틀림)
  - (b-3) [choice] i¹⁰ 의 값은?  〔보기: 1 / −i / i / −1〕  → **−1** · i⁴ = 1 → 10 을 4 로 나눈 나머지 2 만 본다.
  - (b-4) [choice] i + i² + i³ + … + i⁵⁰ 의 값은?  〔보기: −1 / i / −1 + i / 0〕  → **−1 + i** · 묶음은 모두 0, 남는 2개는 앞의 2개(i, −1, −i 순)와 같다.
