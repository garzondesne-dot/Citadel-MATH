## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 10차시: i² = −1 · 켤레복소수 · 중학교: 분모의 유리화
- 💭 생각 열기: i 를 문자처럼 계산하되 i² 이 나오면 −1 로 바꾼다. 나눗셈은 분모의 유리화처럼 켤레를 곱한다.
- 📘 c1 덧셈 · 뺄셈 · 곱셈: 덧셈 · 뺄셈 = 실수부분끼리, 허수부분끼리. 곱셈 = 분배법칙으로 전개 뒤 i² = −1. · ✔ 개념 체크: (1 + i)(1 − i) = 0 이다. → X
- 📘 c2 나눗셈: 분모의 켤레복소수를 분모 · 분자에 곱해 분모를 실수로 만든다: (a + bi)(a − bi) = a² + b².

- 👾 m1 문제 1 · 덧셈과 뺄셈 (⏱ 3.6분)
  - (m1-1) [choice] (3 − 2i) + (−1 + 4i) 를 계산하면?  〔보기: 2 + 2i / 3 + 2i / 4 − 6i / 2 − 2i〕  → **2 + 2i** · 실수부분끼리, 허수부분끼리 계산한다(i 를 문자처럼).
  - (m1-2) [choice] (3 − 2i) − (−1 + 4i) 를 계산하면?  〔보기: 2 + 2i / 4 − 6i / 4 + 6i / −6 + 4i〕  → **4 − 6i** · 실수부분끼리, 허수부분끼리 계산한다(i 를 문자처럼).
- 👾 m2 문제 2 · 곱셈 (⏱ 4.2분)
  - (m2-1) [choice] (2 + i)(3 − i) 를 계산하면?  〔보기: 7 − i / 5 + i / 7 + i / 6 − i〕  → **7 + i** · 분배법칙으로 전개하고 i² = −1 로 바꾼다: −i² = 1.
  - (m2-2) [number] 복소수 z = 3 + 2i 와 그 켤레복소수의 곱을 구하면?  → **13** · (a + bi)(a − bi) = a² + b² = 9 + 4.
- 👾 m3 문제 3 · 나눗셈 (⏱ 3.6분)
  - (m3-1) [choice] (3 + i) ÷ (1 + 2i) 를 계산하려면 분모와 분자에 무엇을 곱해야 하는가?  〔보기: 1 − 2i / 1 + 2i / i / −1 − 2i〕  → **1 − 2i** · 분모의 켤레복소수를 곱하면 분모가 실수(a² + b²)가 된다.
  - (m3-2) [choice] (3 + i) ÷ (1 + 2i) 를 계산하면?  〔보기: 1 + i / 1 − i / −1 + i / −1 − i〕  → **1 − i** · 분모 · 분자에 1 − 2i 를 곱하면 분모 = 5.
- 👾 m4 문제 4 · 켤레가 섞인 식의 값 ⛰ (⏱ 6.9분)
  - (m4-1) [choice] 두 복소수 α = 3 − 2i, β = −2 + i 에 대하여 (ᾱ, β̄ 는 각각 α, β 의 켤레복소수) αᾱ + ᾱβ + αβ̄ + ββ̄ 를 인수분해 하면?  〔보기: (α + ᾱ)(β + β̄) / (α − β)(ᾱ − β̄) / (α + β)(ᾱ + β̄) / (α + β)²〕  → **(α + β)(ᾱ + β̄)** · ᾱ(α + β) + β̄(α + β) 로 묶인다.
  - (m4-2) [choice] 두 복소수 α = 3 − 2i, β = −2 + i 에 대하여 (ᾱ, β̄ 는 각각 α, β 의 켤레복소수) α + β 와 그 켤레복소수 ᾱ + β̄ 를 차례로 구하면?  〔보기: 1 − i, 1 − i / 1 + i, 1 − i / 5 − 3i, 5 + 3i / 1 − i, 1 + i〕  → **1 − i, 1 + i** · 더한 뒤 허수부분의 부호만 바꾸면 켤레(합의 켤레 = 켤레의 합).
  - (m4-3) [number] 두 복소수 α = 3 − 2i, β = −2 + i 에 대하여 (ᾱ, β̄ 는 각각 α, β 의 켤레복소수) αᾱ + ᾱβ + αβ̄ + ββ̄ 의 값은?  → **2** · (α + β)(ᾱ + β̄) = (1 − i)(1 + i) = 1 + 1.
- 👾 m5 🌱 여유 문제 · (1 + i) 의 거듭제곱 (⏱ 2.3분)
  - (m5-1) [choice] (1 + i)² = 2i 임을 이용하여 (1 + i)⁴ 의 값을 구하면?  〔보기: −4 / 4i / −4i / 4〕  → **−4** · (2i)² 를 계산한다 — i² = −1.
- 👑 형성평가 4문항 (⏱ 7.8분) · 짝 = ['m1', 'm2', 'm2', 'm3']
  - (b-1) [choice] (3 − 2i) − (−1 + 4i) 를 계산하면?  〔보기: 2 + 2i / 4 − 6i / 4 + 6i / −6 + 4i〕  → **4 − 6i** · 실수부분끼리, 허수부분끼리 계산한다(i 를 문자처럼).
  - (b-2) [choice] (2 + i)(3 − i) 를 계산하면?  〔보기: 6 − i / 7 − i / 5 + i / 7 + i〕  → **7 + i** · 분배법칙으로 전개하고 i² = −1 로 바꾼다: −i² = 1.
  - (b-3) [number] 복소수 z = 3 + 2i 와 그 켤레복소수의 곱을 구하면?  → **13** · (a + bi)(a − bi) = a² + b² = 9 + 4.
  - (b-4) [choice] (3 + i) ÷ (1 + 2i) 를 계산하면?  〔보기: 1 + i / 1 − i / −1 − i / −1 + i〕  → **1 − i** · 분모 · 분자에 1 − 2i 를 곱하면 분모 = 5.
