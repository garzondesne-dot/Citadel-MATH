## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 29차시: ₙPᵣ 과 n! · 「순서가 다르면 다른 것」
- 💭 생각 열기: 봉사 활동 지원자 5명 중 2명을 뽑는다 — 누구를 먼저 뽑든 같은 2명이면 같은 것 = 조합.
- 📘 c1 조합과 ₙCᵣ: 서로 다른 n 개에서 순서를 생각하지 않고 r 개를 택하는 것 = 조합. ₙCᵣ = ₙPᵣ / r! = n! / {r!(n − r)!}. · ✔ 개념 체크: 5명 중 회장, 부회장을 뽑는 방법의 수는 ₅C₂ 이다. → X
- 📘 c2 ₙCᵣ = ₙCₙ₋ᵣ: r 개를 뽑는 것 = 남길 n − r 개를 정하는 것. ₙC₀ = ₙCₙ = 1. · ✔ 개념 체크: ₇C₅ = ₇C₂ 이다. → O

- 👾 m1 문제 1 · ₙCᵣ 계산 (⏱ 4.8분)
  - (m1-1) [number] ₅C₂ 의 값은?  → **10** · ₅P₂ ÷ 2! = 5 × 4 ÷ 2.
  - (m1-2) [number] ₇C₅ 의 값은?  → **21** · ₙCᵣ = ₙCₙ₋ᵣ → ₇C₂ 로 바꾸어 계산하면 편하다.
- 👾 m2 문제 2 · 순열과의 관계 (⏱ 4.2분)
  - (m2-1) [choice] ₅C₃ 와 ₅P₃ 사이의 관계로 옳은 것은?  〔보기: ₅C₃ × 5! = ₅P₃ / ₅C₃ = ₅P₃ × 3! / ₅C₃ + 3! = ₅P₃ / ₅C₃ × 3! = ₅P₃〕  → **₅C₃ × 3! = ₅P₃** · 3개를 뽑는 조합마다 줄 세우는 방법이 3! 가지 → 곱하면 순열.
  - (m2-2) [number] ₙC₂ = 15 를 만족시키는 자연수 n 의 값은?  → **6** · n(n − 1)/2 = 15 → n(n − 1) = 30 = 6 × 5.
- 👾 m3 문제 3 · 뽑기만 하기 (⏱ 4.8분)
  - (m3-1) [number] 학생 6명 중에서 대표 2명을 뽑는 방법의 수는? (대표끼리는 구별하지 않는다)  → **15** · 순서가 없는 뽑기 → ₆C₂.
  - (m3-2) [number] 6명이 서로 한 번씩 악수를 할 때, 악수의 총 횟수는?  → **15** · 6 중에서 2 를 뽑는 것과 같다 → ₆C₂.
- 👾 m4 문제 4 · 뽑은 뒤 줄 세우기 ⛰ (⏱ 5.9분)
  - (m4-1) [number] 남학생 4명, 여학생 3명 중에서 남학생 2명, 여학생 1명을 뽑아 한 줄로 세우려고 한다. 남학생 2명과 여학생 1명을 뽑는 방법의 수는? (아직 줄은 세우지 않는다)  → **18** · ₄C₂ × ₃C₁ = 6 × 3 (곱의 법칙).
  - (m4-2) [number] 남학생 4명, 여학생 3명 중에서 남학생 2명, 여학생 1명을 뽑아 한 줄로 세우려고 한다. 뽑은 3명을 한 줄로 세우는 방법까지 생각한 전체 방법의 수는?  → **108** · 뽑기 18가지 × 줄 세우기 3! = 6.
- 👾 m5 🌱 여유 문제 · 점을 이어 선분 만들기 (⏱ 2.9분)
  - (m5-1) [number] 원 위에 서로 다른 점 5개가 있다. 이 중 두 점을 이어 만들 수 있는 선분의 개수는?  → **10** · 두 점을 고르면 선분 하나 → ₅C₂.
- 👑 형성평가 4문항 (⏱ 9.6분) · 짝 = ['m1', 'm1', 'm3', 'm3']
  - (b-1) [number] ₅C₂ 의 값은?  → **10** · ₅P₂ ÷ 2! = 5 × 4 ÷ 2.
  - (b-2) [number] ₇C₅ 의 값은?  → **21** · ₙCᵣ = ₙCₙ₋ᵣ → ₇C₂ 로 바꾸어 계산하면 편하다.
  - (b-3) [number] 학생 6명 중에서 대표 2명을 뽑는 방법의 수는? (대표끼리는 구별하지 않는다)  → **15** · 순서가 없는 뽑기 → ₆C₂.
  - (b-4) [number] 6명이 서로 한 번씩 악수를 할 때, 악수의 총 횟수는?  → **15** · 6 중에서 2 를 뽑는 것과 같다 → ₆C₂.
