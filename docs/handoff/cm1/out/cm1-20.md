## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 9차시: 인수정리로 인수분해 · 조립제법 · AB = 0 이면 A = 0 또는 B = 0
- 💭 생각 열기: 삼차 · 사차방정식도 좌변을 인수분해 하면 일차 · 이차방정식으로 쪼개진다.
- 📘 c1 인수분해 공식 · 치환으로 풀기: (좌변) = 0 꼴에서 좌변을 공식이나 x² = X 치환으로 인수분해 → 각 인수 = 0. 복소수 범위에서 삼차는 근 3개, 사차는 4개. · ✔ 개념 체크: 삼차방정식 x³ = 1 의 해는 x = 1 뿐이다. → X
- 📘 c2 인수정리와 조립제법으로 풀기: f(α) = 0 인 α 를 찾아 (x − α)Q(x) = 0 으로 → Q(x) = 0 을 다시 푼다.

- 👾 m1 문제 1 · x³ = a³ 꼴 (⏱ 4.2분)
  - (m1-1) [choice] 삼차방정식 x³ − 27 = 0 의 좌변을 인수분해 하면?  〔보기: (x − 3)(x² − 3x + 9) = 0 / (x + 3)(x² − 3x + 9) = 0 / (x − 3)³ = 0 / (x − 3)(x² + 3x + 9) = 0〕  → **(x − 3)(x² + 3x + 9) = 0** · a³ − b³ = (a − b)(a² + ab + b²).
  - (m1-2) [number] 삼차방정식 x³ − 27 = 0 의 실근은?  → **3** · (x − 3)(이차식) = 0 에서 이차식은 D < 0 이라 허근 → 실근은 x = 3 하나.
- 👾 m2 문제 2 · x² = X 로 놓기 (⏱ 3.6분)
  - (m2-1) [choice] 사차방정식 x⁴ − x² − 12 = 0 에서 x² = X 로 놓고 인수분해 하면?  〔보기: (X − 4)(X + 3) = 0 / (X − 4)(X − 3) = 0 / (X + 4)(X + 3) = 0 / (X + 4)(X − 3) = 0〕  → **(X − 4)(X + 3) = 0** · X² − X − 12 → 곱 −12, 합 −1 인 두 수.
  - (m2-2) [choice] 사차방정식 x⁴ − x² − 12 = 0 의 실근을 모두 구한 것은?  〔보기: x = 2 또는 x = −2 / x = 2 / x = 4 또는 x = −3 / x = 2 또는 x = −2 또는 x = 3 또는 x = −3〕  → **x = 2 또는 x = −2** · x² = 4 에서 x = ±2 · x² = −3 는 실근이 없다(허근).
- 👾 m3 문제 3 · 인수정리로 삼차방정식 (⏱ 3.6분)
  - (m3-1) [choice] 삼차방정식 x³ − 2x² − 5x + 6 = 0 에서 f(x) = x³ − 2x² − 5x + 6 라 하면 f(1) = 0 이다. 좌변을 인수분해 한 첫 단계는?  〔보기: (x + 1)(x² − x − 6) = 0 / (x − 1)(x² + x − 6) = 0 / (x − 1)(x² − x − 5) = 0 / (x − 1)(x² − x − 6) = 0〕  → **(x − 1)(x² − x − 6) = 0** · 인수정리: x − (1) 가 인수 → 조립제법으로 몫을 구한다.
  - (m3-2) [choice] 삼차방정식 x³ − 2x² − 5x + 6 = 0 의 해는?  〔보기: x = −3 또는 x = −1 또는 x = 2 / x = −2 또는 x = 1 / x = −2 또는 x = 1 또는 x = 3 / x = −3 또는 x = −2 또는 x = 1〕  → **x = −2 또는 x = 1 또는 x = 3** · (x − α)(이차식) = 0 → 이차식도 인수분해 하여 세 일차식의 곱으로.
- 👾 m4 문제 4 · 사차방정식 ⛰ (⏱ 6.5분)
  - (m4-1) [multi] 사차방정식 x⁴ + 2x³ + 2x² + x − 6 = 0 에서 f(x) = x⁴ + 2x³ + 2x² + x − 6 라 하자. 다음 중 f(α) = 0 이 되는 α 를 모두 고르시오.  〔보기: 1 / 2 / −1 / −2〕  → **1 · −2** · 상수항의 약수를 넣어 0 이 되는 것을 찾는다.
  - (m4-2) [choice] 사차방정식 x⁴ + 2x³ + 2x² + x − 6 = 0 에서 f(x) = x⁴ + 2x³ + 2x² + x − 6 라 하자. f(1) = 0, f(−2) = 0 임을 이용하여 좌변을 인수분해 하면?  〔보기: (x − 1)(x + 2)(x² + x + 3) = 0 / (x − 1)(x + 2)(x² − x + 3) = 0 / (x + 1)(x − 2)(x² + x + 3) = 0 / (x − 1)(x + 2)(x² + x − 3) = 0〕  → **(x − 1)(x + 2)(x² + x + 3) = 0** · 조립제법을 두 번 써서 일차식 둘을 떼어 낸다.
  - (m4-3) [choice] 사차방정식 (x − 1)(x + 2)(x² + x + 3) = 0 의 실근을 모두 구한 것은?  〔보기: x = 1 / x = −2 또는 x = 1 또는 x = 3 / x = −2 또는 x = 1 / x = −1 또는 x = 2〕  → **x = −2 또는 x = 1** · x² + x + 3 = 0 은 D = −11 < 0 → 허근. 실근은 일차식에서만.
- 👾 m5 🌱 여유 문제 · x³ + a³ = 0 (⏱ 2.3분)
  - (m5-1) [choice] 삼차방정식 x³ + 8 = 0 의 해 중 실수인 것은?  〔보기: x = −2 / x = 2 또는 x = −2 / x = 2 / 실수인 해가 없다〕  → **x = −2** · (x + 2)(x² − 2x + 4) = 0 → 이차식은 허근.
- 👑 형성평가 4문항 (⏱ 7.8분) · 짝 = ['m1', 'm2', 'm3', 'm3']
  - (b-1) [number] 삼차방정식 x³ − 27 = 0 의 실근은?  → **3** · (x − 3)(이차식) = 0 에서 이차식은 D < 0 이라 허근 → 실근은 x = 3 하나.
  - (b-2) [choice] 사차방정식 x⁴ − x² − 12 = 0 의 실근을 모두 구한 것은?  〔보기: x = 2 또는 x = −2 또는 x = 3 또는 x = −3 / x = 2 또는 x = −2 / x = 4 또는 x = −3 / x = 2〕  → **x = 2 또는 x = −2** · x² = 4 에서 x = ±2 · x² = −3 는 실근이 없다(허근).
  - (b-3) [choice] 삼차방정식 x³ − 2x² − 5x + 6 = 0 의 해는?  〔보기: x = −2 또는 x = 1 또는 x = 3 / x = −3 또는 x = −2 또는 x = 1 / x = −3 또는 x = −1 또는 x = 2 / x = −2 또는 x = 1〕  → **x = −2 또는 x = 1 또는 x = 3** · (x − α)(이차식) = 0 → 이차식도 인수분해 하여 세 일차식의 곱으로.
  - (b-4) [choice] 삼차방정식 x³ − 2x² − 5x + 6 = 0 에서 f(x) = x³ − 2x² − 5x + 6 라 하면 f(1) = 0 이다. 좌변을 인수분해 한 첫 단계는?  〔보기: (x − 1)(x² + x − 6) = 0 / (x − 1)(x² − x − 6) = 0 / (x − 1)(x² − x − 5) = 0 / (x + 1)(x² − x − 6) = 0〕  → **(x − 1)(x² − x − 6) = 0** · 인수정리: x − (1) 가 인수 → 조립제법으로 몫을 구한다.
