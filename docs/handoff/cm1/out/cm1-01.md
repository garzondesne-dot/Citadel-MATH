# 1차시 · 다항식의 덧셈과 뺄셈 — 시안 (공통수학1 · Ⅰ-1 다항식의 연산)

> 교과서 12 ~ 14쪽 · 목표: 다항식의 덧셈과 뺄셈의 원리를 설명하고, 그 계산을 할 수 있다.
> ⏱ 예상 45.3분(여유 문제 빼고) · 여유 문제 +2.3분 · 어려운 문제(산) = m5 · 산 = 중단원 마무리 05번 꼴(이 소단원 본문에 어려운 문제가 없어 가져옴)
> 문항 126줄(판 0 ~ 6) · 계산 검산 ✅ 126 · 눈으로 확인 0 · ❌ 0 · 글 검사 걸림 0 · 같은 판 0

## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 중학교: 동류항 · 일차식의 덧셈과 뺄셈 · (3x − 2) − (x + 5) 를 계산해 보기
- 💭 생각 열기: 순위표를 큰 것부터 정렬하면 보기 편하다 → 다항식도 차수 순서로 정리하면 계산이 편하다.
- 📘 c1 다항식의 정리 (내림차순 · 오름차순): 한 문자에 대하여 차수가 높은 항부터 = 내림차순, 낮은 항부터 = 오름차순. 다른 문자는 수처럼 본다. · ✔ 개념 체크: 다항식 5 − 2x + x² 은 x에 대하여 오름차순으로 정리되어 있다. → O
- 📘 c2 다항식의 덧셈과 뺄셈: 덧셈 = 동류항끼리 모아 계산. 뺄셈 = 빼는 식의 모든 항의 부호를 바꾸어 더한다. 교환법칙 · 결합법칙이 성립한다. · ✔ 개념 체크: A − (B − C) = A − B − C 이다. → X

- 👾 m1 문제 1 · 내림차순으로 정리 (⏱ 3.6분)
  - (m1-1) [choice] 다항식 4x − 2 + 3x³ − x² 을 x에 대하여 내림차순으로 정리한 것은?  〔보기: −2 + 4x − x² + 3x³ / 4x + 3x³ − 2 − x² / 3x³ − x² + 4x − 2 / −x² + 3x³ − 2 + 4x〕  → **3x³ − x² + 4x − 2** · 차수가 높은 항부터 차례대로 쓴다(상수항이 맨 뒤).
  - (m1-2) [choice] 다항식 3y² − xy − x³ + 5xy² + 2y + 6 을 y에 대하여 내림차순으로 정리하면 ( □ )y² + ( … )y + ( … ) 꼴이다. □ 에 알맞은 식은?  〔보기: 3x + 5 / 8 / −x + 2 / 5x + 3〕  → **5x + 3** · y² 이 든 항은 3y², 5xy² → y² 으로 묶으면 (5x + 3)y².
- 👾 m2 문제 2 · A + B, A − B (⏱ 3.6분)
  - (m2-1) [choice] A = 3x³ + 2x − 1, B = 2x³ − x² − x + 1 일 때 A + B 를 계산하면?  〔보기: 5x³ + x² + 3x − 2 / x³ + x² + 3x − 2 / −x³ − x² − 3x + 2 / 5x³ − x² + x〕  → **5x³ − x² + x** · 동류항끼리 모아 계수를 더한다.
  - (m2-2) [choice] A = 3x³ + 2x − 1, B = 2x³ − x² − x + 1 일 때 A − B 를 계산하면?  〔보기: x³ + x² + 3x − 2 / −x³ − x² − 3x + 2 / x³ − x² + x / 5x³ − x² + x〕  → **x³ + x² + 3x − 2** · B의 모든 항의 부호를 바꾸어 더한다(첫 항만 바꾸면 틀림).
- 👾 m3 문제 3 · 두 문자 다항식 (⏱ 3.6분)
  - (m3-1) [choice] A = x² + 3xy + 5y², B = 6x² − 9xy − y² 일 때 A + B 를 계산하면?  〔보기: −5x² + 12xy + 6y² / 7x² + 12xy + 4y² / 7x² − 6xy + 4y² / 7x² + 12xy + 6y²〕  → **7x² − 6xy + 4y²** · x², xy, y² 항끼리 따로 모아 계수를 계산한다.
  - (m3-2) [choice] A = x² + 3xy + 5y², B = 6x² − 9xy − y² 일 때 A − B 를 계산하면?  〔보기: −5x² + 12xy + 6y² / −5x² − 6xy + 6y² / −5x² − 6xy + 4y² / 7x² − 6xy + 4y²〕  → **−5x² + 12xy + 6y²** · x², xy, y² 항끼리 따로 모아 계수를 계산한다.
- 👾 m4 문제 4 · 세 다항식의 계산 (⏱ 6.2분)
  - (m4-1) [choice] A = x³ − 2x² + 5, B = −x² + 3x + 1, C = x³ − 5x² + 4x 일 때, A − (B + C) 의 괄호를 풀면?  〔보기: A − B − C / A + B + C / A + B − C / A − B + C〕  → **A − B − C** · 괄호 앞이 − 이면 괄호 안 모든 항의 부호가 바뀐다.
  - (m4-2) [choice] A = x³ − 2x² + 5, B = −x² + 3x + 1, C = x³ − 5x² + 4x 일 때, A − (B + C) 를 계산하면?  〔보기: 2x³ − 6x² + x + 4 / 2x² − x + 6 / 2x³ − 8x² + 7x + 6 / 4x² − 7x + 4〕  → **4x² − 7x + 4** · A − B − C 로 풀어 동류항끼리 계산한다.
  - (m4-3) [choice] A = x³ − 2x² + 5, B = −x² + 3x + 1, C = x³ − 5x² + 4x 일 때, (A − 2B) − (C + A) 를 간단히 하면?  〔보기: 2B − C / 2A − 2B − C / −2B − C / −2B + C〕  → **−2B − C** · A − 2B − C − A 에서 A 와 −A 가 지워진다.
  - (m4-4) [choice] B = −x² + 3x + 1, C = x³ − 5x² + 4x 일 때, −2B − C 를 계산하면?  〔보기: −x³ + 6x² − 7x − 1 / −x³ + 3x² + 2x + 2 / x³ − 3x² − 2x − 2 / −x³ + 7x² − 10x − 2〕  → **−x³ + 7x² − 10x − 2** · B의 각 항에 −2 를 곱하고, C의 각 항의 부호를 바꾸어 더한다.
- 👾 m5 문제 5 · 두 식에서 A, B 찾기 ⛰ (⏱ 6.1분)
  - (m5-1) [choice] 두 다항식 A, B 가 A + B = x³ − 9x² + 4, 2A − B = 2x³ − 6x² − 3x + 2를 만족시킨다. B 를 없애고 A 만 남기려면?  〔보기: 첫 식에 2를 곱해 더한다 / 두 식을 변끼리 뺀다 / 두 식을 변끼리 더한다 (3A 가 남음) / 둘째 식에 2를 곱해 더한다〕  → **두 식을 변끼리 더한다 (3A 가 남음)** · (A + B) + (2A − B) = 3A → B 가 지워진다.
  - (m5-2) [choice] 두 다항식 A, B 가 A + B = x³ − 9x² + 4, 2A − B = 2x³ − 6x² − 3x + 2를 만족시킨다. 두 식을 더하면 3A 이다. A 는?  〔보기: x³ − 5x² − x + 2 / 3x³ − 15x² − 3x + 6 / −x³ − 3x² + 3x + 2 / −4x² + x + 2〕  → **x³ − 5x² − x + 2** · 3A = 3x³ − 15x² − 3x + 6 → 각 계수를 3으로 나눈다.
  - (m5-3) [choice] 두 다항식 A, B 에 대하여 A + B = x³ − 9x² + 4 이고 A = x³ − 5x² − x + 2 이다. B 는?  〔보기: 2x³ − 14x² − x + 6 / −4x² + x + 2 / 4x² − x − 2 / x³ − 5x² − x + 2〕  → **−4x² + x + 2** · B = (A + B) − A 로 계산한다.
- 👾 m6 🌱 여유 문제 · 이익을 식으로 (⏱ 2.3분)
  - (m6-1) [choice] 상품 x개를 만들 때 비용이 2x² + 30x + 500 (원), 수입이 −x² + 80x (원)이다. (이익) = (수입) − (비용) 을 x에 대한 식으로 나타내면?  〔보기: −3x² + 50x + 500 / 3x² − 50x + 500 / −3x² + 50x − 500 / x² + 110x + 500〕  → **−3x² + 50x − 500** · 수입에서 비용의 모든 항을 뺀다(비용 전체에 − 부호).
- 👑 형성평가 4문항 (⏱ 7.2분) · 짝 = ['m1', 'm2', 'm4', 'm5']
  - (b-1) [choice] 다항식 4x − 2 + 3x³ − x² 을 x에 대하여 내림차순으로 정리한 것은?  〔보기: 4x + 3x³ − 2 − x² / −2 + 4x − x² + 3x³ / −x² + 3x³ − 2 + 4x / 3x³ − x² + 4x − 2〕  → **3x³ − x² + 4x − 2** · 차수가 높은 항부터 차례대로 쓴다(상수항이 맨 뒤).
  - (b-2) [choice] A = 3x³ + 2x − 1, B = 2x³ − x² − x + 1 일 때 A − B 를 계산하면?  〔보기: 5x³ − x² + x / −x³ − x² − 3x + 2 / x³ + x² + 3x − 2 / x³ − x² + x〕  → **x³ + x² + 3x − 2** · B의 모든 항의 부호를 바꾸어 더한다(첫 항만 바꾸면 틀림).
  - (b-3) [choice] A = x³ − 2x² + 5, B = −x² + 3x + 1, C = x³ − 5x² + 4x 일 때, A − (B + C) 를 계산하면?  〔보기: 4x² − 7x + 4 / 2x² − x + 6 / 2x³ − 8x² + 7x + 6 / 2x³ − 6x² + x + 4〕  → **4x² − 7x + 4** · A − B − C 로 풀어 동류항끼리 계산한다.
  - (b-4) [choice] A = 2x² − 3x + 4 일 때, A + X = −x² + 5x − 6을 만족시키는 다항식 X 는?  〔보기: −3x² + 8x − 10 / x² + 2x − 2 / −x² + 5x − 6 / 3x² − 8x + 10〕  → **−3x² + 8x − 10** · X = (−x² + 5x − 6) − A 로 계산한다.
