## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 16차시: 이차함수의 그래프와 x축 — D 의 부호 · 인수분해
- 💭 생각 열기: x² − 2x − 3 < 0 = 「포물선이 x축보다 아래에 있는 x 의 범위」. 그래프로 읽으면 한눈에.
- 📘 c1 이차부등식의 해 (D > 0): a > 0, 두 근 α < β: (x − α)(x − β) < 0 ⟺ α < x < β · (x − α)(x − β) > 0 ⟺ x < α 또는 x > β. x² 의 계수가 음수면 −1 을 곱해 방향을 바꾼다. · ✔ 개념 체크: (x − 1)(x − 4) > 0 의 해는 1 < x < 4 이다. → X
- 📘 c2 D = 0, D < 0 인 경우: (x − α)² > 0 ⟺ x ≠ α 인 모든 실수 · (x − α)² ≤ 0 ⟺ x = α · D < 0 (a > 0): ax² + bx + c > 0 은 모든 실수, < 0 은 해가 없다.

- 👾 m1 문제 1 · 두 근의 사이 · 바깥 (⏱ 3.6분)
  - (m1-1) [choice] 이차부등식 x² − 2x − 3 < 0 의 해는?  〔보기: x < 3 / −1 < x < 3 / −3 < x < 1 / x < −1 또는 x > 3〕  → **−1 < x < 3** · (x + 1)(x − 3) < 0 → 그래프가 x축 아래인 부분 = 두 근 사이.
  - (m1-2) [choice] 이차부등식 x² − 7x + 10 > 0 의 해는?  〔보기: x > 5 / x < 2 또는 x > 5 / x < −5 또는 x > −2 / 2 < x < 5〕  → **x < 2 또는 x > 5** · (x − 2)(x − 5) > 0 → 그래프가 x축 위인 부분 = 두 근의 바깥.
- 👾 m2 문제 2 · 계수가 음수 · 중근 (⏱ 3.6분)
  - (m2-1) [choice] 이차부등식 −x² − 3x + 4 ≥ 0 의 해는?  〔보기: −4 < x < 1 / −4 ≤ x ≤ 1 / −1 ≤ x ≤ 4 / x ≤ −4 또는 x ≥ 1〕  → **−4 ≤ x ≤ 1** · 양변에 −1 을 곱하면 x² + 3x − 4 ≤ 0 (부등호 방향이 바뀐다).
  - (m2-2) [choice] 이차부등식 x² − 4x + 4 > 0 의 해는?  〔보기: 해가 없다 / x ≠ 2 인 모든 실수 / 모든 실수 / x = 2〕  → **x ≠ 2 인 모든 실수** · (x − (2))² 은 x = 2 일 때만 0, 나머지는 양수.
- 👾 m3 문제 3 · x축과 만나지 않을 때 (⏱ 3.6분)
  - (m3-1) [choice] 이차부등식 x² + 2x + 3 > 0 의 해는?  〔보기: 해가 없다 / x ≠ −1 인 모든 실수 / x = −1 / 모든 실수〕  → **모든 실수** · D < 0 → 그래프가 x축보다 항상 위 (식 = (x + 1)² + 2 > 0).
  - (m3-2) [choice] 이차부등식 x² + 2x + 3 < 0 의 해는?  〔보기: 모든 실수 / x ≠ −1 인 모든 실수 / 해가 없다 / x = −1〕  → **해가 없다** · D < 0 → 그래프가 x축보다 항상 위 (식 = (x + 1)² + 2 > 0).
- 👾 m4 문제 4 · 모든 실수에서 성립 ⛰ (⏱ 6.1분)
  - (m4-1) [choice] 모든 실수 x 에 대하여 이차부등식 x² + 2kx + (k + 2) > 0 이 성립한다 (k 는 실수). 이 조건을 이차방정식의 판별식 D 로 쓰면?  〔보기: D = 0 / D > 0 / D ≥ 0 / D < 0〕  → **D < 0** · 그래프가 x축과 만나지 않고 항상 위에 있어야 한다.
  - (m4-2) [choice] 모든 실수 x 에 대하여 이차부등식 x² + 2kx + (k + 2) > 0 이 성립한다 (k 는 실수). D/4 를 k 에 대한 식으로 나타내면?  〔보기: k² − k − 2 / k² + k + 2 / k² − k + 2 / 4k² − k − 2〕  → **k² − k − 2** · D/4 = k² − (상수항).
  - (m4-3) [choice] 모든 실수 x 에 대하여 이차부등식 x² + 2kx + (k + 2) > 0 이 성립한다 (k 는 실수). k 의 값의 범위는?  〔보기: −1 < k < 2 / −2 < k < 1 / k < −1 또는 k > 2 / −1 ≤ k ≤ 2〕  → **−1 < k < 2** · (k − (−1))(k − (2)) < 0.
- 👾 m5 🌱 여유 문제 · 해로 부등식 찾기 (⏱ 2.9분)
  - (m5-1) [number] 이차부등식 x² + px + q < 0 의 해가 2 < x < 5 일 때, p + q 의 값은? (p, q 는 상수)  → **3** · (x − (2))(x − (5)) < 0 을 전개: p = −7, q = 10.
- 👑 형성평가 4문항 (⏱ 7.2분) · 짝 = ['m1', 'm1', 'm2', 'm3']
  - (b-1) [choice] 이차부등식 x² − 2x − 3 < 0 의 해는?  〔보기: x < 3 / −1 < x < 3 / −3 < x < 1 / x < −1 또는 x > 3〕  → **−1 < x < 3** · (x + 1)(x − 3) < 0 → 그래프가 x축 아래인 부분 = 두 근 사이.
  - (b-2) [choice] 이차부등식 x² − 7x + 10 > 0 의 해는?  〔보기: x > 5 / x < −5 또는 x > −2 / 2 < x < 5 / x < 2 또는 x > 5〕  → **x < 2 또는 x > 5** · (x − 2)(x − 5) > 0 → 그래프가 x축 위인 부분 = 두 근의 바깥.
  - (b-3) [choice] 이차부등식 −x² − 3x + 4 ≥ 0 의 해는?  〔보기: −1 ≤ x ≤ 4 / −4 < x < 1 / −4 ≤ x ≤ 1 / x ≤ −4 또는 x ≥ 1〕  → **−4 ≤ x ≤ 1** · 양변에 −1 을 곱하면 x² + 3x − 4 ≤ 0 (부등호 방향이 바뀐다).
  - (b-4) [choice] 이차부등식 x² + 2x + 3 > 0 의 해는?  〔보기: 모든 실수 / x = −1 / 해가 없다 / x ≠ −1 인 모든 실수〕  → **모든 실수** · D < 0 → 그래프가 x축보다 항상 위 (식 = (x + 1)² + 2 > 0).
