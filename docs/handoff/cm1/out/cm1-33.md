## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 중학교: 표 읽기 · 순서쌍 (x, y)
- 💭 생각 열기: 매점 두 곳의 품목별 판매량 표 — 괄호로 묶어 숫자만 남기면 행렬이 된다.
- 📘 c1 행렬 · 행 · 열 · 성분: 수나 문자를 직사각형 모양으로 배열해 괄호로 묶은 것 = 행렬. 가로줄 = 행, 세로줄 = 열. m × n 행렬, (i, j) 성분 = 제i행과 제j열이 만나는 곳. · ✔ 개념 체크: 행이 2개, 열이 3개인 행렬은 3 × 2 행렬이다. → X
- 📘 c2 서로 같은 행렬: 두 행렬이 같은 꼴이고 같은 자리의 성분이 모두 같을 때 「서로 같다」고 하고 A = B 로 쓴다. · ✔ 개념 체크: 성분에 쓰인 수들이 같으면 자리가 달라도 두 행렬은 서로 같다. → X

- 👾 m1 문제 1 · 꼴과 성분 (⏱ 4.2분)
  - (m1-1) [choice] 행렬 (−1  5  4 ; −2  1  5) 의 꼴은? (; 는 행을 나누는 표시)  〔보기: 6 × 1 행렬 / 3 × 2 행렬 / 5 × 5 행렬 / 2 × 3 행렬〕  → **2 × 3 행렬** · 행(가로줄) 2개, 열(세로줄) 3개 → 행 × 열 순서로 2 × 3.
  - (m1-2) [number] 행렬 (2  5  −6 ; 8  1  −5) 의 (2, 1) 성분은? (; 는 행을 나누는 표시)  → **8** · 제2행(위에서 2번째 줄)과 제1열(왼쪽에서 1번째 줄)이 만나는 수.
- 👾 m2 문제 2 · aᵢⱼ 로 행렬 만들기 (⏱ 4.2분)
  - (m2-1) [number] 2 × 2 행렬 A 의 (i, j) 성분 aᵢⱼ 가 aᵢⱼ = i + j 일 때, A 의 (2, 1) 성분은?  → **3** · i = 2, j = 1 를 넣는다: i + j → 3.
  - (m2-2) [choice] 2 × 2 행렬 A 의 (i, j) 성분이 aᵢⱼ = i + j 일 때, 행렬 A 는? (; 는 행을 나누는 표시)  〔보기: (3  4 ; 4  5) / (2  3 ; 3  4) / (0  1 ; 1  2) / (4  3 ; 3  4)〕  → **(2  3 ; 3  4)** · a₁₁ = 2, a₁₂ = 3, a₂₁ = 3, a₂₂ = 4 를 차례로 놓는다.
- 👾 m3 문제 3 · 서로 같은 행렬 (⏱ 4.8분)
  - (m3-1) [number] 두 행렬 (x  1 ; 5  y) 와 (3  1 ; 5  −2) 가 서로 같을 때, x + y 의 값은? (; 는 행을 나누는 표시)  → **1** · 같은 자리 성분끼리 같다: x = 3, y = −2.
  - (m3-2) [number] 두 행렬 (x + y  0 ; 1  x − y) 와 (3  0 ; 1  1) 가 서로 같을 때, x 의 값은? (; 는 행을 나누는 표시)  → **2** · x + y = 3, x − y = 1 를 더하면 2x = 4.
- 👾 m4 문제 4 · 조건이 나뉜 성분 ⛰ (⏱ 5.9분)
  - (m4-1) [number] 2 × 2 행렬 A 의 (i, j) 성분 aᵢⱼ 가 i ≥ j 이면 aᵢⱼ = i + j, i < j 이면 aᵢⱼ = 2j − i 일 때, a₁₂ 의 값은?  → **3** · i = 1, j = 2 는 i < j → 2j − i 에 넣는다: 4 − 1.
  - (m4-2) [number] 2 × 2 행렬 A 의 (i, j) 성분 aᵢⱼ 가 i ≥ j 이면 aᵢⱼ = i + j, i < j 이면 aᵢⱼ = 2j − i 일 때, A 의 모든 성분의 합은?  → **12** · a₁₁ = 2, a₁₂ = 3, a₂₁ = 3, a₂₂ = 4 를 더한다.
- 👾 m5 🌱 여유 문제 · 표를 행렬로 읽기 (⏱ 2.9분)
  - (m5-1) [number] 매점 두 곳의 판매량을 행렬 (560  670 ; 890  570) 로 나타냈다. 제1행은 가 매점, 제2행은 나 매점이고 제1열은 김밥, 제2열은 라면의 판매량(개)이다. 나 매점의 김밥 판매량은? (; 는 행을 나누는 표시)  → **890** · 나 매점 = 제2행, 김밥 = 제1열 → (2, 1) 성분.

  - (b-1) [choice] 행렬 (−1  5  4 ; −2  1  5) 의 꼴은? (; 는 행을 나누는 표시)  〔보기: 2 × 3 행렬 / 3 × 2 행렬 / 5 × 5 행렬 / 6 × 1 행렬〕  → **2 × 3 행렬** · 행(가로줄) 2개, 열(세로줄) 3개 → 행 × 열 순서로 2 × 3.
