# 2차시 · 다항식의 곱셈과 곱셈 공식 — 시안 (공통수학1 · Ⅰ-1 다항식의 연산)

> ⏱ 예상 44.6분(여유 문제 빼고) · 여유 문제 +2.3분 · 어려운 문제(산) = m5 · 산 = 중단원 마무리 06 ⑴ 꼴(공통 부분 치환) · 본문에는 공식 대입만 있어 가져옴

## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 중학교 곱셈 공식: (a + b)², (a − b)², (a + b)(a − b), (x + a)(x + b) 빈칸 채우기 · 1차시: 동류항 정리
- 💭 생각 열기: 직사각형 땅을 네 구역으로 나눈 넓이의 합 = 전체 넓이 → (a + b)(x + y) = ax + ay + bx + by.
- 📘 c1 다항식의 곱셈 (분배법칙): 한 식의 각 항을 다른 식의 모든 항에 곱한 뒤 동류항끼리 정리한다. 교환 · 결합 · 분배법칙이 성립한다. · ✔ 개념 체크: (x + 2)(x² − x + 3) 을 전개하면 항이 6개 생기고, 동류항을 정리하면 4개가 된다. → O
- 📘 c2 곱셈 공식 (세 항의 제곱 · 세제곱 · 세제곱의 합과 차): (a + b + c)² = a² + b² + c² + 2ab + 2bc + 2ca · (a ± b)³ = a³ ± 3a²b + 3ab² ± b³ · (a ± b)(a² ∓ ab + b²) = a³ ± b³. · ✔ 개념 체크: (a + b)³ = a³ + b³ 이다. → X

- 👾 m1 문제 1 · 분배법칙으로 전개 (⏱ 4.2분)
  - (m1-1) [choice] (x + 2)(2x² − x + 3) 를 전개하면?  〔보기: 2x³ − 5x² + 5x − 6 / 2x³ − x² + 3x + 6 / 2x³ + 3x² + x + 6 / 2x³ + 3x² + 3x + 6〕  → **2x³ + 3x² + x + 6** · x 와 2 를 각각 뒤 식에 곱해 더한 뒤 동류항을 정리한다.
  - (m1-2) [number] (x² + 2xy + 2y²)(−x + 2y) 를 전개했을 때 xy² 의 계수는?  → **2** · xy² 이 나오는 곱: 2xy × 2y, 2y² × −x → 4 + (−2).
- 👾 m2 문제 2 · 세 항의 제곱 (⏱ 3.6분)
  - (m2-1) [choice] (a − b + 2c)² 을 전개하면?  〔보기: a² + b² + 4c² / a² + b² + 4c² − ab − 2bc + 2ac / a² + b² + 4c² + 2ab + 4bc + 4ac / a² + b² + 4c² − 2ab − 4bc + 4ac〕  → **a² + b² + 4c² − 2ab − 4bc + 4ac** · (a + b + c)² = a² + b² + c² + 2ab + 2bc + 2ca 에 부호까지 넣어 대입한다.
  - (m2-2) [choice] (a + b − 1)² 을 전개하면?  〔보기: a² + b² + 2ab − 2a − 2b − 1 / a² + b² + 2ab − 2a − 2b + 1 / a² + b² + 2ab − a − b + 1 / a² + b² + 1〕  → **a² + b² + 2ab − 2a − 2b + 1** · c 자리에 −1 를 넣는다: c² = 1, 2bc 와 2ca 의 부호에 주의.
- 👾 m3 문제 3 · 세제곱 전개 (⏱ 3.6분)
  - (m3-1) [choice] (x − 1)³ 을 전개하면?  〔보기: x³ − 1 / x³ − 3x² + 3x + 1 / x³ − x² + x − 1 / x³ − 3x² + 3x − 1〕  → **x³ − 3x² + 3x − 1** · (a ± b)³ = a³ ± 3a²b + 3ab² ± b³ 에 a = x, b = 1 대입.
  - (m3-2) [choice] (2a − b)³ 을 전개하면?  〔보기: 8a³ − 12a²b + 6ab² − b³ / 8a³ + 12a²b + 6ab² + b³ / 8a³ − 4a²b + 2ab² − b³ / 8a³ − b³〕  → **8a³ − 12a²b + 6ab² − b³** · 2a 와 b 를 통째로 a, b 로 보고 세제곱 공식에 넣는다(계수도 세제곱).
- 👾 m4 문제 4 · a³ ± b³ 꼴 (⏱ 4.3분)
  - (m4-1) [ox] (x + 2)(x² + 2x + 4) = x³ + 8 이다.  → **X** · 가운데 항의 부호가 앞 괄호와 반대여야 a³ + b³ 이 된다.
  - (m4-2) [choice] (x − 2)(x² + 2x + 4) 를 전개하면?  〔보기: x³ + 4 / x³ + 8 / x³ − 8 / x³ − 4x² + 8x − 8〕  → **x³ − 8** · (a − b)(a² + ab + b²) = a³ − b³ 꼴 → b = 2.
  - (m4-3) [choice] (2x + 3y)(4x² − 6xy + 9y²) 를 전개하면?  〔보기: 8x³ − 27y³ / 4x³ + 9y³ / 2x³ + 3y³ / 8x³ + 27y³〕  → **8x³ + 27y³** · a = 2x, b = 3y 로 보면 a³ ± b³ 꼴 → 계수도 세제곱한다.
- 👾 m5 문제 5 · 공통 부분을 한 문자로 ⛰ (⏱ 6.1분)
  - (m5-1) [choice] (x² − 2x − 3)(x² − 2x − 2) 를 전개하려고 한다. x² − 2x = t 로 놓으면 이 식은?  〔보기: (t − 3)² / t² + 6 / (t + 3)(t + 2) / (t − 3)(t − 2)〕  → **(t − 3)(t − 2)** · 두 괄호에 똑같이 들어 있는 부분을 한 문자로 바꾼다.
  - (m5-2) [choice] (t − 3)(t − 2) 를 전개하면?  〔보기: t² + 5t + 6 / t² + 6t − 5 / t² − 5t + 6 / t² + 6〕  → **t² − 5t + 6** · (t + a)(t + b) = t² + (a + b)t + ab.
  - (m5-3) [choice] (x² − 2x − 3)(x² − 2x − 2) 를 전개하면?  〔보기: x⁴ − 4x³ − x² + 10x + 6 / x⁴ − 4x³ + 4x² + 6 / x⁴ − 9x² − 2x + 6 / x⁴ − 4x³ − x² + 10x − 6〕  → **x⁴ − 4x³ − x² + 10x + 6** · t = x² − 2x 로 놓고 전개한 뒤 t 를 되돌려 다시 전개한다.
- 👾 m6 🌱 여유 문제 · 합차 공식 되풀이 (⏱ 2.3분)
  - (m6-1) [choice] (a − 1)(a + 1)(a² + 1)(a⁴ + 1) 를 전개하면?  〔보기: a⁸ − 1 / a⁷ − 1 / a⁸ + 1 / a¹⁶ − 1〕  → **a⁸ − 1** · (a − b)(a + b) = a² − b² 을 앞에서부터 차례로 되풀이한다.
- 👑 형성평가 4문항 (⏱ 7.8분) · 짝 = ['m1', 'm2', 'm3', 'm4']
  - (b-1) [number] (x − 1)(x² − x + 1) 를 전개했을 때 x 의 계수는?  → **2** · x 가 나오는 곱: x × (1) 와 (−1) × (−x) → 1 + (1).
  - (b-2) [choice] (a − b + 2c)² 을 전개하면?  〔보기: a² + b² + 4c² / a² + b² + 4c² + 2ab + 4bc + 4ac / a² + b² + 4c² − ab − 2bc + 2ac / a² + b² + 4c² − 2ab − 4bc + 4ac〕  → **a² + b² + 4c² − 2ab − 4bc + 4ac** · (a + b + c)² = a² + b² + c² + 2ab + 2bc + 2ca 에 부호까지 넣어 대입한다.
  - (b-3) [choice] (x − 1)³ 을 전개하면?  〔보기: x³ − 3x² + 3x + 1 / x³ − 3x² + 3x − 1 / x³ − x² + x − 1 / x³ − 1〕  → **x³ − 3x² + 3x − 1** · (a ± b)³ = a³ ± 3a²b + 3ab² ± b³ 에 a = x, b = 1 대입.
  - (b-4) [choice] (x − 2)(x² + 2x + 4) 를 전개하면?  〔보기: x³ + 4 / x³ + 8 / x³ − 4x² + 8x − 8 / x³ − 8〕  → **x³ − 8** · (a − b)(a² + ab + b²) = a³ − b³ 꼴 → b = 2.
