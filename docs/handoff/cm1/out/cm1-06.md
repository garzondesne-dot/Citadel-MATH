## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 4차시: A = BQ + R · 5차시: 항등식에 수 대입하기
- 💭 생각 열기: 제품을 부수지 않고 검사하듯, 직접 나누지 않고도 나머지를 안다: f(x) = (x − α)Q(x) + R 에 x = α 를 넣으면?
- 📘 c1 나머지정리: 다항식 f(x) 를 일차식 x − α 로 나누었을 때의 나머지 R = f(α). 일차식 ax + b 로 나누면 R = f(−b/a). · ✔ 개념 체크: 다항식 f(x) 를 x + 1 로 나누었을 때의 나머지는 f(1) 이다. → X
- 📘 c2 이차식으로 나눈 나머지: 이차식으로 나눈 나머지는 일차 이하 → ax + b 로 놓고, 나누는 식이 0 이 되는 두 수를 대입해 연립한다.

- 👾 m1 문제 1 · f(α) 로 나머지 구하기 (⏱ 4.8분)
  - (m1-1) [number] 다항식 f(x) = 2x³ + 4x² − 3x + 1 을 x − 1 로 나누었을 때의 나머지는?  → **4** · 나머지정리: 나머지 = f(1) → x 에 1 를 대입해 계산.
  - (m1-2) [number] 다항식 f(x) = 2x³ + 4x² − 3x + 1 을 x + 2 로 나누었을 때의 나머지는?  → **7** · 나머지정리: 나머지 = f(−2) → x 에 −2 를 대입해 계산.
- 👾 m2 문제 2 · ax + b 로 나눈 나머지 (⏱ 4.2분)
  - (m2-1) [choice] 다항식 f(x) 를 일차식 2x + 1 로 나누었을 때의 나머지는 f(□) 이다. □ 에 알맞은 수는?  〔보기: −1 / −1/2 / −2 / 1/2〕  → **−1/2** · 2x + 1 = 0 이 되는 x 의 값을 대입한다 → x = −1/2.
  - (m2-2) [number] 다항식 f(x) = 12x³ − x + 2 을 2x + 1 로 나누었을 때의 나머지는?  → **1** · f(−1/2) 를 계산한다.
- 👾 m3 문제 3 · 나머지로 계수 찾기 (⏱ 4.2분)
  - (m3-1) [choice] 다항식 f(x) = x³ + ax² + x + 7 을 x − 2 로 나누었을 때의 나머지가 5 이다 (a 는 상수). 이 조건을 식으로 쓰면?  〔보기: f(2) = 0 / f(2) = 5 / f(5) = 2 / f(−2) = 5〕  → **f(2) = 5** · x − 2 로 나눈 나머지 = f(2).
  - (m3-2) [number] 다항식 f(x) = x³ + ax² + x + 7 을 x − 2 로 나누었을 때의 나머지가 5 이다 (a 는 상수). a 의 값은?  → **-3** · f(2) = 8 + 4a + (9) = 5 을 푼다.
- 👾 m4 문제 4 · 이차식으로 나눈 나머지 ⛰ (⏱ 6.5분)
  - (m4-1) [choice] 다항식 f(x) 를 x − 1 로 나눈 나머지는 −1, x + 3 로 나눈 나머지는 7 이다. f(x) 를 (x − 1)(x + 3) 로 나눈 나머지를 구할 때, 나머지를 어떻게 놓아야 하는가?  〔보기: 0 / ax + b (일차 이하의 식) / ax² + bx + c (이차식) / a (상수)〕  → **ax + b (일차 이하의 식)** · 이차식으로 나눈 나머지는 일차 이하의 다항식이다.
  - (m4-2) [multi] 다항식 f(x) 를 x − 1 로 나눈 나머지는 −1, x + 3 로 나눈 나머지는 7 이다. f(x) = (x − 1)(x + 3)Q(x) + ax + b 로 놓을 때, 맞는 식을 모두 고르시오.  〔보기: a + b = −1 / −a + b = −1 / −3a + b = 7 / −3a + b = −1 / a + b = 7〕  → **a + b = −1 · −3a + b = 7** · x = 1, x = −3 를 대입하면 Q(x) 항이 사라진다.
  - (m4-3) [choice] 다항식 f(x) 를 x − 1 로 나눈 나머지는 −1, x + 3 로 나눈 나머지는 7 이다. f(x) 를 (x − 1)(x + 3) 로 나누었을 때의 나머지는?  〔보기: x − 2 / −2x − 1 / −2x + 1 / 2x + 1〕  → **−2x + 1** · a + b = −1, −3a + b = 7 을 연립 → a = −2, b = 1.
- 👾 m5 🌱 여유 문제 · 몫을 다시 나누기 (⏱ 2.9분)
  - (m5-1) [number] 다항식 f(x) 를 x − 1 로 나눈 몫이 Q(x), 나머지가 3 이고, Q(x) 를 x − 2 로 나눈 나머지가 2 이다. f(2) 의 값은?  → **5** · f(x) = (x − 1)Q(x) + (3), Q(2) = 2 → (1) × (2) + (3).
- 👑 형성평가 4문항 (⏱ 9.0분) · 짝 = ['m1', 'm2', 'm3', 'm4']
  - (b-1) [number] 다항식 f(x) = 2x³ + 4x² − 3x + 1 을 x + 1 로 나누었을 때의 나머지는?  → **6** · 나머지정리: 나머지 = f(−1) → x 에 −1 를 대입해 계산.
  - (b-2) [number] 다항식 f(x) = 12x³ − x + 2 을 2x + 1 로 나누었을 때의 나머지는?  → **1** · f(−1/2) 를 계산한다.
  - (b-3) [number] 다항식 f(x) = x³ + ax² + x + 7 을 x − 2 로 나누었을 때의 나머지가 5 이다 (a 는 상수). a 의 값은?  → **-3** · f(2) = 8 + 4a + (9) = 5 을 푼다.
  - (b-4) [choice] 다항식 f(x) 를 x − 1 로 나눈 나머지는 −1, x + 3 로 나눈 나머지는 7 이다. f(x) 를 (x − 1)(x + 3) 로 나누었을 때의 나머지는?  〔보기: −2x − 1 / x − 2 / −2x + 1 / 2x + 1〕  → **−2x + 1** · a + b = −1, −3a + b = 7 을 연립 → a = −2, b = 1.
