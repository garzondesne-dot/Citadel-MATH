# 10차시 · 복소수의 뜻 — 시안 (공통수학1 · Ⅱ-1 복소수와 이차방정식)

> 교과서 46 ~ 47쪽 · 목표: 복소수의 뜻을 알고, 서로 같을 조건과 켤레복소수를 구할 수 있다.
> ⏱ 예상 45.5분(여유 문제 빼고) · 여유 문제 +2.3분 · 어려운 문제(산) = m4 · 산 = 중단원 마무리 01번 꼴(본문에 어려운 문제가 없어 가져옴)
> 문항 98줄(판 0 ~ 6) · 계산 검산 ✅ 98 · 눈으로 확인 0 · ❌ 0 · 글 검사 걸림 0 · 같은 판 0

## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 중학교: 제곱근 · x² = 4 의 해 · 실수는 제곱하면 0 이상
- 💭 생각 열기: x² = −1 의 해는 실수에 없다 → 제곱해서 −1 이 되는 새 수 i 를 만든다.
- 📘 c1 허수단위 i 와 복소수: i² = −1. 실수 a, b 에 대하여 a + bi 꼴의 수 = 복소수(a 실수부분 · b 허수부분). b = 0 이면 실수, b ≠ 0 이면 허수. · ✔ 개념 체크: 실수 5 는 복소수가 아니다. → X
- 📘 c2 서로 같은 복소수 · 켤레복소수: a + bi = c + di ⟺ a = c, b = d (a, b, c, d 실수). a + bi 의 켤레복소수 = a − bi. · ✔ 개념 체크: 3 − 2i 의 켤레복소수는 −3 + 2i 이다. → X

- 👾 m1 문제 1 · 실수부분과 허수부분 (⏱ 4.5분)
  - (m1-1) [number] 복소수 3 − i 의 허수부분은?  → **-1** · a + bi 에서 a 가 실수부분, b 가 허수부분(i 는 빼고 수만).
  - (m1-2) [multi] 다음 중 허수인 것을 모두 고르시오.  〔보기: 2 / 1 + i / 5i / √3〕  → **1 + i · 5i** · 허수 = 허수부분이 0 이 아닌 복소수(i 가 붙은 부분이 남아 있는 수).
- 👾 m2 문제 2 · 서로 같은 복소수 (⏱ 4.8분)
  - (m2-1) [number] 등식 (x − 1) + (y + 2)i = 3 − 4i 를 만족시키는 실수 x, y 에 대하여 x 의 값은?  → **4** · 실수부분끼리 같다 → x 가 든 괄호 = 3.
  - (m2-2) [number] 등식 (x − 1) + (y + 2)i = 3 − 4i 를 만족시키는 실수 x, y 에 대하여 y 의 값은?  → **-6** · 허수부분끼리 같다 → y 가 든 괄호 = −4.
- 👾 m3 문제 3 · 켤레복소수 (⏱ 4.2분)
  - (m3-1) [choice] 복소수 2 + 3i 의 켤레복소수는?  〔보기: −2 + 3i / 2 − 3i / −2 − 3i / 3 + 2i〕  → **2 − 3i** · 켤레복소수 = 허수부분의 부호만 바꾼 수.
  - (m3-2) [number] 복소수 a + bi 의 켤레복소수가 2 − 3i 일 때, a + b 의 값은? (a, b 는 실수)  → **5** · a + bi = 2 + 3i → a = 2, b = 3.
- 👾 m4 문제 4 · 두 식을 세워 x, y 구하기 ⛰ (⏱ 8.0분)
  - (m4-1) [multi] 등식 (x + y) + (x − y)i = 5 − i 를 만족시키는 실수 x, y 에 대하여 맞는 식을 모두 고르시오.  〔보기: x + y = 5 / x − y = 5 / x − y = −1 / x + y = −1〕  → **x + y = 5 · x − y = −1** · 실수부분끼리, 허수부분끼리 각각 같다.
  - (m4-2) [number] 등식 (x + y) + (x − y)i = 5 − i 를 만족시키는 실수 x, y 에 대하여 x 의 값은?  → **2** · x + y = 5, x − y = −1 를 더하면 2x = 4.
  - (m4-3) [number] 등식 (x + y) + (x − y)i = 5 − i 를 만족시키는 실수 x, y 에 대하여 y 의 값은?  → **3** · x + y = 5, x − y = −1 를 빼면 2y = 6.
- 👾 m5 🌱 여유 문제 · 제곱하면 음수 (⏱ 2.3분)
  - (m5-1) [choice] 제곱하여 −9 이 되는 수를 모두 구한 것은?  〔보기: 3i / 3, −3 / −3i / 3i, −3i〕  → **3i, −3i** · (3i)² = 9i² = −9, (−3i)² 도 같다.
- 👑 형성평가 4문항 (⏱ 9.0분) · 짝 = ['m1', 'm2', 'm3', 'm4']
  - (b-1) [number] 복소수 3 − i 의 허수부분은?  → **-1** · a + bi 에서 a 가 실수부분, b 가 허수부분(i 는 빼고 수만).
  - (b-2) [number] 등식 (x − 1) + (y + 2)i = 3 − 4i 를 만족시키는 실수 x, y 에 대하여 x 의 값은?  → **4** · 실수부분끼리 같다 → x 가 든 괄호 = 3.
  - (b-3) [choice] 복소수 2 + 3i 의 켤레복소수는?  〔보기: 3 + 2i / 2 − 3i / −2 − 3i / −2 + 3i〕  → **2 − 3i** · 켤레복소수 = 허수부분의 부호만 바꾼 수.
  - (b-4) [number] 등식 (x + y) + (x − y)i = 5 − i 를 만족시키는 실수 x, y 에 대하여 x 의 값은?  → **2** · x + y = 5, x − y = −1 를 더하면 2x = 4.
