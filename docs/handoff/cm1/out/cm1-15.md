# 15차시 · 두 수를 근으로 하는 이차방정식과 이차식의 인수분해 — 시안 (공통수학1 · Ⅱ-1 복소수와 이차방정식)

> 교과서 56 ~ 58쪽 · 목표: 두 수를 근으로 하는 이차방정식을 만들고, 이차식을 복소수의 범위에서 인수분해 할 수 있다.
> ⏱ 예상 40.9분(여유 문제 빼고) · 여유 문제 +2.3분 · 어려운 문제(산) = m4 · 산 = 본문 58쪽 생각 넓히기 꼴(본문에 있어 중단원에서 안 가져옴)
> 문항 105줄(판 0 ~ 6) · 계산 검산 ✅ 105 · 눈으로 확인 0 · ❌ 0 · 글 검사 걸림 0 · 같은 판 0

## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 14차시: α + β = −b/a, αβ = c/a · 11차시: (a + bi)(a − bi) = a² + b²
- 💭 생각 열기: 근을 알면 방정식을 거꾸로 만들 수 있다: x² − (합)x + (곱) = 0.
- 📘 c1 두 수를 근으로 하는 이차방정식: 두 수 α, β 를 근으로 하고 x² 의 계수가 1 인 이차방정식: x² − (α + β)x + αβ = 0. · ✔ 개념 체크: 두 수 2, 3 을 근으로 하는 이차방정식은 x² + 5x + 6 = 0 이다. → X
- 📘 c2 이차식의 인수분해 (복소수 범위): ax² + bx + c = 0 의 두 근이 α, β 이면 ax² + bx + c = a(x − α)(x − β). 계수가 실수이면 허근은 켤레끼리 짝.

- 👾 m1 문제 1 · 두 근으로 방정식 만들기 (⏱ 4.9분)
  - (m1-1) [choice] 두 수 2, −5 를 근으로 하고 x² 의 계수가 1 인 이차방정식은?  〔보기: x² + 3x − 10 = 0 / x² + 10x − 3 = 0 / x² − 3x − 10 = 0 / x² + 3x + 10 = 0〕  → **x² + 3x − 10 = 0** · x² − (합)x + (곱) = 0: 합 −3, 곱 −10.
  - (m1-2) [choice] 두 수 2 + √5, 2 − √5 를 근으로 하고 x² 의 계수가 1 인 이차방정식은?  〔보기: x² − 4x − 1 = 0 / x² + x + 4 = 0 / x² + 4x − 1 = 0 / x² − 4x + 1 = 0〕  → **x² − 4x − 1 = 0** · 합 = 4, 곱 = 4 − 5 = −1 (합차 공식).
  - (m1-3) [choice] 두 수 2 + 3i, 2 − 3i 를 근으로 하고 x² 의 계수가 1 인 이차방정식은?  〔보기: x² − 4x + 13 = 0 / x² − 13x + 4 = 0 / x² + 4x + 13 = 0 / x² − 4x − 13 = 0〕  → **x² − 4x + 13 = 0** · 합 = 4, 곱 = 4 − (3i)² = 4 + 9.
- 👾 m2 문제 2 · 새 두 근으로 방정식 만들기 (⏱ 3.6분)
  - (m2-1) [choice] 이차방정식 x² + 2x + 3 = 0 의 두 근을 α, β 라 할 때, α + β 와 αβ 를 두 근으로 하고 x² 의 계수가 1 인 이차방정식은?  〔보기: x² − x − 6 = 0 / x² + x − 6 = 0 / x² + 6x + 1 = 0 / x² − x + 6 = 0〕  → **x² − x − 6 = 0** · 새 두 근 = −2, 3 → 합 1, 곱 −6.
  - (m2-2) [choice] 이차방정식 x² + 2x + 3 = 0 의 두 근을 α, β 라 할 때, α + 1 과 β + 1 을 두 근으로 하고 x² 의 계수가 1 인 이차방정식은?  〔보기: x² − 2x = 0 / x² − 2 = 0 / x² + 2 = 0〕  → **x² + 2 = 0** · 합 = (α + β) + 2 = 0, 곱 = αβ + (α + β) + 1 = 2.
- 👾 m3 문제 3 · 복소수 범위에서 인수분해 (⏱ 3.6분)
  - (m3-1) [choice] 이차식 x² + 7 을 복소수의 범위에서 인수분해 하면?  〔보기: (x + 7i)(x − 7i) / (x + √7)(x − √7) / (x + √7 i)² / (x + √7 i)(x − √7 i)〕  → **(x + √7 i)(x − √7 i)** · x² + 7 = 0 의 근 x = ±√7 i → (x − α)(x − β).
  - (m3-2) [choice] 이차식 x² − 6x + 10 을 복소수의 범위에서 인수분해 하면?  〔보기: (x − 3 − 1)(x − 3 + 1) / (x + 3 − 1)(x + 3 + 1) / (x − 3 − i)(x − 3 + i) / (x + 3 − i)(x + 3 + i)〕  → **(x − 3 − i)(x − 3 + i)** · 근이 x = 3 ± i → {x − (3 + i)}{x − (3 − i)}.
- 👾 m4 문제 4 · 한 근이 허수일 때 a, b ⛰ (⏱ 7.6분)
  - (m4-1) [choice] 계수가 실수인 이차방정식 x² + ax + b = 0 의 한 근이 2 + i 이다. 다른 한 근은?  〔보기: 2 − i / −2 + i / 1 + 2i / −2 − i〕  → **2 − i** · 계수가 실수이면 허근은 켤레복소수끼리 짝으로 나온다.
  - (m4-2) [number] 계수가 실수인 이차방정식 x² + ax + b = 0 의 한 근이 2 + i 이다. a 의 값은?  → **-4** · 두 근 2 + i, 2 − i 의 합 = 4 = −a.
  - (m4-3) [number] 계수가 실수인 이차방정식 x² + ax + b = 0 의 한 근이 2 + i 이다. b 의 값은?  → **5** · 두 근의 곱 = 4 + 1 = b.
- 👾 m5 🌱 여유 문제 · x² 의 계수가 1 이 아닐 때 (⏱ 2.3분)
  - (m5-1) [choice] 두 수 1, −3 를 근으로 하고 x² 의 계수가 2 인 이차방정식은?  〔보기: x² + 2x − 3 = 0 / 2x² + 4x − 6 = 0 / 2x² − 4x − 6 = 0 / 2x² + 2x − 3 = 0〕  → **2x² + 4x − 6 = 0** · 2(x² − (합)x + (곱)) = 0 — 전체에 2 를 곱한다.
- 👑 형성평가 4문항 (⏱ 7.2분) · 짝 = ['m1', 'm1', 'm3', 'm4']
  - (b-1) [choice] 두 수 2, −5 를 근으로 하고 x² 의 계수가 1 인 이차방정식은?  〔보기: x² + 3x − 10 = 0 / x² + 10x − 3 = 0 / x² + 3x + 10 = 0 / x² − 3x − 10 = 0〕  → **x² + 3x − 10 = 0** · x² − (합)x + (곱) = 0: 합 −3, 곱 −10.
  - (b-2) [choice] 두 수 2 + 3i, 2 − 3i 를 근으로 하고 x² 의 계수가 1 인 이차방정식은?  〔보기: x² − 4x + 13 = 0 / x² − 13x + 4 = 0 / x² + 4x + 13 = 0 / x² − 4x − 13 = 0〕  → **x² − 4x + 13 = 0** · 합 = 4, 곱 = 4 − (3i)² = 4 + 9.
  - (b-3) [choice] 이차식 x² − 6x + 10 을 복소수의 범위에서 인수분해 하면?  〔보기: (x − 3 − 1)(x − 3 + 1) / (x + 3 − 1)(x + 3 + 1) / (x + 3 − i)(x + 3 + i) / (x − 3 − i)(x − 3 + i)〕  → **(x − 3 − i)(x − 3 + i)** · 근이 x = 3 ± i → {x − (3 + i)}{x − (3 − i)}.
  - (b-4) [choice] 계수가 실수인 이차방정식 x² + ax + b = 0 의 한 근이 2 + i 이다. 다른 한 근은?  〔보기: 2 − i / −2 + i / 1 + 2i / −2 − i〕  → **2 − i** · 계수가 실수이면 허근은 켤레복소수끼리 짝으로 나온다.
