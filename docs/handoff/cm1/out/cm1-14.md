## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 3차시: a² + b² = (a + b)² − 2ab · 13차시: 근의 공식
- 💭 생각 열기: 근을 구하지 않아도 계수만 보면 두 근의 합과 곱을 안다 — 2x² − 7x + 3 = 0 의 두 근을 더하고 곱해 보자.
- 📘 c1 근과 계수의 관계: ax² + bx + c = 0 의 두 근 α, β: α + β = −b/a, αβ = c/a. · ✔ 개념 체크: 이차방정식 x² − 5x + 3 = 0 의 두 근의 합은 −5 이다. → X
- 📘 c2 합과 곱으로 식의 값: α² + β², 1/α + 1/β, (α + 1)(β + 1) 처럼 두 근을 바꿔도 같은 식은 α + β 와 αβ 로 고쳐 계산한다(3차시 공식).

- 👾 m1 문제 1 · 두 근의 합과 곱 (⏱ 3.6분)
  - (m1-1) [choice] 이차방정식 2x² + 7x − 1 = 0 의 두 근의 합은?  〔보기: 7/2 / −7 / −1/2 / −7/2〕  → **−7/2** · 두 근의 합 = −b/a = −(7)/2.
  - (m1-2) [choice] 이차방정식 2x² + 7x − 1 = 0 의 두 근의 곱은?  〔보기: −1/2 / −7/2 / −1 / 1/2〕  → **−1/2** · 두 근의 곱 = c/a = (−1)/2.
- 👾 m2 문제 2 · α² + β², 1/α + 1/β (⏱ 4.2분)
  - (m2-1) [number] 이차방정식 x² − 4x + 5 = 0 의 두 근을 α, β 라 할 때, α² + β² 의 값은?  → **6** · α + β = 4, αβ = 5 → (α + β)² − 2αβ = 16 − (10).
  - (m2-2) [choice] 이차방정식 x² − 4x + 5 = 0 의 두 근을 α, β 라 할 때, 1/α + 1/β 의 값은?  〔보기: 4/5 / −4/5 / 5/4 / 1/4〕  → **4/5** · 통분: (α + β)/(αβ) = (4)/(5).
- 👾 m3 문제 3 · (α + 1)(β + 1), β/α + α/β (⏱ 4.2분)
  - (m3-1) [number] 이차방정식 x² + 3x + 4 = 0 의 두 근을 α, β 라 할 때, (α + 1)(β + 1) 의 값은?  → **2** · 전개: αβ + (α + β) + 1 = (4) + (−3) + 1.
  - (m3-2) [choice] 이차방정식 x² + 3x + 4 = 0 의 두 근을 α, β 라 할 때, β/α + α/β 의 값은?  〔보기: 1/4 / 4 / −1/4 / 9/4〕  → **1/4** · 통분: (α² + β²)/(αβ) = (1)/(4).
- 👾 m4 문제 4 · 한 근이 다른 근의 몇 배 ⛰ (⏱ 7.6분)
  - (m4-1) [choice] 이차방정식 x² − 6x + k = 0 의 한 근이 다른 근의 2배이다 (k 는 실수). 두 근을 어떻게 놓으면 좋은가?  〔보기: α, 2α / α, 1/α / α, −2α / α, α + 2〕  → **α, 2α** · 「2배」이므로 작은 쪽을 α 라 하면 다른 근은 2α.
  - (m4-2) [number] 이차방정식 x² − 6x + k = 0 의 한 근이 다른 근의 2배이다 (k 는 실수). 두 근을 α, 2α 로 놓고 두 근의 합을 이용하여 α 의 값을 구하면?  → **2** · α + 2α = 3α = 6 (두 근의 합 = x 의 계수의 부호를 바꾼 값).
  - (m4-3) [number] 이차방정식 x² − 6x + k = 0 의 한 근이 다른 근의 2배이다 (k 는 실수). k 의 값은?  → **8** · 두 근 2, 4 의 곱 = k.
- 👾 m5 🌱 여유 문제 · α³ + β³ (⏱ 2.9분)
  - (m5-1) [number] 이차방정식 x² − 2x − 4 = 0 의 두 근을 α, β 라 할 때, α³ + β³ 의 값은?  → **32** · (α + β)³ − 3αβ(α + β) = (2)³ − 3 × (−4) × (2).
- 👑 형성평가 4문항 (⏱ 8.4분) · 짝 = ['m1', 'm1', 'm2', 'm3']
  - (b-1) [choice] 이차방정식 2x² + 7x − 1 = 0 의 두 근의 합은?  〔보기: −7 / −7/2 / 7/2 / −1/2〕  → **−7/2** · 두 근의 합 = −b/a = −(7)/2.
  - (b-2) [choice] 이차방정식 2x² + 7x − 1 = 0 의 두 근의 곱은?  〔보기: −1/2 / −7/2 / 1/2 / −1〕  → **−1/2** · 두 근의 곱 = c/a = (−1)/2.
  - (b-3) [number] 이차방정식 x² − 4x + 5 = 0 의 두 근을 α, β 라 할 때, α² + β² 의 값은?  → **6** · α + β = 4, αβ = 5 → (α + β)² − 2αβ = 16 − (10).
  - (b-4) [number] 이차방정식 x² + 3x + 4 = 0 의 두 근을 α, β 라 할 때, (α + 1)(β + 1) 의 값은?  → **2** · 전개: αβ + (α + β) + 1 = (4) + (−3) + 1.
