## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 20차시: 인수분해로 삼차 · 사차방정식 풀기 · 12차시: i 의 거듭제곱의 규칙
- 💭 생각 열기: 식 안에 같은 덩어리가 보이면 한 문자로. 그리고 x³ = 1 의 허근 ω 는 i 처럼 「세 박자」로 돈다.
- 📘 c1 공통부분이 있는 사차방정식: x² + bx 같은 공통부분을 X 로 놓아 X 에 대한 이차방정식을 풀고, X 값마다 x 에 대한 이차방정식을 다시 푼다.
- 📘 c2 삼차방정식의 활용과 x³ = 1 의 허근: 부피 문제 = 삼차방정식(양수인 근만). x³ = 1 의 허근 ω: ω³ = 1, ω² + ω + 1 = 0. · ✔ 개념 체크: x³ = 1 의 한 허근을 ω 라 하면 ω² + ω + 1 = 0 이다. → O

- 👾 m1 문제 1 · 공통부분을 X 로 (⏱ 3.6분)
  - (m1-1) [choice] 사차방정식 (x² + x)² − 8(x² + x) + 12 = 0 에서 x² + x = X 로 놓으면 X 의 값은?  〔보기: X = 2 / X = 2 또는 X = 6 / X = −6 또는 X = −2 / X = 8 또는 X = 12〕  → **X = 2 또는 X = 6** · X² − 8X + 12 = 0 을 인수분해 한다.
  - (m1-2) [choice] 사차방정식 (x² + x)² − 8(x² + x) + 12 = 0 에서 x² + x = X 로 놓으면 X = 2 또는 X = 6 이다. 이 사차방정식의 해를 모두 구한 것은?  〔보기: x = −3 또는 x = −2 또는 x = 1 또는 x = 2 / x = −2 또는 x = −1 또는 x = 2 또는 x = 3 / x = 2 또는 x = 6 / x = 1 또는 x = 2〕  → **x = −3 또는 x = −2 또는 x = 1 또는 x = 2** · x² + x = 2, x² + x = 6 두 이차방정식을 각각 푼다.
- 👾 m2 문제 2 · 한 근을 알 때 (⏱ 4.2분)
  - (m2-1) [number] 삼차방정식 x³ + ax² + x + 6 = 0 의 한 근이 2 이다 (a 는 상수). a 의 값은?  → **-4** · x = 2 를 대입하면 a 에 대한 일차방정식이 된다.
  - (m2-2) [choice] 삼차방정식 x³ − 4x² + x + 6 = 0 의 한 근이 2 일 때, 나머지 두 근은?  〔보기: −1, −3 / −1, 3 / 2, −3 / −3, 1〕  → **−1, 3** · x − (2) 로 조립제법 → 몫(이차식) = 0 을 푼다.
- 👾 m3 문제 3 · 직육면체의 부피 (⏱ 4.2분)
  - (m3-1) [choice] 가로, 세로, 높이가 각각 x, x + 1, x + 2 인 직육면체의 부피가 60 이다. x 에 대한 방정식을 세워 정리하면?  〔보기: x³ + 3x² + 2x + 60 = 0 / x³ + 3x² + 2x − 60 = 0 / x³ + 3x² − 60 = 0〕  → **x³ + 3x² + 2x − 60 = 0** · x(x + 1)(x + 2) = 60 를 전개해 우변을 넘긴다.
  - (m3-2) [number] 가로, 세로, 높이가 각각 x, x + 1, x + 2 인 직육면체의 부피가 60 이다. x 의 값은? (x 는 양수)  → **3** · x = 3 을 넣으면 3 × 4 × 5 = 60. x 가 양수일 때 부피는 x 가 커질수록 커지므로 답은 하나.
- 👾 m4 문제 4 · x³ = 1 의 허근 ω ⛰ (⏱ 7.6분)
  - (m4-1) [number] 방정식 x³ = 1 의 한 허근을 ω 라 할 때, ω³ 의 값은?  → **1** · ω 는 x³ = 1 의 근 → ω³ = 1 → ω³ = (ω³)¹ = 1.
  - (m4-2) [number] 방정식 x³ = 1 의 한 허근을 ω 라 할 때, x³ − 1 = (x − 1)(x² + x + 1) 임을 이용하여 ω² + ω + 1 의 값을 구하면?  → **0** · ω 는 허근이므로 x − 1 = 0 이 아닌 x² + x + 1 = 0 의 근이다.
  - (m4-3) [choice] 방정식 x³ = 1 의 한 허근을 ω 라 할 때, ω¹⁰ + ω⁵ + 1 의 값은? (ω³ = 1, ω² + ω + 1 = 0)  〔보기: 0 / 3 / 1 / −1〕  → **0** · ω¹⁰ = ω, ω⁵ = ω² (지수를 3 으로 나눈 나머지) → ω + ω² + 1.
- 👾 m5 🌱 여유 문제 · 네 근 살펴보기 (⏱ 2.9분)
  - (m5-1) [number] 사차방정식 x⁴ − 5x² + 4 = 0 의 네 근 중 가장 큰 근과 가장 작은 근의 곱은?  → **-4** · (x² − 1)(x² − 4) = 0 → x = ±1, ±2 → 2 × (−2).
- 👑 형성평가 4문항 (⏱ 9.0분) · 짝 = ['m1', 'm2', 'm3', 'm4']
  - (b-1) [choice] 사차방정식 (x² + x)² − 8(x² + x) + 12 = 0 에서 x² + x = X 로 놓으면 X 의 값은?  〔보기: X = 8 또는 X = 12 / X = −6 또는 X = −2 / X = 2 / X = 2 또는 X = 6〕  → **X = 2 또는 X = 6** · X² − 8X + 12 = 0 을 인수분해 한다.
  - (b-2) [number] 삼차방정식 x³ + ax² + x + 6 = 0 의 한 근이 2 이다 (a 는 상수). a 의 값은?  → **-4** · x = 2 를 대입하면 a 에 대한 일차방정식이 된다.
  - (b-3) [number] 가로, 세로, 높이가 각각 x, x + 1, x + 2 인 직육면체의 부피가 60 이다. x 의 값은? (x 는 양수)  → **3** · x = 3 을 넣으면 3 × 4 × 5 = 60. x 가 양수일 때 부피는 x 가 커질수록 커지므로 답은 하나.
  - (b-4) [number] 방정식 x³ = 1 의 한 허근을 ω 라 할 때, ω³ 의 값은?  → **1** · ω 는 x³ = 1 의 근 → ω³ = 1 → ω³ = (ω³)¹ = 1.

[핵심 한 줄] ω³ = 1 이므로 ω 의 거듭제곱은 ω, ω², 1 이 되풀이된다.
[장면]
1. 카드에 x³ − 1 = (x − 1)(x² + x + 1) 이 갈라진다.
2. 뒤 괄호의 근에 ω 딱지가 붙고 ω² + ω + 1 = 0 이 뜬다.
3. 세 칸 바퀴(ω, ω², 1)가 「× ω」 누를 때마다 한 칸씩 돈다.
4. ω¹⁰ 을 넣으면 세 바퀴 돌고 ω 에 멈춘다.
[마지막 화면] ω³ = 1 · ω² + ω + 1 = 0
