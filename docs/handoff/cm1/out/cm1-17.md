## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 16차시: 그래프와 x축 — D 의 부호 · x축은 직선 y = 0
- 💭 생각 열기: x축 대신 비스듬한 직선이면? 두 식을 같다고 놓은 이차방정식의 실근이 교점의 x좌표.
- 📘 c1 그래프와 직선이 만나는 점: y = ax² + bx + c 와 y = mx + n 이 만나는 점의 x좌표 = ax² + (b − m)x + c − n = 0 의 실근.
- 📘 c2 판별식과 위치 관계: 정리한 이차방정식의 D > 0 두 점 · D = 0 접한다 · D < 0 만나지 않는다. · ✔ 개념 체크: 이차함수의 그래프와 직선이 접하면, 두 식을 같다고 놓은 이차방정식은 중근을 갖는다. → O

- 👾 m1 문제 1 · 직선과 만나는 점 (⏱ 2.3분)
  - (m1-1) [choice] 이차함수 y = x² − 2 의 그래프와 직선 y = x 이 만나는 점의 x좌표를 모두 구한 것은?  〔보기: −2, 2 / −1, 3 / −1, 2 / −2, 1〕  → **−1, 2** · 두 식을 같다고 놓고 정리: x² − x − 2 = 0.
- 👾 m2 문제 2 · 직선과의 위치 관계 (⏱ 4.9분)
  - (m2-1) [choice] 이차함수 y = −x² + 5x + 1 의 그래프와 직선 y = −x + 3 의 교점을 구하려고 두 식을 같다고 놓았다. 정리한 이차방정식은?  〔보기: −x² + 6x + 2 = 0 / −x² + 4x + 4 = 0 / −x² − 6x − 2 = 0 / −x² + 6x − 2 = 0〕  → **−x² + 6x − 2 = 0** · 직선의 식을 좌변으로 넘겨 동류항끼리 정리한다.
  - (m2-2) [choice] 이차함수 y = −x² + 5x + 1 의 그래프와 직선 y = −x + 3 의 위치 관계는?  〔보기: 서로 다른 두 점에서 만난다 / 한 점에서 만난다 (접한다) / 만나지 않는다〕  → **서로 다른 두 점에서 만난다** · −x² + 6x − 2 = 0 의 판별식 D = 28.
  - (m2-3) [choice] 이차함수 y = −x² + 5x + 1 의 그래프와 직선 y = x + 5 의 위치 관계는?  〔보기: 한 점에서 만난다 (접한다) / 서로 다른 두 점에서 만난다 / 만나지 않는다〕  → **한 점에서 만난다 (접한다)** · −x² + 4x − 4 = 0 의 판별식 D = 0.
- 👾 m3 문제 3 · 위치 관계로 a 구하기 (⏱ 4.2분)
  - (m3-1) [choice] 이차함수 y = x² + 2x + a 의 그래프와 직선 y = 6x − 2 이 만나지 않도록 하는 실수 a 의 값의 범위는?  〔보기: a < 2 / a ≤ 2 / a > 2 / a ≥ 2〕  → **a > 2** · 정리한 방정식의 D < 0: D/4 = 4 − (a − (−2)) < 0.
  - (m3-2) [number] 이차함수 y = x² + 2x + a 의 그래프와 직선 y = 6x − 2 이 접하도록 하는 실수 a 의 값은?  → **2** · D = 0: 4 − a + (−2) = 0.
- 👾 m4 문제 4 · 접하게 하는 a 를 모두 ⛰ (⏱ 6.1분)
  - (m4-1) [choice] 이차함수 y = x² + ax − 1 의 그래프와 직선 y = x − 5 이 한 점에서 만난다 (a 는 실수). 두 식을 같다고 놓고 정리한 방정식은?  〔보기: x² + (a − 1)x + 4 = 0 / x² + (a + 1)x + 4 = 0 / x² + ax + 4 = 0 / x² + (a − 1)x − 4 = 0〕  → **x² + (a − 1)x + 4 = 0** · 직선의 식을 좌변으로 넘겨 x 항과 상수항을 따로 정리한다.
  - (m4-2) [choice] 이차함수 y = x² + ax − 1 의 그래프와 직선 y = x − 5 이 한 점에서 만난다 (a 는 실수). 「한 점에서 만난다」를 x² + (a − 1)x + 4 = 0 의 판별식 D 로 쓰면?  〔보기: (a − 1)² − 16 > 0 / (a − 1)² − 4 = 0 / (a − 1)² + 16 = 0 / (a − 1)² − 16 = 0〕  → **(a − 1)² − 16 = 0** · 접한다 ⟺ D = b² − 4ac = 0.
  - (m4-3) [choice] 이차함수 y = x² + ax − 1 의 그래프와 직선 y = x − 5 이 한 점에서 만난다 (a 는 실수). a 의 값을 모두 구한 것은?  〔보기: −5, 3 / −1, 3 / −3, 5 / 5〕  → **−3, 5** · (a − (1))² = 16 → a − (1) = ±4.
- 👾 m5 🌱 여유 문제 · y = mx + a 가 접할 때 (⏱ 2.9분)
  - (m5-1) [number] 이차함수 y = x² − x − 2 의 그래프와 직선 y = x + a 가 한 점에서 만날 때, 실수 a 의 값은?  → **-3** · x² + (−2)x + (−2) − a = 0 의 D = 0.
- 👑 형성평가 4문항 (⏱ 7.8분) · 짝 = ['m1', 'm2', 'm3', 'm3']
  - (b-1) [choice] 이차함수 y = x² − 2 의 그래프와 직선 y = x 이 만나는 점의 x좌표를 모두 구한 것은?  〔보기: −2, 2 / −2, 1 / −1, 2 / −1, 3〕  → **−1, 2** · 두 식을 같다고 놓고 정리: x² − x − 2 = 0.
  - (b-2) [choice] 이차함수 y = −x² + 5x + 1 의 그래프와 직선 y = −x + 3 의 위치 관계는?  〔보기: 서로 다른 두 점에서 만난다 / 한 점에서 만난다 (접한다) / 만나지 않는다〕  → **서로 다른 두 점에서 만난다** · −x² + 6x − 2 = 0 의 판별식 D = 28.
  - (b-3) [choice] 이차함수 y = x² + 2x + a 의 그래프와 직선 y = 6x − 2 이 만나지 않도록 하는 실수 a 의 값의 범위는?  〔보기: a < 2 / a ≥ 2 / a > 2 / a ≤ 2〕  → **a > 2** · 정리한 방정식의 D < 0: D/4 = 4 − (a − (−2)) < 0.
  - (b-4) [number] 이차함수 y = x² + 2x + a 의 그래프와 직선 y = 6x − 2 이 접하도록 하는 실수 a 의 값은?  → **2** · D = 0: 4 − a + (−2) = 0.
