## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 중학교: 절댓값 = 원점에서의 거리 · 23차시: 연립부등식의 공통부분
- 💭 생각 열기: |x| < 3 은 「원점에서 거리가 3 보다 가까운 수」 → −3 과 3 사이.
- 📘 c1 |x| < a, |x| > a (a > 0): |x| < a ⟺ −a < x < a · |x| > a ⟺ x < −a 또는 x > a. x 자리에 식이 와도 같다. · ✔ 개념 체크: |x| > 2 의 해는 −2 < x < 2 이다. → X
- 📘 c2 범위를 나누어 풀기: 절댓값 안이 0 이 되는 값을 기준으로 범위를 나눠 기호를 없애고, 범위마다 푼 해를 합친다.

- 👾 m1 문제 1 · |식| < a, |식| ≥ a (⏱ 3.6분)
  - (m1-1) [choice] 부등식 |x − 2| < 3 의 해는?  〔보기: x < −1 또는 x > 5 / −1 < x < 5 / −5 < x < 1 / x < 5〕  → **−1 < x < 5** · −3 < x − (2) < 3 → 각 변에 2 를 더한다.
  - (m1-2) [choice] 부등식 |2x + 1| ≥ 5 의 해는?  〔보기: −3 ≤ x ≤ 2 / x ≤ −3 또는 x ≥ 2 / x ≥ 2 / x < −3 또는 x > 2〕  → **x ≤ −3 또는 x ≥ 2** · 2x − (−1) ≤ −5 또는 2x − (−1) ≥ 5.
- 👾 m2 문제 2 · 정수인 해 (⏱ 4.8분)
  - (m2-1) [number] 부등식 |x − 1| ≤ 3 을 만족시키는 정수 x 의 개수는?  → **7** · −2 ≤ x ≤ 4 → 양 끝 포함 7개.
  - (m2-2) [number] 부등식 |x + 2| < 4 을 만족시키는 정수 x 중 가장 큰 수는?  → **1** · −6 < x < 2 → 끝은 빠지므로 1.
- 👾 m3 문제 3 · 범위를 나누어 풀기 (⏱ 4.9분)
  - (m3-1) [choice] 부등식 |x − 2| < 2x − 1 에서 x ≥ 2 일 때 절댓값 기호를 없앤 식은?  〔보기: x − 2 < 2x − 1 / x + 2 < 2x − 1 / −x + 2 < 2x − 1 / x − 2 > 2x − 1〕  → **x − 2 < 2x − 1** · x ≥ 2 이면 절댓값 안이 0 이상 → 그대로.
  - (m3-2) [choice] 부등식 |x − 2| < 2x − 1 에서 x < 2 일 때의 해는?  〔보기: x > 1 / x < 2 / 1 < x < 2 / x < 1〕  → **1 < x < 2** · −x + (2) < 2x + (−1) → 3x > 3 → x > 1 이고 x < 2.
  - (m3-3) [choice] 부등식 |x − 2| < 2x − 1 에서 해는?  〔보기: 1 < x < 2 / x ≥ 2 / x > 1 / x < 1〕  → **x > 1** · x ≥ 2 인 경우(모두 해)와 1 < x < 2 를 합친다.
- 👾 m4 문제 4 · 절댓값이 두 개 ⛰ (⏱ 6.1분)
  - (m4-1) [choice] 부등식 |x + 1| + |x − 2| < 5 에서 절댓값 기호 안이 0 이 되는 x 의 값을 기준으로 범위를 나누려고 한다. 기준이 되는 두 수는?  〔보기: −1, 2 / −2, 1 / 0, 5 / −2, 3〕  → **−1, 2** · x − (−1) = 0, x − (2) = 0 이 되는 값.
  - (m4-2) [choice] 부등식 |x + 1| + |x − 2| < 5 에서 x < −1 일 때의 해는?  〔보기: x < −2 / x < −1 / −2 < x < −1 / −2 < x < 2〕  → **−2 < x < −1** · 두 절댓값 안이 모두 음수 → −2x + (1) < 5 → x > −2.
  - (m4-3) [choice] 부등식 |x + 1| + |x − 2| < 5 에서 해는?  〔보기: −1 < x < 2 / −2 < x < 3 / x < −2 또는 x > 3 / −2 ≤ x ≤ 3〕  → **−2 < x < 3** · 세 범위(x < −1, −1 ≤ x < 2, x ≥ 2)의 해를 모두 합친다.
- 👾 m5 🌱 여유 문제 · 정수 해의 개수로 a (⏱ 2.9분)
  - (m5-1) [number] 부등식 |x| < a 를 만족시키는 정수 x 가 7개일 때, 자연수 a 의 값은?  → **4** · −a < x < a 인 정수는 −(a − 1) 부터 a − 1 까지 2a − 1 개 → 2a − 1 = 7.
- 👑 형성평가 4문항 (⏱ 7.8분) · 짝 = ['m1', 'm1', 'm2', 'm3']
  - (b-1) [choice] 부등식 |x − 2| < 3 의 해는?  〔보기: x < −1 또는 x > 5 / x < 5 / −1 < x < 5 / −5 < x < 1〕  → **−1 < x < 5** · −3 < x − (2) < 3 → 각 변에 2 를 더한다.
  - (b-2) [choice] 부등식 |2x + 1| ≥ 5 의 해는?  〔보기: −3 ≤ x ≤ 2 / x ≤ −3 또는 x ≥ 2 / x ≥ 2 / x < −3 또는 x > 2〕  → **x ≤ −3 또는 x ≥ 2** · 2x − (−1) ≤ −5 또는 2x − (−1) ≥ 5.
  - (b-3) [number] 부등식 |x − 1| ≤ 3 을 만족시키는 정수 x 의 개수는?  → **7** · −2 ≤ x ≤ 4 → 양 끝 포함 7개.
