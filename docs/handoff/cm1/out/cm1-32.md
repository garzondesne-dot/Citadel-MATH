## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 31차시: ₙCᵣ = ₙPᵣ / r! · ₙCᵣ = ₙCₙ₋ᵣ
- 💭 생각 열기: 동아리 7명 중 3명을 뽑는데 「회장은 꼭 가야 한다」는 조건이 붙으면 경우의 수는 어떻게 달라질까?
- 📘 c1 조건이 붙은 뽑기: 꼭 포함 → 미리 뽑아 두고 나머지에서 고른다. 제외 → 빼 놓고 고른다. 종류별로 뽑기 → 각각 구해 곱한다. · ✔ 개념 체크: 7명 중 3명을 뽑을 때 특정한 1명을 꼭 포함하는 방법의 수는 ₆C₂ 이다. → O
- 📘 c2 도형 세기와 「적어도」: 점 2개 = 선분, 점 3개 = 삼각형. 「적어도 하나」는 전체에서 「하나도 없는 경우」를 뺀다. · ✔ 개념 체크: 「적어도 1명은 여학생」의 반대는 「여학생이 1명뿐」이다. → X

  - (m1-1) [number] 학생 7명 중에서 3명을 뽑을 때, 특정한 학생 1명을 반드시 포함하여 뽑는 방법의 수는?  → **15** · 그 학생은 이미 뽑혔다 → 남은 6명에서 2명: ₆C₂.
  - (m1-2) [number] 학생 7명 중에서 3명을 뽑을 때, 특정한 학생 1명을 빼고 뽑는 방법의 수는?  → **20** · 그 학생을 뺀 6명에서 3명: ₆C₃.
- 👾 m2 문제 2 · 종류별로 뽑기 (⏱ 4.8분)
  - (m2-1) [number] 빨간 공 5개와 파란 공 4개가 있다. 공은 모두 서로 다르다. 빨간 공 2개와 파란 공 2개를 뽑는 방법의 수는?  → **60** · ₅C₂ × ₄C₂ = 10 × 6 (동시에 일어나므로 곱).
