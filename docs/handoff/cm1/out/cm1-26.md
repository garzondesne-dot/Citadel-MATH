## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 23차시: 연립부등식의 공통부분 · 25차시: 「< 0 은 사이, > 0 은 바깥」
- 💭 생각 열기: 조건이 둘이면 각각 풀어 수직선에서 겹치는 곳 — 이차부등식이 들어가도 똑같다.
- 📘 c1 연립이차부등식: 차수가 가장 높은 부등식이 이차인 연립부등식. 각 부등식의 해를 구해 공통부분을 찾는다. · ✔ 개념 체크: 연립부등식의 해는 두 부등식의 해를 합친 범위이다. → X
- 📘 c2 활용: 넓이 · 길이 조건을 x 의 부등식으로 세운 뒤, 길이는 양수 · 대소 조건까지 함께 연립한다.

- 👾 m1 문제 1 · 일차 + 이차 (⏱ 3.6분)
  - (m1-1) [choice] 연립부등식 2x > 4, x² − 5x + 4 < 0 에서 두 부등식을 각각 풀면?  〔보기: x > 2, 1 < x < 4 / x < 2, 1 < x < 4 / x > 2, −4 < x < −1 / x > 2, x < 1 또는 x > 4〕  → **x > 2, 1 < x < 4** · 일차부등식은 이항, 이차부등식은 인수분해 → 「< 0 은 사이」.
  - (m1-2) [choice] 연립부등식 2x > 4, x² − 5x + 4 < 0 에서 해는?  〔보기: x > 2 / 1 < x < 2 / 1 < x < 4 / 2 < x < 4〕  → **2 < x < 4** · x > 2 와 1 < x < 4 의 공통부분.
- 👾 m2 문제 2 · 이차 + 이차 (⏱ 3.6분)
  - (m2-1) [choice] 연립부등식 x² − x − 6 ≤ 0, x² − 6x + 5 > 0 에서 둘째 부등식 x² − 6x + 5 > 0 의 해는?  〔보기: x > 5 / x ≤ 1 또는 x ≥ 5 / x < 1 또는 x > 5 / 1 < x < 5〕  → **x < 1 또는 x > 5** · 「> 0 은 두 근의 바깥」.
  - (m2-2) [choice] 연립부등식 x² − x − 6 ≤ 0, x² − 6x + 5 > 0 에서 해는?  〔보기: −2 < x ≤ 1 / −2 ≤ x < 1 / −2 ≤ x ≤ 3 / 1 < x ≤ 3〕  → **−2 ≤ x < 1** · −2 ≤ x ≤ 3 와 (x < 1 또는 x > 5) 가 겹치는 곳.
- 👾 m3 문제 3 · 정수인 해 · 해가 없는 경우 (⏱ 4.2분)
  - (m3-1) [number] 연립부등식 x² − x − 6 ≤ 0, x² − 6x + 5 > 0 에서 정수인 해의 개수는?  → **3** · 해 −2 ≤ x < 1 → −2 부터 0 까지.
  - (m3-2) [choice] 연립부등식 x² − x − 2 < 0, x² − 9x + 18 < 0 의 해는?  〔보기: −1 < x < 6 / −1 < x < 2 / 해가 없다 / 2 < x < 3〕  → **해가 없다** · −1 < x < 2 와 3 < x < 6 는 겹치지 않는다.
- 👾 m4 문제 4 · 직사각형의 넓이 조건 ⛰ (⏱ 6.5분)
  - (m4-1) [multi] 둘레의 길이가 20 인 직사각형의 넓이가 21 이상이 되게 하려고 한다. 가로의 길이를 x 라 할 때 (가로가 세로보다 길다), 맞는 식을 모두 고르시오.  〔보기: x(10 − x) ≥ 21 / x(20 − x) ≥ 21 / x > 10 − x / x < 10 − x〕  → **x(10 − x) ≥ 21 · x > 10 − x** · 세로 = 10 − x · 넓이 = 가로 × 세로 · 가로 > 세로.
  - (m4-2) [choice] 둘레의 길이가 20 인 직사각형의 넓이가 21 이상이 되게 하려고 한다. 가로의 길이를 x 라 할 때 (가로가 세로보다 길다), x(10 − x) ≥ 21 를 정리하여 풀면?  〔보기: x ≤ 3 또는 x ≥ 7 / 3 < x < 7 / 2 ≤ x ≤ 8 / 3 ≤ x ≤ 7〕  → **3 ≤ x ≤ 7** · x² − 10x + 21 ≤ 0 → (x − 3)(x − 7) ≤ 0.
  - (m4-3) [choice] 둘레의 길이가 20 인 직사각형의 넓이가 21 이상이 되게 하려고 한다. 가로의 길이를 x 라 할 때 (가로가 세로보다 길다), x 의 값의 범위는?  〔보기: 5 ≤ x ≤ 7 / 5 < x ≤ 7 / 3 ≤ x ≤ 7 / 3 ≤ x < 5〕  → **5 < x ≤ 7** · 3 ≤ x ≤ 7 와 x > 5 (가로 > 세로) 의 공통부분.
- 👾 m5 🌱 여유 문제 · A < B ≤ C 꼴 (⏱ 2.3분)
  - (m5-1) [choice] 부등식 2x < x² ≤ 6x 를 만족시키는 x 의 값의 범위는? (x > 0)  〔보기: 2 < x ≤ 6 / 0 < x ≤ 6 / x > 2 / 2 ≤ x < 6〕  → **2 < x ≤ 6** · x > 0 이므로 x 로 나누면 2 < x ≤ 6.
- 👑 형성평가 4문항 (⏱ 7.8분) · 짝 = ['m1', 'm2', 'm3', 'm4']
  - (b-1) [choice] 연립부등식 2x > 4, x² − 5x + 4 < 0 에서 해는?  〔보기: 2 < x < 4 / x > 2 / 1 < x < 4 / 1 < x < 2〕  → **2 < x < 4** · x > 2 와 1 < x < 4 의 공통부분.
  - (b-2) [choice] 연립부등식 x² − x − 6 ≤ 0, x² − 6x + 5 > 0 에서 해는?  〔보기: −2 ≤ x ≤ 3 / −2 < x ≤ 1 / 1 < x ≤ 3 / −2 ≤ x < 1〕  → **−2 ≤ x < 1** · −2 ≤ x ≤ 3 와 (x < 1 또는 x > 5) 가 겹치는 곳.
  - (b-3) [number] 연립부등식 x² − x − 6 ≤ 0, x² − 6x + 5 > 0 에서 정수인 해의 개수는?  → **3** · 해 −2 ≤ x < 1 → −2 부터 0 까지.
  - (b-4) [choice] 둘레의 길이가 20 인 직사각형의 넓이가 21 이상이 되게 하려고 한다. 가로의 길이를 x 라 할 때 (가로가 세로보다 길다), x(10 − x) ≥ 21 를 정리하여 풀면?  〔보기: 3 ≤ x ≤ 7 / 3 < x < 7 / x ≤ 3 또는 x ≥ 7 / 2 ≤ x ≤ 8〕  → **3 ≤ x ≤ 7** · x² − 10x + 21 ≤ 0 → (x − 3)(x − 7) ≤ 0.
