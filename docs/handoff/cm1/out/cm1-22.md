## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 중학교: 연립일차방정식의 대입법 · 14차시: 합과 곱으로 이차방정식 만들기
- 💭 생각 열기: 일차식 하나와 이차식 하나 — 일차식을 한 문자에 대해 풀어 이차식에 넣으면 이차방정식 하나가 된다.
- 📘 c1 일차식과 이차식의 연립: 일차식을 y = (x 의 식) 으로 고쳐 이차식에 대입 → x 에 대한 이차방정식 → 구한 x 마다 y. 합 · 곱이 주어지면 t² − (합)t + (곱) = 0. · ✔ 개념 체크: 연립방정식 x + y = 5, xy = 6 의 해는 x = 2, y = 3 하나뿐이다. → X
- 📘 c2 두 이차식의 연립: 한 식을 인수분해 하여 일차식 둘(x = y 또는 x = 2y …)로 나눈 뒤, 각각을 다른 식에 대입한다.

- 👾 m1 문제 1 · 대입해서 풀기 (⏱ 3.6분)
  - (m1-1) [choice] 연립방정식 x − y = 1, x² + y² = 25 에서 y = x − 1 을 둘째 식에 대입하여 정리하면?  〔보기: x² − 2x − 24 = 0 / 2x² − 2x + 26 = 0 / 2x² − 2x − 24 = 0 / 2x² + 2x − 24 = 0〕  → **2x² − 2x − 24 = 0** · x² + (x − 1)² = 25 을 전개해 정리.
  - (m1-2) [choice] 연립방정식 x − y = 1, x² + y² = 25 에서 해를 모두 구한 것은?  〔보기: x = −3, y = −4 / x = 3, y = −4 또는 x = 4, y = −3 / x = −4, y = −3 또는 x = 3, y = 4 / x = −3, y = −4 또는 x = 4, y = 3〕  → **x = −3, y = −4 또는 x = 4, y = 3** · 일차식을 y = x − (1) 로 고쳐 대입 → x 를 구한 뒤 y.
- 👾 m2 문제 2 · 합과 곱이 주어질 때 (⏱ 3.6분)
  - (m2-1) [choice] 연립방정식 x + y = 7, xy = 10 에서 x, y 는 어떤 이차방정식의 두 근인가? (미지수는 t)  〔보기: t² − 7t − 10 = 0 / t² + 7t + 10 = 0 / t² − 7t + 10 = 0 / t² − 10t + 7 = 0〕  → **t² − 7t + 10 = 0** · 합이 s, 곱이 p 인 두 수 = t² − st + p = 0 의 두 근.
  - (m2-2) [choice] 연립방정식 x + y = 7, xy = 10 의 해를 모두 구한 것은?  〔보기: x = 2, y = −5 또는 x = −5, y = 2 / x = 2, y = 5 또는 x = 5, y = 2 / x = −2, y = −5 또는 x = −5, y = −2 / x = 2, y = 5〕  → **x = 2, y = 5 또는 x = 5, y = 2** · 합 7, 곱 10 인 두 수 2, 5 → x, y 자리를 바꾼 것도 해.
- 👾 m3 문제 3 · 인수분해 되는 식 (⏱ 3.6분)
  - (m3-1) [choice] 연립방정식 x² − 3xy + 2y² = 0, x² + y² = 20 에서 첫째 식의 좌변을 인수분해 하여 얻는 x, y 의 관계는?  〔보기: x = y 또는 x = 2y / x = 2y / x = −y 또는 x = −2y / x = y 또는 x = −2y〕  → **x = y 또는 x = 2y** · (x − y)(x − 2y) = 0.
  - (m3-2) [choice] 연립방정식 x² − 3xy + 2y² = 0, x² + y² = 20 에서 x = 2y 인 경우의 해를 모두 구한 것은?  〔보기: x = −4, y = −2 또는 x = 4, y = 2 / x = 4, y = 2 / x = −2, y = −4 또는 x = 2, y = 4 / x = −4, y = 2 또는 x = 4, y = −2〕  → **x = −4, y = −2 또는 x = 4, y = 2** · (2y)² + y² = 20 → 5y² = 20 → y = ±2.
- 👾 m4 문제 4 · 직사각형의 가로와 세로 ⛰ (⏱ 8.0분)
  - (m4-1) [multi] 둘레의 길이가 28 이고 대각선의 길이가 10 인 직사각형의 가로, 세로의 길이를 각각 x, y 라 할 때 (x > y), 맞는 식을 모두 고르시오.  〔보기: x + y = 14 / x + y = 28 / x² + y² = 100 / x² + y² = 10 / xy = 10〕  → **x + y = 14 · x² + y² = 100** · 둘레 = 2(x + y) · 대각선² = x² + y² (피타고라스).
  - (m4-2) [number] 둘레의 길이가 28 이고 대각선의 길이가 10 인 직사각형의 가로, 세로의 길이를 각각 x, y 라 할 때 (x > y), x + y = 14, x² + y² = 100 이다. xy 의 값은?  → **48** · (x + y)² − (x² + y²) = 2xy → 196 − 100 = 96.
  - (m4-3) [number] 둘레의 길이가 28 이고 대각선의 길이가 10 인 직사각형의 가로, 세로의 길이를 각각 x, y 라 할 때 (x > y), 가로의 길이 x 는?  → **8** · 합 14, 곱 48 인 두 수 = 8, 6 → 큰 쪽이 x.
- 👾 m5 🌱 여유 문제 · x² − y² 을 쪼개기 (⏱ 2.9분)
  - (m5-1) [number] 연립방정식 x + y = 5, x² − y² = 15 에서 x 의 값은?  → **4** · x² − y² = (x + y)(x − y) → x − y = 3 → 두 식을 더해 2x = 8.
- 👑 형성평가 4문항 (⏱ 7.8분) · 짝 = ['m1', 'm2', 'm3', 'm4']
  - (b-1) [choice] 연립방정식 x − y = 1, x² + y² = 25 에서 해를 모두 구한 것은?  〔보기: x = −3, y = −4 또는 x = 4, y = 3 / x = −4, y = −3 또는 x = 3, y = 4 / x = 3, y = −4 또는 x = 4, y = −3 / x = −3, y = −4〕  → **x = −3, y = −4 또는 x = 4, y = 3** · 일차식을 y = x − (1) 로 고쳐 대입 → x 를 구한 뒤 y.
  - (b-2) [choice] 연립방정식 x + y = 7, xy = 10 의 해를 모두 구한 것은?  〔보기: x = −2, y = −5 또는 x = −5, y = −2 / x = 2, y = −5 또는 x = −5, y = 2 / x = 2, y = 5 / x = 2, y = 5 또는 x = 5, y = 2〕  → **x = 2, y = 5 또는 x = 5, y = 2** · 합 7, 곱 10 인 두 수 2, 5 → x, y 자리를 바꾼 것도 해.
  - (b-3) [choice] 연립방정식 x² − 3xy + 2y² = 0, x² + y² = 20 에서 첫째 식의 좌변을 인수분해 하여 얻는 x, y 의 관계는?  〔보기: x = 2y / x = −y 또는 x = −2y / x = y 또는 x = 2y / x = y 또는 x = −2y〕  → **x = y 또는 x = 2y** · (x − y)(x − 2y) = 0.
  - (b-4) [number] 둘레의 길이가 28 이고 대각선의 길이가 10 인 직사각형의 가로, 세로의 길이를 각각 x, y 라 할 때 (x > y), x + y = 14, x² + y² = 100 이다. xy 의 값은?  → **48** · (x + y)² − (x² + y²) = 2xy → 196 − 100 = 96.
