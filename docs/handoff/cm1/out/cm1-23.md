## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 중학교: 일차부등식의 풀이 · 음수를 곱하거나 나누면 부등호 방향이 바뀐다
- 💭 생각 열기: 제한 속도는 「시속 50 이상 110 이하」 — 두 조건을 한꺼번에 만족하는 범위를 찾는 것이 연립부등식.
- 📘 c1 연립부등식과 그 해: 각 부등식을 풀어 수직선 위에 나타내고 겹치는 부분(공통부분)을 찾는다. A < B < C 는 A < B 이고 B < C. · ✔ 개념 체크: 부등식 −2x > 6 의 해는 x > −3 이다. → X
- 📘 c2 해가 하나이거나 없는 경우: 겹치는 부분이 한 점이면 해는 그 수 하나, 겹치는 부분이 없으면 해가 없다.

- 👾 m1 문제 1 · 공통부분 찾기 (⏱ 3.6분)
  - (m1-1) [choice] 연립부등식 x − 1 > 2, 2x ≤ 10 에서 두 부등식을 각각 풀면?  〔보기: x < 3, x ≤ 5 / x > −3, x ≤ 5 / x > 3, x ≥ 5 / x > 3, x ≤ 5〕  → **x > 3, x ≤ 5** · 이항하고, 양수로 나누면 부등호 방향은 그대로.
  - (m1-2) [choice] 연립부등식 x − 1 > 2, 2x ≤ 10 에서 해는?  〔보기: 3 ≤ x < 5 / x ≤ 5 / x > 3 / 3 < x ≤ 5〕  → **3 < x ≤ 5** · x > 3 와 x ≤ 5 를 수직선에 그려 겹치는 부분.
- 👾 m2 문제 2 · A < B ≤ C 꼴 (⏱ 3.6분)
  - (m2-1) [choice] 부등식 2x − 1 < x + 3 ≤ 4x 를 연립부등식으로 고치면?  〔보기: 2x − 1 < x + 3, 2x − 1 ≤ 4x / 2x − 1 < 4x, x + 3 ≤ 4x / 2x − 1 < x + 3, x + 3 ≤ 4x / 2x − 1 ≤ x + 3, x + 3 < 4x〕  → **2x − 1 < x + 3, x + 3 ≤ 4x** · A < B ≤ C 는 「A < B 이고 B ≤ C」.
  - (m2-2) [choice] 부등식 2x − 1 < x + 3 ≤ 4x 의 해는?  〔보기: x < 4 / x ≥ 1 / 1 ≤ x < 4 / 1 < x ≤ 4〕  → **1 ≤ x < 4** · 2x − 1 < x + 3 → x < 4 · x + 3 ≤ 4x → x ≥ 1.
- 👾 m3 문제 3 · 해가 하나 · 없음 (⏱ 3.6분)
  - (m3-1) [choice] 연립부등식 2x ≥ 6, x ≤ 3 의 해는?  〔보기: 해가 없다 / x ≥ 3 / x ≤ 3 / x = 3〕  → **x = 3** · x ≥ 3 와 x ≤ 3 가 겹치는 곳은 한 점.
  - (m3-2) [choice] 연립부등식 x > 3, x < 1 의 해는?  〔보기: x = 3 / x > 3 / 1 < x < 3 / 해가 없다〕  → **해가 없다** · 3 보다 크면서 1 보다 작은 수는 없다(겹치는 부분 없음).
- 👾 m4 문제 4 · 정수인 해의 개수로 a 의 범위 ⛰ (⏱ 5.3분)
  - (m4-1) [choice] 연립부등식 x > 2, x ≤ a 를 만족시키는 정수 x 가 3개이다 (a 는 실수). 그 정수 x 를 모두 구한 것은?  〔보기: 3, 4, 5 / 3, 4 / 2, 3, 4 / 4, 5, 6〕  → **3, 4, 5** · 2 보다 큰 정수부터 차례로 3개.
  - (m4-2) [choice] 연립부등식 x > 2, x ≤ a 를 만족시키는 정수 x 가 3개이다 (a 는 실수). a 의 값의 범위는?  〔보기: 5 ≤ a < 6 / 5 < a ≤ 6 / 4 ≤ a < 5 / a = 5〕  → **5 ≤ a < 6** · 5 은 포함되고 6 은 포함되지 않아야 한다 → a = 6 이면 정수가 하나 더 생긴다.
  - (m4-3) [ox] 연립부등식 x > 2, x ≤ a 에서 a = 5 + 0.5 이면 정수인 해는 3개이다.  → **O** · 정수는 3 부터 5 까지 3개.
- 👾 m5 🌱 여유 문제 · 정수인 해 세기 (⏱ 2.9분)
  - (m5-1) [number] 부등식 −2 < x ≤ 3 를 만족시키는 정수 x 의 개수는?  → **5** · −1 부터 3 까지.
- 👑 형성평가 4문항 (⏱ 7.2분) · 짝 = ['m1', 'm2', 'm3', 'm3']
  - (b-1) [choice] 연립부등식 x − 1 > 2, 2x ≤ 10 에서 해는?  〔보기: 3 < x ≤ 5 / 3 ≤ x < 5 / x ≤ 5 / x > 3〕  → **3 < x ≤ 5** · x > 3 와 x ≤ 5 를 수직선에 그려 겹치는 부분.
  - (b-2) [choice] 부등식 2x − 1 < x + 3 ≤ 4x 의 해는?  〔보기: 1 < x ≤ 4 / x ≥ 1 / x < 4 / 1 ≤ x < 4〕  → **1 ≤ x < 4** · 2x − 1 < x + 3 → x < 4 · x + 3 ≤ 4x → x ≥ 1.
  - (b-3) [choice] 연립부등식 2x ≥ 6, x ≤ 3 의 해는?  〔보기: 해가 없다 / x ≥ 3 / x ≤ 3 / x = 3〕  → **x = 3** · x ≥ 3 와 x ≤ 3 가 겹치는 곳은 한 점.
  - (b-4) [choice] 연립부등식 x > 3, x < 1 의 해는?  〔보기: 해가 없다 / x > 3 / x = 3 / 1 < x < 3〕  → **해가 없다** · 3 보다 크면서 1 보다 작은 수는 없다(겹치는 부분 없음).
