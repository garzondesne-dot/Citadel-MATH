## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 6차시: 나머지 R = f(α) · 나머지가 0 이면?
- 💭 생각 열기: 나머지 f(α) 가 0 이면 「나누어떨어진다」 = x − α 가 인수. 계수만 써서 빠르게 나누는 법 = 조립제법.
- 📘 c1 인수정리: f(α) = 0 ⟺ f(x) 가 x − α 로 나누어떨어진다(x − α 가 f(x) 의 인수). · ✔ 개념 체크: f(2) = 0 이면 f(x) 는 x + 2 로 나누어떨어진다. → X
- 📘 c2 조립제법: 일차식 x − α 로 나눌 때 계수만 적어 「곱해서 더하기」를 되풀이 → 아랫줄 = 몫의 계수와 나머지. 없는 차수는 0 을 적는다. · ✔ 개념 체크: 2x³ − 5x + 4 를 조립제법으로 나눌 때 계수는 2, −5, 4 세 개만 적는다. → X

- 👾 m1 문제 1 · 인수 찾기 (⏱ 3.3분)
  - (m1-1) [multi] 다음 중 다항식 f(x) = x³ − 7x + 6 의 인수인 것을 모두 고르시오.  〔보기: x − 1 / x + 1 / x − 2 / x + 3〕  → **x − 1 · x − 2 · x + 3** · x − α 가 인수 ⟺ f(α) = 0 → 각 일차식이 0 이 되는 값을 대입해 본다.
  - (m1-2) [ox] 다항식 f(x) = x³ − 7x + 6 은 x − 1 로 나누어떨어진다.  → **O** · f(1) = 0 = 0 이므로 나누어떨어진다.
- 👾 m2 문제 2 · 나누어떨어질 때의 계수 (⏱ 4.2분)
  - (m2-1) [choice] 다항식 f(x) = x³ + 3x² − 2x + a 가 x − 2 로 나누어떨어진다 (a 는 상수). 이 조건을 식으로 쓰면?  〔보기: f(2) = 0 / f(2) = a / f(−2) = 0 / f(0) = 2〕  → **f(2) = 0** · 인수정리: x − α 로 나누어떨어진다 ⟺ f(α) = 0.
  - (m2-2) [number] 다항식 f(x) = x³ + 3x² − 2x + a 가 x − 2 로 나누어떨어진다 (a 는 상수). a 의 값은?  → **-16** · f(2) = 16 + a = 0.
- 👾 m3 문제 3 · 조립제법 (⏱ 5.5분)
  - (m3-1) [choice] (2x³ − 5x + 4) ÷ (x + 2) 를 조립제법으로 계산할 때, 첫 줄에 쓰는 수는?  〔보기: 2 │ 2  0  −5  4 / −2 │ 2  −5  4 / 2 │ 2  −5  4 / −2 │ 2  0  −5  4〕  → **−2 │ 2  0  −5  4** · 왼쪽에는 x + 2 = 0 이 되는 −2, 오른쪽에는 계수를 차수 순서로(없는 차수는 0).
  - (m3-2) [choice] (2x³ − 5x + 4) ÷ (x + 2) 의 몫은?  〔보기: 2x³ − 4x² + 3x − 2 / 2x² − 4x + 3 / 2x² + 4x + 3 / 2x² − 4x + 4〕  → **2x² − 4x + 3** · 조립제법 아랫줄 2 −4 3 │ −2 → 앞의 세 수가 몫의 계수.
  - (m3-3) [number] (2x³ − 5x + 4) ÷ (x + 2) 의 나머지는?  → **-2** · 조립제법 아랫줄의 맨 끝 수 = 나머지 (f(−2) 와 같다).
- 👾 m4 문제 4 · 두 일차식의 곱으로 나누어떨어짐 ⛰ (⏱ 7.6분)
  - (m4-1) [choice] 다항식 f(x) = x³ + ax² − 5x + b 가 (x − 1)(x + 2) 로 나누어떨어진다 (a, b 는 상수). 이 조건을 식으로 쓰면?  〔보기: f(−1) = 0 이고 f(2) = 0 / f(1) = f(−2) = 1 / f(1) = 0 이고 f(−2) = 0 / f(1) = 0 또는 f(−2) = 0〕  → **f(1) = 0 이고 f(−2) = 0** · 곱으로 나누어떨어지면 두 일차식 각각으로도 나누어떨어진다.
  - (m4-2) [number] 다항식 f(x) = x³ + ax² − 5x + b 가 (x − 1)(x + 2) 로 나누어떨어진다 (a, b 는 상수). f(1) = 0 을 정리하면 a + b = □ 이다. □ 에 알맞은 수는?  → **4** · f(1) = 1 + a + (−5) + b = 0 에서 수를 넘긴다.
  - (m4-3) [number] 다항식 f(x) = x³ + ax² − 5x + b 가 (x − 1)(x + 2) 로 나누어떨어진다 (a, b 는 상수). a 의 값은?  → **-2** · f(1) = 0, f(−2) = 0 을 연립해 b 를 없앤다 → a = −2, b = 6.
- 👾 m5 🌱 여유 문제 · 2x − 1 꼴로 나누는 조립제법 (⏱ 2.3분)
  - (m5-1) [choice] (2x³ − x² + 4x + 3) ÷ (2x − 1) 의 몫은? (조립제법으로 x − 1/2 로 나눈 몫은 2x² + 4 이다)  〔보기: 2x² + 4 / 4x² + 8 / x² + 3 / x² + 2〕  → **x² + 2** · 2x − 1 = 2(x − 1/2) 이므로 조립제법으로 구한 몫을 2 로 나눈다. 나머지는 그대로.
- 👑 형성평가 4문항 (⏱ 8.7분) · 짝 = ['m1', 'm2', 'm3', 'm3']
  - (b-1) [multi] 다음 중 다항식 f(x) = x³ − 7x + 6 의 인수인 것을 모두 고르시오.  〔보기: x − 1 / x + 1 / x − 2 / x + 3〕  → **x − 1 · x − 2 · x + 3** · x − α 가 인수 ⟺ f(α) = 0 → 각 일차식이 0 이 되는 값을 대입해 본다.
  - (b-2) [number] 다항식 f(x) = x³ + 3x² − 2x + a 가 x − 2 로 나누어떨어진다 (a 는 상수). a 의 값은?  → **-16** · f(2) = 16 + a = 0.
  - (b-3) [choice] (2x³ − 5x + 4) ÷ (x + 2) 의 몫은?  〔보기: 2x² − 4x + 3 / 2x² − 4x + 4 / 2x² + 4x + 3 / 2x³ − 4x² + 3x − 2〕  → **2x² − 4x + 3** · 조립제법 아랫줄 2 −4 3 │ −2 → 앞의 세 수가 몫의 계수.
  - (b-4) [number] (2x³ − 5x + 4) ÷ (x + 2) 의 나머지는?  → **-2** · 조립제법 아랫줄의 맨 끝 수 = 나머지 (f(−2) 와 같다).
