# 9차시 · 복잡한 식의 인수분해 — 시안 (공통수학1 · Ⅰ-2 나머지정리와 인수분해)

> 교과서 34 ~ 35쪽 · 목표: 치환 · A² − B² 꼴 · 인수정리를 이용하여 삼차 이상의 다항식을 인수분해 할 수 있다.
> ⏱ 예상 40.2분(여유 문제 빼고) · 여유 문제 +2.9분 · 어려운 문제(산) = m4 · 산 = 본문 35쪽 문제 5 꼴(이미 어려운 문제가 있어 중단원에서 안 가져옴)
> 문항 105줄(판 0 ~ 6) · 계산 검산 ✅ 105 · 눈으로 확인 0 · ❌ 0 · 글 검사 걸림 0 · 같은 판 0

## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 7차시: 인수정리 f(α) = 0 · 조립제법 · 8차시: 공통부분을 X 로
- 💭 생각 열기: 공식이 안 보이는 삼차 · 사차식은? ① x² 을 한 문자로 ② 제곱 − 제곱 꼴 만들기 ③ f(α) = 0 인 α 찾기.
- 📘 c1 x⁴ + ax² + b 꼴: x² = X 로 놓아 인수분해 되면 그대로, 안 되면 x² 항을 더하고 빼서 A² − B² 꼴로 고친다. · ✔ 개념 체크: x⁴ − 5x² + 4 = (x² − 1)(x² − 4) 는 인수분해가 끝난 것이다. → X
- 📘 c2 인수정리를 이용한 인수분해: f(α) = 0 인 α 를 상수항의 약수(±) 에서 찾는다 → x − α 로 조립제법 → 몫을 다시 인수분해.

- 👾 m1 문제 1 · x² = X 로 놓기 (⏱ 3.6분)
  - (m1-1) [choice] x⁴ − 13x² + 36 에서 x² = X 로 놓고 인수분해 하면?  〔보기: (X − 2)(X − 3) / (X + 4)(X − 9) / (X + 4)(X + 9) / (X − 4)(X − 9)〕  → **(X − 4)(X − 9)** · X² − 13X + 36 → 곱 36, 합 −13.
  - (m1-2) [choice] x⁴ − 13x² + 36 을 인수분해 하면?  〔보기: (x² − 4)(x² + 9) / (x + 2)²(x + 3)² / (x + 2)(x − 2)(x + 3)(x − 3) / (x − 2)²(x − 3)²〕  → **(x + 2)(x − 2)(x + 3)(x − 3)** · (x² − 4)(x² − 9) 의 두 괄호를 합차 공식으로 한 번 더.
- 👾 m2 문제 2 · A² − B² 꼴로 (⏱ 3.6분)
  - (m2-1) [choice] x⁴ + x² + 1 을 A² − B² 꼴로 고치면?  〔보기: (x² + 1)² − x² / (x² + 1)² + x² / (x² − 1)² − x²〕  → **(x² + 1)² − x²** · x⁴ 과 1 을 보고 (x² + 1)² = x⁴ + 2x² + 1 를 만든 뒤 남는 x² 을 뺀다.
  - (m2-2) [choice] x⁴ + x² + 1 을 인수분해 하면?  〔보기: (x² + x + 1)(x² − x + 1) / (x² + x + 1)² / (x² + 1)² / (x² + x − 1)(x² − x − 1)〕  → **(x² + x + 1)(x² − x + 1)** · A² − B² = (A + B)(A − B) 에 A = x² + (상수), B = (일차식) 을 넣는다.
- 👾 m3 문제 3 · 인수정리로 삼차식 (⏱ 4.9분)
  - (m3-1) [choice] f(x) = x³ − 7x + 6 을 인수분해 하려고 한다. 다음 중 f(α) = 0 이 되는 α 는?  〔보기: 3 / −1 / 1 / −2〕  → **1** · 상수항 6 의 약수를 차례로 넣어 본다 → f(1) = 0.
  - (m3-2) [choice] (x³ − 7x + 6) ÷ (x − 1) 의 몫은? (나누어떨어진다)  〔보기: x² + x − 6 / x² + 2x − 6 / x² − x − 6 / x² + x + 6〕  → **x² + x − 6** · 조립제법으로 나누면 나머지 0, 아랫줄 세 수가 몫의 계수.
  - (m3-3) [choice] x³ − 7x + 6 을 인수분해 하면?  〔보기: (x + 2)(x + 1)(x − 3) / (x + 3)(x + 1)(x − 2) / (x + 3)(x − 1)(x − 2) / (x − 1)(x − 2)(x − 3)〕  → **(x + 3)(x − 1)(x − 2)** · f(α) = 0 인 α 로 일차식 인수를 찾고, 몫(이차식)을 다시 인수분해 한다.
- 👾 m4 문제 4 · 계수를 찾고 사차식 인수분해 ⛰ (⏱ 6.9분)
  - (m4-1) [number] 다항식 f(x) = x⁴ + ax³ + 3x² + 4x + 2 이 x + 1 을 인수로 갖는다 (a 는 상수). a 의 값은?  → **2** · 인수정리: f(−1) = 0 에 대입해 a 에 대한 일차방정식을 푼다.
  - (m4-2) [choice] (x⁴ + 2x³ + 3x² + 4x + 2) ÷ (x + 1) 의 몫은? (나누어떨어진다)  〔보기: x³ + x² + 2x + 2 / x³ + x² + 2x − 2 / x³ − x² + 2x − 2 / x³ + x² + 2x + 3〕  → **x³ + x² + 2x + 2** · 조립제법: 계수 다섯 개를 적고 「곱해서 더하기」 네 번.
  - (m4-3) [choice] x⁴ + 2x³ + 3x² + 4x + 2 을 인수분해 하면?  〔보기: (x − 1)²(x² + 2) / (x + 1)(x − 1)(x² + 2) / (x + 1)²(x² − 2) / (x + 1)²(x² + 2)〕  → **(x + 1)²(x² + 2)** · 일차식 인수를 하나 떼고, 몫(삼차식)에 다시 인수정리를 쓴다. 더 안 되는 이차식은 그대로 둔다.
- 👾 m5 🌱 여유 문제 · 큰 수 계산 (⏱ 2.9분)
  - (m5-1) [number] (999³ − 13 × 999 + 12) ÷ (999 × 1002 − 4) 의 값은? (x³ − 13x + 12 = (x − 1)(x − 3)(x + 4), x(x + 3) − 4 = (x + 4)(x − 1) 임을 이용)  → **996** · x = 999 으로 보면 (x − 1)(x − 3)(x + 4) ÷ {(x + 4)(x − 1)} = x − 3.
- 👑 형성평가 4문항 (⏱ 7.2분) · 짝 = ['m1', 'm2', 'm3', 'm3']
  - (b-1) [choice] x⁴ − 13x² + 36 을 인수분해 하면?  〔보기: (x − 2)²(x − 3)² / (x² − 4)(x² + 9) / (x + 2)(x − 2)(x + 3)(x − 3) / (x + 2)²(x + 3)²〕  → **(x + 2)(x − 2)(x + 3)(x − 3)** · (x² − 4)(x² − 9) 의 두 괄호를 합차 공식으로 한 번 더.
  - (b-2) [choice] x⁴ + x² + 1 을 인수분해 하면?  〔보기: (x² + x + 1)(x² − x + 1) / (x² + 1)² / (x² + x − 1)(x² − x − 1) / (x² + x + 1)²〕  → **(x² + x + 1)(x² − x + 1)** · A² − B² = (A + B)(A − B) 에 A = x² + (상수), B = (일차식) 을 넣는다.
  - (b-3) [choice] f(x) = x³ − 7x + 6 을 인수분해 하려고 한다. 다음 중 f(α) = 0 이 되는 α 는?  〔보기: 3 / 1 / −1 / −2〕  → **1** · 상수항 6 의 약수를 차례로 넣어 본다 → f(1) = 0.
  - (b-4) [choice] x³ − 7x + 6 을 인수분해 하면?  〔보기: (x + 3)(x − 1)(x − 2) / (x + 2)(x + 1)(x − 3) / (x + 3)(x + 1)(x − 2) / (x − 1)(x − 2)(x − 3)〕  → **(x + 3)(x − 1)(x − 2)** · f(α) = 0 인 α 로 일차식 인수를 찾고, 몫(이차식)을 다시 인수분해 한다.
