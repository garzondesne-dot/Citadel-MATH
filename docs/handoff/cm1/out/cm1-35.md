## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 34차시: 덧셈 · 뺄셈 · 실수배는 「같은 자리끼리」
- 💭 생각 열기: 모둠별로 산 개수 행렬과 가격 행렬 — 모둠이 낸 돈은 「개수 × 가격」을 더한 값. 이것이 행렬의 곱셈이다.
- 📘 c1 곱할 수 있는 조건과 꼴: A 의 열의 수 = B 의 행의 수일 때만 AB 를 계산할 수 있다. (m × k)(k × n) = m × n 행렬. · ✔ 개념 체크: 2 × 3 행렬과 2 × 3 행렬은 곱할 수 있다. → X
- 📘 c2 행 × 열: AB 의 (i, j) 성분 = A 의 제i행과 B 의 제j열의 성분을 차례로 곱해 더한 값. 곱셈은 「같은 자리끼리」가 아니다. · ✔ 개념 체크: 행렬의 곱셈은 같은 자리의 성분끼리 곱하는 것이다. → X

- 👾 m1 문제 1 · 곱의 꼴 (⏱ 3.0분)
  - (m1-1) [choice] A 는 2 × 3 행렬, B 는 3 × 2 행렬일 때, 곱 AB 의 꼴은?  〔보기: 3 × 3 행렬 / 2 × 3 행렬 / 2 × 2 행렬 / 6 × 6 행렬〕  → **2 × 2 행렬** · (A 의 행의 수) × (B 의 열의 수) = 2 × 2.
  - (m1-2) [ox] A 는 2 × 3 행렬, B 는 2 × 2 행렬일 때, 곱 AB 를 계산할 수 있다.  → **X** · A 의 열의 수 3 와 B 의 행의 수 2 가 달라 곱할 수 없다.
- 👾 m2 문제 2 · 행 하나 × 열 하나 (⏱ 4.2분)
  - (m2-1) [number] A = (2  3), B = (4 ; 1) 일 때, 곱 AB 는 1 × 1 행렬이다. 그 성분은? (; 는 행을 나누는 표시)  → **11** · 2 × 4 + 3 × 1 (앞끼리, 뒤끼리 곱해 더한다).
  - (m2-2) [choice] A = (1  2 ; 3  4), B = (2 ; 1) 일 때, AB 는? (; 는 행을 나누는 표시)  〔보기: (2 ; 4) / (4 ; 10) / (10 ; 5) / (5 ; 10)〕  → **(4 ; 10)** · 제1행 × B = 4, 제2행 × B = 10 — 위아래로 놓는다.
- 👾 m3 문제 3 · 2 × 2 끼리의 곱 (⏱ 4.2분)
  - (m3-1) [number] A = (1  2 ; 0  1), B = (3  1 ; 2  4) 일 때, AB 의 (1, 2) 성분은? (; 는 행을 나누는 표시)  → **9** · A 의 제1행과 B 의 제2열: 1 × 1 + 2 × 4.
  - (m3-2) [choice] A = (1  2 ; 0  1), B = (3  1 ; 2  4) 일 때, AB 는? (; 는 행을 나누는 표시)  〔보기: (7  9 ; 2  4) / (3  7 ; 2  8) / (3  2 ; 0  4) / (7  2 ; 9  5)〕  → **(7  9 ; 2  4)** · (i, j) 성분 = A 의 제i행과 B 의 제j열을 차례로 곱해 더한 값.
- 👾 m4 문제 4 · 개수와 가격 ⛰ (⏱ 5.2분)
  - (m4-1) [choice] 김밥 한 줄은 1500원, 음료 한 병은 1000원이다. 1모둠은 김밥 2줄과 음료 1병, 2모둠은 김밥 3줄과 음료 2병을 샀다. A = (2  1 ; 3  2), B = (1500 ; 1000) 라 하자. (; 는 행을 나누는 표시) 곱 AB 의 (1, 1) 성분이 뜻하는 것은?  〔보기: 1모둠이 낸 금액 / 2모둠이 낸 금액 / 두 모둠이 산 김밥의 수 / 김밥 한 줄과 음료 한 병 값의 합〕  → **1모둠이 낸 금액** · 제1행(1모둠의 개수) × 가격 = 2 × 1500 + 1 × 1000.
  - (m4-2) [number] 김밥 한 줄은 1500원, 음료 한 병은 1000원이다. 1모둠은 김밥 2줄과 음료 1병, 2모둠은 김밥 3줄과 음료 2병을 샀다. A = (2  1 ; 3  2), B = (1500 ; 1000) 라 하자. (; 는 행을 나누는 표시) 곱 AB 의 (2, 1) 성분은?  → **6500** · 2모둠: 3 × 1500 + 2 × 1000 = 6500 (원).
- 👾 m5 🌱 여유 문제 · 세로 × 가로 (⏱ 2.9분)
  - (m5-1) [number] A = (1 ; 2), B = (3  4) 일 때, 곱 AB 는 2 × 2 행렬이다. AB 의 모든 성분의 합은? (; 는 행을 나누는 표시)  → **21** · AB = (3  4 ; 6  8) — 세로 행렬 × 가로 행렬은 2 × 2 가 된다.
- 👑 형성평가 4문항 (⏱ 8.4분) · 짝 = ['m1', 'm2', 'm3', 'm3']
  - (b-1) [choice] A 는 2 × 3 행렬, B 는 3 × 2 행렬일 때, 곱 AB 의 꼴은?  〔보기: 2 × 2 행렬 / 6 × 6 행렬 / 3 × 3 행렬 / 2 × 3 행렬〕  → **2 × 2 행렬** · (A 의 행의 수) × (B 의 열의 수) = 2 × 2.
  - (b-2) [number] A = (2  3), B = (4 ; 1) 일 때, 곱 AB 는 1 × 1 행렬이다. 그 성분은? (; 는 행을 나누는 표시)  → **11** · 2 × 4 + 3 × 1 (앞끼리, 뒤끼리 곱해 더한다).
  - (b-3) [number] A = (1  2 ; 0  1), B = (3  1 ; 2  4) 일 때, AB 의 (1, 2) 성분은? (; 는 행을 나누는 표시)  → **9** · A 의 제1행과 B 의 제2열: 1 × 1 + 2 × 4.
  - (b-4) [choice] A = (1  2 ; 0  1), B = (3  1 ; 2  4) 일 때, AB 는? (; 는 행을 나누는 표시)  〔보기: (7  9 ; 2  4) / (7  2 ; 9  5) / (3  2 ; 0  4) / (3  7 ; 2  8)〕  → **(7  9 ; 2  4)** · (i, j) 성분 = A 의 제i행과 B 의 제j열을 차례로 곱해 더한 값.
