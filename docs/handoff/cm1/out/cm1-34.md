## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 33차시: 행 · 열 · (i, j) 성분 · 서로 같은 행렬
- 💭 생각 열기: 매점의 1학기 판매량 행렬과 2학기 판매량 행렬 — 1년 판매량은 같은 자리끼리 더하면 된다.
- 📘 c1 덧셈과 뺄셈: 같은 꼴의 두 행렬은 같은 자리의 성분끼리 더하고 뺀다. 모든 성분이 0 인 행렬 = 영행렬 O. · ✔ 개념 체크: 2 × 2 행렬과 2 × 3 행렬은 더할 수 있다. → X
- 📘 c2 실수배: kA = A 의 모든 성분에 k 를 곱한 행렬. 덧셈 · 실수배는 수의 계산처럼 교환 · 결합 · 분배법칙이 성립한다. · ✔ 개념 체크: 2A 는 A 의 제1행에만 2 를 곱한 행렬이다. → X

- 👾 m1 문제 1 · 더하기와 빼기 (⏱ 3.6분)
  - (m1-1) [choice] A = (1  2 ; 3  −1), B = (2  0 ; −1  4) 일 때, A + B 는? (; 는 행을 나누는 표시)  〔보기: (−4  2 ; 2  −5) / (4  2 ; 2  3) / (3  2 ; 2  3) / (3  2 ; 2  4)〕  → **(3  2 ; 2  3)** · 같은 자리 성분끼리 더한다.
  - (m1-2) [choice] A = (1  2 ; 3  −1), B = (2  0 ; −1  4) 일 때, A − B 는? (; 는 행을 나누는 표시)  〔보기: (3  2 ; 2  3) / (−1  4 ; 2  −4) / (−1  2 ; 4  −5) / (1  −2 ; −4  5)〕  → **(−1  2 ; 4  −5)** · 같은 자리 성분끼리 뺀다 (A 의 성분 − B 의 성분).
- 👾 m2 문제 2 · 실수배 (⏱ 4.8분)
  - (m2-1) [number] A = (2  −1 ; 0  3) 일 때, 행렬 3A 의 모든 성분의 합은? (; 는 행을 나누는 표시)  → **12** · 모든 성분에 3을 곱한다 → 합도 3 배: 3 × 4.
  - (m2-2) [number] A = (1  2 ; 3  −1), B = (2  0 ; −1  4) 일 때, 행렬 2A − B 의 (1, 2) 성분은? (; 는 행을 나누는 표시)  → **4** · 2 × 2 − 0 의 값.
- 👾 m3 문제 3 · X 구하기 (⏱ 4.2분)
  - (m3-1) [choice] A = (1  2 ; 3  −1), B = (2  0 ; −1  4) 일 때, A + X = B 를 만족시키는 행렬 X 는? (; 는 행을 나누는 표시)  〔보기: (1  −4 ; −2  6) / (1  −2 ; −4  5) / (3  2 ; 2  3) / (−1  2 ; 4  −5)〕  → **(1  −2 ; −4  5)** · X = B − A (수의 방정식처럼 A 를 옮긴다).
  - (m3-2) [number] A = (3  −2 ; 1  5) 일 때, A + X = O 를 만족시키는 행렬 X 의 (2, 2) 성분은? (O 는 모든 성분이 0 인 영행렬) (; 는 행을 나누는 표시)  → **-5** · X = −A → 모든 성분의 부호를 바꾼다.
- 👾 m4 문제 4 · 실수배가 섞인 X ⛰ (⏱ 5.2분)
  - (m4-1) [choice] A = (1  2 ; 0  −3), B = (5  0 ; 4  1) 이고 2X + A = B 일 때, 2X 는? (; 는 행을 나누는 표시)  〔보기: (4  4 ; −2  5) / (6  2 ; 4  −2) / (5  −2 ; 4  4) / (4  −2 ; 4  4)〕  → **(4  −2 ; 4  4)** · 2X = B − A (A 를 옮긴다).
  - (m4-2) [number] A = (1  2 ; 0  −3), B = (5  0 ; 4  1) 이고 2X + A = B 일 때, 행렬 X 의 모든 성분의 합은? (; 는 행을 나누는 표시)  → **5** · X = (B − A) ÷ 2. B − A 의 성분의 합 10을 2로 나눈다.
- 👾 m5 🌱 여유 문제 · 순서를 바꿔 더하기 (⏱ 1.7분)
  - (m5-1) [ox] A = (1  2 ; 3  −1), B = (2  0 ; −1  4) 일 때, A + B = B + A 이다. (; 는 행을 나누는 표시)  → **O** · 행렬의 덧셈은 성분끼리의 덧셈 → 순서를 바꿔도 같다(교환법칙).
- 👑 형성평가 4문항 (⏱ 7.8분) · 짝 = ['m1', 'm1', 'm2', 'm3']
  - (b-1) [choice] A = (1  2 ; 3  −1), B = (2  0 ; −1  4) 일 때, A + B 는? (; 는 행을 나누는 표시)  〔보기: (3  2 ; 2  4) / (3  2 ; 2  3) / (4  2 ; 2  3) / (−4  2 ; 2  −5)〕  → **(3  2 ; 2  3)** · 같은 자리 성분끼리 더한다.
  - (b-2) [choice] A = (1  2 ; 3  −1), B = (2  0 ; −1  4) 일 때, A − B 는? (; 는 행을 나누는 표시)  〔보기: (−1  4 ; 2  −4) / (−1  2 ; 4  −5) / (1  −2 ; −4  5) / (3  2 ; 2  3)〕  → **(−1  2 ; 4  −5)** · 같은 자리 성분끼리 뺀다 (A 의 성분 − B 의 성분).
  - (b-3) [number] A = (2  −1 ; 0  3) 일 때, 행렬 3A 의 모든 성분의 합은? (; 는 행을 나누는 표시)  → **12** · 모든 성분에 3을 곱한다 → 합도 3 배: 3 × 4.
  - (b-4) [choice] A = (1  2 ; 3  −1), B = (2  0 ; −1  4) 일 때, A + X = B 를 만족시키는 행렬 X 는? (; 는 행을 나누는 표시)  〔보기: (1  −4 ; −2  6) / (1  −2 ; −4  5) / (3  2 ; 2  3) / (−1  2 ; 4  −5)〕  → **(1  −2 ; −4  5)** · X = B − A (수의 방정식처럼 A 를 옮긴다).
