## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 중학교: 근의 공식 · 12차시: √(−a) = √a i
- 💭 생각 열기: 번호판 색만 보고 친환경 차를 알듯, 근을 구하지 않고도 실근인지 허근인지 아는 법 — 근호 안의 부호.
- 📘 c1 실근과 허근: 계수가 실수인 이차방정식은 복소수 범위에서 반드시 근을 갖는다. 실수인 근 = 실근, 허수인 근 = 허근. · ✔ 개념 체크: 이차방정식 x² + 9 = 0 은 복소수의 범위에서 근이 없다. → X
- 📘 c2 판별식 D = b² − 4ac: D > 0 서로 다른 두 실근 · D = 0 중근(실근) · D < 0 서로 다른 두 허근. 실근을 가질 조건은 D ≥ 0. · ✔ 개념 체크: 이차방정식이 실근을 가질 조건은 D > 0 이다. → X

- 👾 m1 문제 1 · 풀어서 실근 · 허근 (⏱ 3.0분)
  - (m1-1) [choice] 이차방정식 x² − 4x + 7 = 0 의 해는?  〔보기: x = 2 ± √7 i / x = −2 ± √3 i / x = 2 ± √3 i / x = 2 ± √3〕  → **x = 2 ± √3 i** · 근의 공식(짝수 공식): x = 2 ± √(4 − 7) = 2 ± √(−3).
  - (m1-2) [ox] 이차방정식 x² + 2x + 4 = 0 의 근은 허근이다.  → **O** · 근호 안 b² − 4ac = −12 < 0 → 허근.
- 👾 m2 문제 2 · 판별식으로 판별 (⏱ 4.2분)
  - (m2-1) [number] 이차방정식 x² + 3x − 1 = 0 의 판별식 D = b² − 4ac 의 값은?  → **13** · (3)² − 4 × 1 × (−1).
  - (m2-2) [choice] 이차방정식 x² + 3x − 1 = 0 의 근을 판별하면?  〔보기: 서로 다른 두 실근 / 중근 (실근) / 서로 다른 두 허근〕  → **서로 다른 두 실근** · D = 13 > 0.
- 👾 m3 문제 3 · 근의 조건으로 a 의 범위 (⏱ 4.2분)
  - (m3-1) [choice] 이차방정식 x² + 4x + a − 3 = 0 이 실근을 갖도록 하는 실수 a 의 값의 범위는?  〔보기: a > 7 / a < 7 / a ≤ 7 / a ≥ 7〕  → **a ≤ 7** · 실근 ⟺ D ≥ 0 (중근 포함): D/4 = 4 − (a − 3) ≥ 0.
  - (m3-2) [number] 이차방정식 x² + 4x + a − 3 = 0 이 중근을 갖도록 하는 실수 a 의 값은?  → **7** · 중근 ⟺ D = 0: 4 − a − (−3) = 0.
- 👾 m4 문제 4 · 중근일 때 k ⛰ (⏱ 6.9분)
  - (m4-1) [choice] 이차방정식 x² − 2(k + 1)x + k² + 5 = 0 이 중근을 갖는다 (k 는 실수). 이 조건을 판별식 D 로 쓰면?  〔보기: D = 0 / D < 0 / D ≥ 0 / D > 0〕  → **D = 0** · 중근 ⟺ 판별식이 0.
  - (m4-2) [choice] 이차방정식 x² − 2(k + 1)x + k² + 5 = 0 이 중근을 갖는다 (k 는 실수). D/4 = (k + 1)² − (k² + 5) 를 정리하면?  〔보기: 2k² + 2k − 4 / 2k − 4 / 2k + 6 / −2k − 4〕  → **2k − 4** · k² 이 서로 지워지고 k 의 일차식만 남는다.
  - (m4-3) [number] 이차방정식 x² − 2(k + 1)x + k² + 5 = 0 이 중근을 갖는다 (k 는 실수). k 의 값은?  → **2** · D/4 = 2k − 4 = 0 을 푼다.
- 👾 m5 🌱 여유 문제 · 부호만 보고 판별 (⏱ 2.3분)
  - (m5-1) [choice] 이차방정식 2x² + x − 5 = 0 은 이차항의 계수와 상수항의 부호가 다르다. 이 방정식의 근은?  〔보기: 서로 다른 두 실근 / 중근 (실근) / 서로 다른 두 허근 / 근이 없다〕  → **서로 다른 두 실근** · ac < 0 이면 −4ac > 0 → D = b² − 4ac > 0.
- 👑 형성평가 4문항 (⏱ 7.8분) · 짝 = ['m1', 'm2', 'm3', 'm4']
  - (b-1) [choice] 이차방정식 x² − 4x + 7 = 0 의 해는?  〔보기: x = 2 ± √3 i / x = −2 ± √3 i / x = 2 ± √3 / x = 2 ± √7 i〕  → **x = 2 ± √3 i** · 근의 공식(짝수 공식): x = 2 ± √(4 − 7) = 2 ± √(−3).
  - (b-2) [choice] 이차방정식 x² + 3x − 1 = 0 의 근을 판별하면?  〔보기: 서로 다른 두 실근 / 중근 (실근) / 서로 다른 두 허근〕  → **서로 다른 두 실근** · D = 13 > 0.
  - (b-3) [choice] 이차방정식 x² + 4x + a − 3 = 0 이 실근을 갖도록 하는 실수 a 의 값의 범위는?  〔보기: a ≤ 7 / a > 7 / a ≥ 7 / a < 7〕  → **a ≤ 7** · 실근 ⟺ D ≥ 0 (중근 포함): D/4 = 4 − (a − 3) ≥ 0.
