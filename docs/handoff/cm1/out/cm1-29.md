## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 27차시: 곱의 법칙 · 28차시: 서로 다른 색으로 칠하기(한 번 쓴 것은 다시 못 씀)
- 💭 생각 열기: DNA 염기 4개 중 3개를 골라 줄 세우면? 고르는 순서가 다르면 다른 것으로 센다 = 순열.
- 📘 c1 순열과 ₙPᵣ: 서로 다른 n 개에서 r 개를 택하여 일렬로 나열하는 것 = 순열. ₙPᵣ = n(n − 1)(n − 2) … (n − r + 1) (r 개의 곱). · ✔ 개념 체크: ₅P₂ = 5 × 2 = 10 이다. → X
- 📘 c2 계승 n!: n! = n(n − 1) … 2 · 1 = ₙPₙ · 0! = 1, ₙP₀ = 1 · ₙPᵣ = n! / (n − r)!. · ✔ 개념 체크: 0! = 0 이다. → X

- 👾 m1 문제 1 · ₙPᵣ 계산 (⏱ 4.8분)
  - (m1-1) [number] ₅P₂ 의 값은?  → **20** · 5 부터 1 씩 줄여 가며 2개를 곱한다: 5 × 4.
  - (m1-2) [number] ₙP₂ = 30 을 만족시키는 자연수 n 의 값은?  → **6** · n(n − 1) = 30 = 6 × 5.
- 👾 m2 문제 2 · 계승 (⏱ 4.2분)
  - (m2-1) [number] 5! 의 값은?  → **120** · 5 × 4 × 3 × 2 × 1.
  - (m2-2) [choice] ₆P₃ 을 계승(!)을 써서 나타내면?  〔보기: 6! × 3! / 6! / 4! / 6! / 3! / 3! / 6!〕  → **6! / 3!** · ₙPᵣ = n! / (n − r)! → 뒤에 남는 3! 로 나눈다.
- 👾 m3 문제 3 · 뽑아서 줄 세우기 (⏱ 4.8분)
  - (m3-1) [number] 학생 5명 중에서 3명을 뽑아 한 줄로 세우는 방법의 수는?  → **60** · 서로 다른 5개에서 3개를 택해 일렬로 → ₅P₃.
  - (m3-2) [number] 학생 6명 중에서 회장 1명, 부회장 1명을 뽑는 방법의 수는?  → **30** · 역할이 서로 다르므로 순서가 있는 뽑기 → ₆P₂.
- 👾 m4 문제 4 · ₙP₃ = k × ₙP₂ ⛰ (⏱ 6.9분)
  - (m4-1) [choice] 등식 ₙP₃ = 4 × ₙP₂ 를 만족시키는 자연수 n (n ≥ 3) 에 대하여 등식을 n 의 식으로 풀어 쓰면?  〔보기: n³ = 4n² / n(n − 1)(n − 2) = 4n(n − 2) / n(n − 1)(n − 2) = 4n(n − 1) / 3n = 8n〕  → **n(n − 1)(n − 2) = 4n(n − 1)** · ₙP₃ = n(n − 1)(n − 2), ₙP₂ = n(n − 1).
  - (m4-2) [choice] 등식 ₙP₃ = 4 × ₙP₂ 를 만족시키는 자연수 n (n ≥ 3) 에 대하여 n(n − 1)(n − 2) = 4n(n − 1) 의 양변을 n(n − 1) 로 나누면? (n ≥ 3 이므로 n(n − 1) ≠ 0)  〔보기: n − 1 = 4 / n − 2 = 4 / n = 4 / n + 2 = 4〕  → **n − 2 = 4** · 양변에 똑같이 들어 있는 n(n − 1) 을 약분한다.
  - (m4-3) [number] 등식 ₙP₃ = 4 × ₙP₂ 를 만족시키는 자연수 n (n ≥ 3) 에 대하여 n 의 값은?  → **6** · n − 2 = 4.
- 👾 m5 🌱 여유 문제 · 모두 줄 세우기 (⏱ 2.9분)
  - (m5-1) [number] 서로 다른 책 4권을 책꽂이에 한 줄로 모두 꽂는 방법의 수는?  → **24** · 4개를 모두 일렬로 → 4!.

  - (b-2) [number] 5! 의 값은?  → **120** · 5 × 4 × 3 × 2 × 1.

  - (b-4) [number] 학생 6명 중에서 회장 1명, 부회장 1명을 뽑는 방법의 수는?  → **30** · 역할이 서로 다르므로 순서가 있는 뽑기 → ₆P₂.
