# 3차시 · 곱셈 공식의 활용 — 시안 (공통수학1 · Ⅰ-1 다항식의 연산)

> 교과서 17 (예제 3 · 문제 4) · 21 (중단원 07 · 10)쪽 · 목표: 곱셈 공식을 변형하여 여러 가지 식의 값을 구할 수 있다.
> ⏱ 예상 46.3분(여유 문제 빼고) · 여유 문제 +6.5분 · 어려운 문제(산) = m4 · 산 = 중단원 마무리 10번 꼴(직육면체) · 대각선은 「길이의 제곱」으로 주어 √ 계산을 덜어 냄
> 문항 119줄(판 0 ~ 6) · 계산 검산 ✅ 119 · 눈으로 확인 0 · ❌ 0 · 글 검사 걸림 0 · 같은 판 0

## 학습지 구성 (판 0 = 학습지에 실을 문항)

- 🔁 전시 확인: 2차시 곱셈 공식 세 줄 빈칸: (a + b + c)² · (a + b)³ · (a + b)(a² − ab + b²)
- 💭 생각 열기: 두 수를 몰라도 합과 곱만 알면 제곱의 합 · 세제곱의 합을 알 수 있다 → 공식을 「거꾸로」 쓴다.
- 📘 c1 합과 곱으로 a² + b², a³ ± b³ 구하기: a² + b² = (a + b)² − 2ab · a³ + b³ = (a + b)³ − 3ab(a + b) · a³ − b³ = (a − b)³ + 3ab(a − b). · ✔ 개념 체크: a + b = 3, ab = 1 이면 a² + b² = 9 이다. → X
- 📘 c2 세 문자: a² + b² + c² 과 (a + b + c)²: a² + b² + c² = (a + b + c)² − 2(ab + bc + ca). 직육면체의 겉넓이 · 대각선 문제에 쓰인다.

- 👾 m1 문제 1 · a² + b² (⏱ 4.2분)
  - (m1-1) [choice] a + b 와 ab 의 값을 알 때, a² + b² 을 구하는 식은?  〔보기: (a + b)² / (a + b)² − 2ab / (a + b)² − ab / (a + b)² + 2ab〕  → **(a + b)² − 2ab** · (a + b)² = a² + 2ab + b² 에서 2ab 를 넘긴다.
  - (m1-2) [number] a + b = 2, ab = −3 일 때, a² + b² 의 값은?  → **10** · (2)² − 2 × (−3) = 4 − (−6).
- 👾 m2 문제 2 · a³ + b³ (⏱ 4.2분)
  - (m2-1) [choice] a + b 와 ab 의 값을 알 때, a³ + b³ 을 구하는 식은?  〔보기: (a + b)³ + 3ab(a + b) / (a + b)³ − 3ab(a + b) / (a + b)³ − 3ab / (a + b)³〕  → **(a + b)³ − 3ab(a + b)** · (a + b)³ 을 전개하면 3a²b + 3ab² = 3ab(a + b) 가 더 붙는다.
  - (m2-2) [number] a + b = 5, ab = 4 일 때, a³ + b³ 의 값은?  → **65** · (5)³ − 3 × (4) × (5) = 125 − (60).
- 👾 m3 문제 3 · a² + b² + c² (⏱ 4.2분)
  - (m3-1) [choice] a + b + c 와 ab + bc + ca 의 값을 알 때, a² + b² + c² 을 구하는 식은?  〔보기: (a + b + c)² − 2(ab + bc + ca) / (a + b + c)² − (ab + bc + ca) / (a + b + c)² / (a + b + c)² + 2(ab + bc + ca)〕  → **(a + b + c)² − 2(ab + bc + ca)** · 세 항의 제곱 공식에서 2(ab + bc + ca) 를 넘긴다.
  - (m3-2) [number] a + b + c = 9, ab + bc + ca = 26 일 때, a² + b² + c² 의 값은?  → **29** · 9² − 2 × 26 = 81 − 52.
- 👾 m4 문제 4 · 직육면체의 a + b + c ⛰ (⏱ 10.1분)
  - (m4-1) [number] 가로 a, 세로 b, 높이 c 인 직육면체의 겉넓이가 94 이고 대각선의 길이의 제곱이 50 이다. 겉넓이 = 2(ab + bc + ca) 임을 이용하면 ab + bc + ca 의 값은?  → **47** · 2(ab + bc + ca) = 94 → 양변을 2로 나눈다.
  - (m4-2) [choice] 가로 a, 세로 b, 높이 c 인 직육면체의 겉넓이가 94 이고 대각선의 길이의 제곱이 50 이다. 대각선의 길이의 제곱을 a, b, c 로 나타내면?  〔보기: ab + bc + ca / (a + b + c)² / a² + b² + c² / a + b + c〕  → **a² + b² + c²** · 직육면체의 대각선: 밑면 대각선² = a² + b², 여기에 c² 을 더한다(피타고라스 두 번).
  - (m4-3) [number] a² + b² + c² = 50, ab + bc + ca = 47 일 때, (a + b + c)² 의 값은?  → **144** · (a + b + c)² = a² + b² + c² + 2(ab + bc + ca) = 50 + 94.
  - (m4-4) [number] 가로 a, 세로 b, 높이 c 인 직육면체의 겉넓이가 94 이고 대각선의 길이의 제곱이 50 이다. a + b + c 의 값은? (a, b, c 는 양수)  → **12** · (a + b + c)² = 50 + 94 = 144 → 양수이므로 12.
- 👾 m5 🌱 여유 문제 · x³ − y³ (⏱ 4.2분)
  - (m5-1) [choice] x − y 와 xy 의 값을 알 때, x³ − y³ 을 구하는 식은?  〔보기: (x − y)³ / (x − y)³ − 3xy(x − y) / (x − y)³ + 3xy / (x − y)³ + 3xy(x − y)〕  → **(x − y)³ + 3xy(x − y)** · (x − y)³ = x³ − 3x²y + 3xy² − y³ → −3xy(x − y) 를 넘기면 + 가 된다.
  - (m5-2) [number] x − y = 7, xy = −10 일 때, x³ − y³ 의 값은?  → **133** · (7)³ + 3 × (−10) × (7) = 343 + (−210).
- 👾 m6 🌱 여유 문제 · 무리수 대입 (⏱ 2.3분)
  - (m6-1) [choice] x = √2 + 1, y = √2 − 1 일 때, x³ + y³ 의 값은?  〔보기: 10 / 16√2 / 22√2 / 10√2〕  → **10√2** · x + y = 2√2, xy = 1 → (2√2)³ − 3 × 1 × 2√2 = 16√2 − 6√2.
- 👑 형성평가 4문항 (⏱ 9.6분) · 짝 = ['m1', 'm2', 'm3', 'm4']
  - (b-1) [number] a + b = 2, ab = −3 일 때, a² + b² 의 값은?  → **10** · (2)² − 2 × (−3) = 4 − (−6).
  - (b-2) [number] a + b = 5, ab = 4 일 때, a³ + b³ 의 값은?  → **65** · (5)³ − 3 × (4) × (5) = 125 − (60).
  - (b-3) [number] a + b + c = 9, ab + bc + ca = 26 일 때, a² + b² + c² 의 값은?  → **29** · 9² − 2 × 26 = 81 − 52.
  - (b-4) [number] a² + b² + c² = 50, ab + bc + ca = 47 일 때, (a + b + c)² 의 값은?  → **144** · (a + b + c)² = a² + b² + c² + 2(ab + bc + ca) = 50 + 94.
