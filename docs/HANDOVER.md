## 수업 흐름 (v0.2.0)
| 단계 | 교사 폰 | 종합상황실 | 학생 폰 |
|---|---|---|---|
| 대기실 | QR · 코드 · 입장 명단 → ▶ = 수업 시작 (대기실 인원 확정 = 체력 계산 인원) | QR · 입장 인원 · 용사단(머리 위 번호·실명) | 수업 코드 + 로그인(반·번호 → 가린 이름 확인 → 4자리, 처음이면 가입 + 용사 고르기) → 던전 입장 |
| 도입 · 개념 설명 | ◀ ▶ | 학습지 이미지(화면 절반, 수업 준비에서 올림) + 단계 제목·요약 | "📣 선생님에게 주목하세요" |
| 몬스터 (문제 · 보강) | ◀ ▶ · 제출 n/N · 기준% −5/+5 · 도움 필요 학생 | 던전 배경 레이드: 공동 체력 막대, 제출할 때마다 용사가 움직임 (성공 = 달려가 타격 + 번쩍 + 데미지 숫자, 실패 = 휘두르고 물렁한 소리) · 보강은 "⭐ 스페셜 몬스터 난입!" | 몬스터 1마리와 대치. 소문제를 모두 풀고 [공격!] → 바로 채점 → 성공 / 부분 성공(3/4) / 실패 + 해설 → "다시 해 보겠습니까?" (2번까지, 숫자 모두 바뀜, 지난번 틀린 칸 ✘) |
| 형성평가 (보스) | 데미지 · 기준% | "👑 보스 출현!" + 화면 흔들림 + 땅울림. 체력 0 → 즉시 승리 | 1~7번 (7번 ⭐ 보너스) · 세트1 → 틀린 문항은 세트2 (폰 입력. 사진 채점은 4단계) |
| 끝 | — | 던전 클리어 | 트로피 |

**▶ 를 눌렀는데 몬스터가 남았으면:** 미제출 학생이 있으면 번호를 알려 주고, 한 번 더 누르면 그 학생을 빼고 판정. 체력이 남았으면 알려 주고, 한 번 더 누르면 그대로 넘어감.

## 레이드 규칙 (`js/raid/model.js`, `tests/model.test.js`)
| 규칙 | 내용 |
|---|---|
| 체력 | ⌊대기실 인원 × 소문제 수 × 기준%⌋ (18명 · 4칸 · 90% → 64). 기준% = 몬스터마다 교사가 실시간 조정, 기본값은 수업 준비 화면 (없으면 90) |
| 데미지 | 학생마다 **가장 많이 맞힌 소문제 수** (재도전은 늘어난 만큼만 더해짐) |
| 재도전 | 2번 (시도 최대 3번). 소문제 전부 새 숫자 (시드 `수업코드|학생|몬스터|시도`) |
| 격파 | 참여 학생 **전원이 한 번 이상 제출**(제외된 학생 빼고)한 뒤 체력 0 이하 |
| 보스 | 체력 ⌊인원 × 6 × 기준%⌋, 문항별로 세트1·세트2 중 한 번이라도 맞히면 1 데미지, 7번은 보너스. **체력 0 즉시 승리** |
| 도움 필요 | 직접 요청 > 재도전까지 다 썼는데 다 못 맞힘 > 몬스터가 나온 지 2분째 미제출 (교사 폰에만) |
| 개인정보 | 정답·오답 **글자**는 종합상황실에 안 띄움. 공격 연출(성공·실패)은 보임 (사용자 결정) |

## 데이터 모양 (Firebase)
- `rooms/{코드}`: `meta`(차시·교사·기준% 기본값) · `hosts` · `state`(step·stepAt·headcount·pct·skip) · `active` · `players` · `help` · `subs/{몬스터}/{uid}/{시도}`(답 JSON) · `bossAns/{uid}/{세트}`
- `secrets/{코드}`: 종합상황실 키 (학생은 못 읽음)
- `prep/{차시}`: `img/{단계}`(학습지 이미지, 줄인 JPEG) · `pct`(기준% 기본값) — 교사 계정만 씀
- `roster/{반}/{번호}` 이름 (로그인한 계정만 읽음) · `rosterMask/{반}/{번호}` 가린 이름 · `accounts/{반}/{번호}` { uid, gen, hero, reset? } · `admins/{uid}`

## 차시 추가 방법
1. `lessons/<id>.js` 를 `set-03.js` 처럼 만든다 (`js/engine/lessons.js` 머리말의 pack 형식). 학습지를 기반으로 하고, 게임으로 어려운 문항은 **변경안을 PDF로 제안 → 컨펌 후** 반영.
2. `index.html` · `demo.html` 에 `<script>` 한 줄, `sw.js` CORE 에도 추가.
3. `tests/` 에 첫 시도 = 학습지 정답, 재도전 생성기 독립 검산, 형성평가 검산.
4. 차시별 그림(던전 입구 등)은 사용자에게 묻는다. 학습지·교과서 원본은 커밋하지 않는다.
