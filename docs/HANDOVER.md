## 레이드 규칙 (`js/raid/model.js`, `tests/model.test.js`)
| 규칙 | 내용 |
|---|---|
| 체력 | ⌊대기실 인원 × 소문제 수 × 기준%⌋ (18명 · 4칸 · 90% → 64). 기준% = 몬스터마다 교사가 실시간 조정, 기본값은 수업 준비 화면 (없으면 90) |
| 데미지 | 학생마다 **가장 많이 맞힌 소문제 수** (재도전은 늘어난 만큼만 더해짐) |
| 재도전 | 2번 (시도 최대 3번). 소문제 전부 새 숫자 (시드 `수업코드|학생|몬스터|시도`) |
| 격파 | 참여 학생 **전원이 한 번 이상 제출**(제외된 학생 빼고)한 뒤 체력 0 이하 |

## 데이터 모양 (Firebase)
- `rooms/{코드}`: `meta`(차시·교사·기준% 기본값) · `hosts` · `state`(step·stepAt·headcount·pct·skip·**focus·closed**) · `active` · `players`(num·nick·hero·**fx·cls·lobby**) · **`online/{uid}`**(접속, 끊기면 서버가 지움) · `help` · `subs/{몬스터}/{uid}/{시도}`(답 JSON) · `bossAns/{uid}/{세트}` · **`words/{uid}`**(한마디) · **`hide/{uid}`**
- `rooms/{코드}/state/sheet` = 📄 문제 화면 켜짐 (단계가 바뀌면 지움) · `prep/{차시}/img/{단계}` 는 개념 · 문제 · 보강 · 형성평가 모든 단계
- `sheets/{id}` = 엑셀로 만든 차시 pack (앱 시작 때 모두 불러와 등록)
- `live/{반}` = { code, lesson, no, theme, open } 지금(또는 마지막) 차원문 · `rooms/{코드}/meta` 에 cls(반) · think(생각 시간)
- `unlock/{반}` = 그 반에 배포한 가장 큰 차시 번호 (모루 열림) · `cards/{반}/{번호}/{카드}` 만든 카드 · `wordLock/{반}/{번호}` 한마디 잠금
- `bonus/{반}/{번호}/{차시}/{몬스터}` = { tries, clear, at } 보강던전 · `xp/{반}/{번호}` = { total, log/{키} } · `records/{반}/{번호}/{차시}` = 개인 결과 요약(개념별 첫 시도 · 복습 추천) · `prep/{차시}/video/{칸}` = 🎬 영상 링크 또는 'file' · `prepVideo/{차시}/{칸}` = 올린 영상 파일(data URL, 3MB 이하)
- `secrets/{코드}`: 종합상황실 키 (학생은 못 읽음)
- `prep/{차시}`: `img/{단계}`(학습지 이미지, 줄인 JPEG) · `pct`(기준% 기본값) — 교사 계정만 씀
- `roster/{반}/{번호}` 이름 (로그인한 계정만 읽음) · `rosterMask/{반}/{번호}` 가린 이름 · `accounts/{반}/{번호}` { uid, gen, hero, fx, reset? } · `admins/{uid}`

## 차시 추가 방법
1. `lessons/<id>.js` 를 `set-03.js` 처럼 만든다 (`no`: 차시 번호 — 모루 열림, `crops`: PDF 자르기 위치) (`js/engine/lessons.js` 머리말의 pack 형식). 학습지를 기반으로 하고, 게임으로 어려운 문항은 **변경안을 PDF로 제안 → 컨펌 후** 반영.
2. `index.html` · `demo.html` 에 `<script>` 한 줄, `sw.js` CORE 에도 추가.
3. `tests/` 에 첫 시도 = 학습지 정답, 재도전 생성기 독립 검산, 형성평가 검산.
4. 차시별 그림(던전 입구 등)은 사용자에게 묻는다. 학습지·교과서 원본은 커밋하지 않는다.
