## 수업 흐름 (50분 기준 예시)
| 단계 | 교사 폰 | 종합상황실 | 학생 폰 |
|---|---|---|---|
| 입장 | 새 수업 → 코드·QR·키 | QR·코드, 입장 인원 | 코드·번호·닉네임·용사 고르기 |
| 연성 (단계 1~4) | 단계 버튼, 학생 탭에서 카드 ✓·🙋 | 단계 카드 2장, 완성 인원, 선생님 시범 연성 | 모루에서 연성 → 첫 카드는 예제를 맞혀야 완성 |
| 전투 | 몬스터 유형 골라 소환 (모두 카드가 있어야) | 몬스터, 제출 n/N | 문제 풀기 → 맞는 카드 고르기 → 공격 (공격력 110 → 1초에 1씩 → 최저 100) |
| 마지막 공격 | 학생 전원 제출 뒤 선생님 문제·카드 제출 | 같음 (어느 쪽에서 해도 됨) | 대기 |
| 결과 | 틀린 사람(교사 폰에만) → 설명 → ↻ 재도전 | 성공/실패 연출만 | 내 정답·해설 |
| 보스 | 학생 탭 문항 도달 ●○ → 🏆 선언 | 보스 체력 (학생 수 × 6 × 100) | 형성평가 1~6번, 세트 2 로 재도전 |
| 끝 | 최고 용사 | 트로피 · 최고 용사 | 트로피 |

## 점수·판정 (`js/raid/model.js`, `tests/model.test.js`)
| 규칙 | 내용 |
|---|---|
| 공격력 | 문제를 연 시각부터 `100 + max(0, 10 − ⌊초⌋)` (110 → 100). 교사는 점수 없음 |
| 정답 | 그 문제에 맞는 카드(`q.cards`)를 **가지고 있고** 골랐으며, 답이 맞아야 정답 |
| 공동 공격 | 교사 포함 전원 정답이면 성공. 아니면 실패 → 같은 유형·새 숫자로 재도전 |
| 점수 | 몬스터마다 첫 정답만 (`credits/{uid}/m{번호}`) |
| 보스 | 문항별로 세트1·세트2 중 한 번이라도 맞히면 도달, 문항당 100 |
| 최고 용사 | 일반전 점수 + 보스 기여. 동점은 추첨, 교사 제외 |
| 문제 숫자 | 시드 `라운드id|uid` → 학생마다 다른 숫자, 교사 기기가 같은 시드로 다시 만들어 채점 |

## 3차시 내용 (`lessons/set-03.js`)
| 단계 | 카드 (연성법) | 몬스터 문제 유형 |
|---|---|---|
| 1 부분집합 | 포함 판정 `[A] ⊂ [B]` · 반례 탐지 `[A] ⊄ [B]` | 포함 판정 · 조건제시법 포함 · 반례 찾기 |
| 2 꼭 기억할 두 가지 | 자기 포함 `[A] ⊂ [A]` · 공집합의 포함 `[∅] ⊂ [A]` | 자기 포함 · 공집합의 포함 · ∈ 와 ⊂ 구별 |
| 3 서로 같은 집합 | `[B] ⊂ [A]` 부품 → `[포함 판정] 이고 [B ⊂ A]` | 서로 같은 집합 · 조건제시법 같은 집합 |
| 4 부분집합 모두 구하기 | 부분집합 탐색 `[∅] ⋯ [A]` · 진부분집합 `[부분집합 탐색] − [A]` | 부분집합 모두 · 진부분집합 개수 |
| 보스 | 3차시 형성평가 6문항 | 세트1 = 학습지 그대로, 세트2 = 숫자 바꾼 재도전 |

검산 (`node tests/lesson.test.js`): 연성 8개 엄격 판정 · 문제 유형마다 500개씩 5000개를 원소를 직접 세거나 조건을 다시 계산해 확인 · 형성평가 두 세트 정답 확인.
- 이 수업에서 `⊂` 는 학습지처럼 서로 같은 집합도 포함하는 부분집합 기호다.
- 형성평가 세트1 정답(학습지): ⊂·⊄ / ④ / = / {5, 7} 의 부분집합 ∅, {5}, {7}, {5, 7} / 3 / a = 3
- 세트2 정답: {2,4} ⊂ {2,4,6}, {2,5} ⊄ … / ② / {x | x는 4의 약수} = {1, 2, 4} / {2, 8} 의 부분집합 4개 / 3 / a = 5

## 데이터 모양 (Firebase `rooms/{코드}`)
`meta`(차시·교사 uid) · `hosts`(교사 기기) · `state`(phase·stage·monster·round·result·winner) · `active`(참여 학생) · `players` · `cards` · `help` · `seen` · `subs`(답은 JSON 문자열) · `credits` · `bossAns`. 종합상황실 키는 `secrets/{코드}` (학생은 못 읽음).
보안 규칙: 학생은 자기 칸(players·cards·help·seen·subs·bossAns)만, 제출은 전투 중 한 번만. 진행·판정·점수는 교사·종합상황실만.

## 차시 추가 방법
1. `lessons/<id>.js` 를 `set-03.js` 처럼 만든다 (`js/engine/lessons.js` 머리말의 pack 형식). 카드 그림은 `assets/manifest.js` 의 칸 번호.
2. `index.html` · `demo.html` 의 `<script src="lessons/set-03.js">` 아래에 한 줄 추가 → 교사 폰 차시 목록에 자동으로 뜬다.
3. `tests/lesson.test.js` 처럼 새 차시의 연성·문제·형성평가를 **독립 계산으로 검산**하는 테스트를 추가.
4. 학습지·교과서 원본은 커밋하지 않는다 (문제 문장·정답만 옮긴다).
