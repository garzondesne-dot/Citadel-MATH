# ⚔ 소레이드 설계 규칙 (머리 방 · 2026-11-09 선생님과의 대화에서 배운 것)

> 목적: 선생님이 시안을 여러 번 고치지 않게, **머리 방이 처음부터 이 규칙으로 짜고 · 스스로 검사한 뒤** 보여 준다.
> 새 소레이드(수업 · 성채 · 허수아비)를 짜거나 고칠 때 이 파일을 먼저 읽는다. 규칙이 바뀌면 머리 방이 이 파일을 고친다.

## 1. 단계 짜기 (졸개 → 대장)

| # | 규칙 | 배운 곳 (11/09) |
|---|---|---|
| S1 | **졸개 하나 = 개념 하나.** 같은 개념(예: A · B 원소나열)은 한 졸개로 묶는다(한 화면 칸 둘). | 문제 4 「졸개1 · 2 같은 개념이야」 |
| S2 | **조건의 뜻도 개념이다.** 식 · 조건이 나오면 「이 조건이 뜻하는 것은?」을 고르는 졸개를 계산보다 먼저 둔다 (예: B ∪ X = B → X ⊂ B · A ∩ X = ∅ → 서로소). | 문제 4 「서로소 · X ⊂ B 도 개념」 |
| S3 | **결론을 갑자기 묻지 않는다.** 최댓값 · 최솟값 · 개수를 묻기 전에 「언제 그렇게 되나?」를 고르는 졸개를 먼저 (예: 「가장 많을 때는?」 B ⊂ A). | 문제 6 「너무 갑자기 뜬금없이 결론」 |
| S4 | **식을 세우는 단계는 「맞는 식을 모두 고르기」로.** 정답 식 2개 안팎 + 함정 식 3개 · 고른 식이 「나의 풀이」 문장이 된다. | 문제 5 「두 개를 적절하게 골라야 서술문이 채워져야지」 |
| S5 | **「가능한가? ○/✕」 같은 질문은 쓰지 않는다** (풀이의 한 줄이 되지 않는 질문 금지). 모든 졸개의 답은 그대로 「나의 풀이」 한 줄이 된다. | 문제 5 「가능하다 · 불가능하다는 너무 이상한 질문」 |
| S6 | **세는 노가다는 요령 단계로 쪼갠다** (예: 「가장 작은 원소」 → 「몇씩 커지나 = 최소공배수」). | 문제 7 「노가다밖에 없나?」 |
| S7 | 단계 수 = **3~5** (수업 시간) · 대장 = 문제가 묻는 마지막 답 · 대장 say 는 「그러므로 …」. | #18 |

## 2. 💡 근거 줄 (서술형 사다리)

| # | 규칙 | 배운 곳 |
|---|---|---|
| R1 | 근거 줄 = **비약이 일어나는 사실 · 공식 하나** (낱말이 아니라 「부분집합의 개수 = 2ⁿ」 같은 것). | 문제 4 「비약이라는 뜻이었어」 |
| R2 | 근거 줄은 **그 근거를 쓰는 단계를 맞힌 뒤**에 붙인다. 첫 판 완성 문장 · 한 판 더 빈칸 모두. | 문제 4 「정답이 먼저 공개됨」 |
| R3 | 보기 3개 = 정답 + 대표 오개념 2개 · 틀려도 기회 안 깎임. | #26 · #40 |

## 3. 보기 · 함정

| # | 규칙 |
|---|---|
| T1 | 함정 = **학생이 실제로 하는 착각**: 포함 방향 반대(A ⊂ B ↔ B ⊂ A) · 서로소(A ∩ B = ∅) · 합 ↔ 교 · 드모르간 기호 그대로 · 최대 ↔ 최소 조건 바꿈 · 두 수의 곱 ↔ 최소공배수. |
| T2 | 문제의 **전제를 깨는 보기는 넣지 않는다** (예: B = {x, 6} 에서 「x = 6」 → 학생이 헷갈림). |
| T3 | 숫자가 바뀐 판에서 **함정이 정답과 같아지는 경우가 없게** 생성 조건을 둔다(검산 시험으로 확인). |

## 4. 화면 · 판

| # | 규칙 | 배운 곳 |
|---|---|---|
| P1 | 🔥 한 판 더(숫자 바뀐 판)에는 문제 카드 맨 위 「📜 문제」 = 바뀐 숫자의 **원문 문제 전체**. | 「문제 상황 없이 소문제만」 |
| P2 | 형평성 = **문제 문장 · 숫자 · 형성평가**만 반끼리 같게. 게임 단계를 바꾸면 **학생 학습지 칸(① ② ③ · 💡 자리)도 같이** 바꿔 새 판(vN+1)으로 — 종이와 게임이 어긋나면 안 됨. | #26 · 7차시 v3 「아직 예전 소문제 티가 나」 |
| P3 | 테스트 모드도 학생과 같은 과정 (다른 건 정찰 5초 · 지갑뿐). | #47 |
| P4 | **아래 칸 = 「⚔ 공격」 + 「✍ 서술형 도전 📸」(언제나)** · 대장 처치 뒤 = 「🔥 한 판 더 (n/3)」 · ⛓ 묶기 · 💚 힐 중 학생이 고름 · **저절로 다음 판으로 넘어가지 않음** · 서술형 통과 = 남은 단계 모두 푼 것으로. | #50 「한 번 더를 누르지 않았는데 넘어감」 · 「서술형을 언제든」 |

## 5. 보여 드리기 전 스스로 검사 (머리 방 · 매번)

1. **첫 판 「나의 풀이」를 끝까지 써 본다** (교과서 숫자로 · 줄마다 어느 단계에서 생기는지 표시).
2. 줄마다 묻기: 이 줄이 **아직 안 푼 단계의 답 · 방법을 보여 주나?** → 보이면 자리 옮김(R2).
3. 졸개마다 묻기: S1 개념 하나? · S2 조건 뜻 졸개 있나? · S3 결론 전 「언제」 있나? · S5 ○/✕ 없나? · S6 세기 노가다 없나?
4. 보기마다 묻기: T1 실제 착각인가? · T2 전제 깨나?
5. 숫자 바뀐 판 하나를 머리로 만들어 같은 검사 · P1 문제 상자에 무엇이 뜨는지 확인.
6. 통과한 것만 시안으로 · 시안 표에 「스스로 검사 ✔」 한 줄.
