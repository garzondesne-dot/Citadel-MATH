# 「모두와 던전 : 공통수학2」 에셋 디자인 지침 (외부 제작용)

이 문서는 게임 그림을 새로 만들거나 바꾸는 사람(또는 이미지 생성 AI)에게 주는 지침입니다. 함께 받은 **스크린샷**과 **스타일 기준 시트**(`style-reference.png`)를 먼저 보세요.
**이 문서의 크기 · 칸 배치를 지키면 코드를 고치지 않고 그림만 바꿔 끼울 수 있습니다.**

## 0. 게임 한 줄 소개

- 특성화고 1학년 수학(공통수학2) **수업 시간**에 학생 스마트폰 · 교사 폰 · 교실 TV(종합상황실)로 함께 하는 **협동 던전 레이드**입니다.
- 수학 문제 = 몬스터입니다. 학생들이 각자 문제를 풀면, 맞힌 만큼 반 전체가 공동 체력을 깎습니다.
- 수업 밖에서는 모닥불(개인 공간)과 모루(개념 카드 연성)를 이용합니다.
- 대상은 **수학에 자신 없는 고등학생**입니다. 무섭거나 잔인하지 않고, 귀엽고 씩씩하며 "해 볼 만하다"는 느낌이어야 합니다.

## 2. 공통 기술 규칙

| 항목 | 규칙 |
|---|---|
| 파일 형식 | **PNG(투명 배경, 원본)** 로 주면 우리가 WebP로 압축합니다. WebP로 줄 경우 투명 그림은 알파 포함 |
| 투명 | 캐릭터 · 몬스터 · 포털 · 아이콘 · 나무 · 모루 등 **배경 위에 올리는 그림은 모두 완전 투명 배경**. 흰 바탕 · 체크무늬를 그려 넣으면 안 됨 |
| 칸(셀) 시트 | 한 장에 여러 칸을 **같은 크기의 격자**로 배치. 칸 사이 여백도 칸 안에 포함(칸 경계를 넘어 그리지 않음) |
| 정렬 | 같은 줄의 프레임은 **발 위치(바닥선) · 몸 중심이 같은 자리**. 프레임마다 위치가 달라지면 화면에서 덜컹거립니다 (모닥불 v1 실제 사례) |
| 바라보는 방향 | 용사는 **오른쪽**, 몬스터는 **왼쪽(용사 쪽)**. 반대로 그렸으면 알려 주면 게임이 뒤집어 씀 |
| 여백 | 칸 안에서 캐릭터는 칸의 약 75~85%. 발 아래 5~8% 여백 |
| 해상도 | 아래 표의 크기 이상. 더 크게 그려도 되지만 **가로세로 비율**은 지킴 |
| 파일 이름 | `종류-이름-v버전.png` (예: `monsters-unit3-v1.png`). 그림을 고치면 **버전 숫자를 올림** (앱이 그림을 캐시하므로 같은 이름이면 안 바뀜) |

## 3. 에셋 종류별 명세

### 3-1. 용사(학생 캐릭터) 시트 — `heroes-*.png`
| 항목 | 값 |
|---|---|
| 격자 | **4열 × 8행** (현재 887×1774, 칸 약 222×222) |
| 행 | 한 줄 = 용사 1명 (8명). 기본 시트의 **8번째 줄은 선생님**(현자) |

## 4. 하지 말 것 (자주 생기는 문제)

1. 칸마다 캐릭터 위치 · 크기가 다름 → 애니메이션이 흔들림
2. 투명 배경 대신 흰 바탕 · 체크무늬 그림
3. 그림 안에 글자 · 숫자 · 수식 (게임이 그 위에 씀)
4. 칸 경계를 넘는 무기 · 이펙트 (옆 칸으로 잘려 들어감)
5. 몬스터가 오른쪽을 봄 (용사와 마주 보지 않음)
6. 지나치게 무섭거나 잔인한 표현, 기존 게임 캐릭터를 닮음
7. 부드러운 일러스트풍 · 3D 렌더풍 (도트 느낌이 깨짐)

## 5. 납품 체크리스트

- [ ] 크기 · 격자(열 × 행)가 명세와 같다
- [ ] 투명 그림은 알파가 있다 (바탕이 실제로 비어 있다)
- [ ] 같은 줄 프레임의 바닥선 · 중심이 맞는다
- [ ] 용사는 오른쪽, 몬스터는 왼쪽을 본다
- [ ] 그림 안에 글자가 없다 (브랜드 제외)
- [ ] 32~64px로 줄여도 알아볼 수 있다
- [ ] 파일 이름에 버전이 있다 (`-v1`, `-v2` …)
- [ ] 이름 목록을 함께 준다 (몬스터 이름 · 나무 경계 · 작업면 위치처럼 게임에 적을 값)

## 6. 이미지 생성 AI용 프롬프트 틀 (영문)

**공통 앞부분**
> Original 16-bit JRPG pixel art, crisp stepped pixels, dark navy outlines, top-left lighting with navy shadows, warm torch light and soft cyan magic glow, cute and brave (not scary, no gore), palette navy #0a1424 / gold #e8b85a / cyan #5ae8ff / ember #ff9a2a, transparent background, no text, no letters, no numbers, no logos.

**몬스터 시트**
> SPRITE SHEET exactly 3 columns × N rows, equal 256×256 cells, one monster per row, columns left→right: idle, attack, defeated (cute flattened, X eyes). Every monster faces LEFT. Same ground line and center in all three cells of a row. Monsters themed for a [던전 테마] math dungeon, may wear subtle set-symbol runes (∈ ⊂ ∅) as ornaments. Full alpha transparency, nothing crossing cell borders.

**용사 시트**
> SPRITE SHEET exactly 4 columns × 8 rows, equal square cells, one chibi hero (2–2.5 heads tall) per row, columns: idle, walk, attack, knocked down. All face RIGHT, identical foot line per row, readable at 26px.

**던전 배경**
> 1672×941 dungeon battle background, frontal perspective, lower 40% flat walkable floor for 25 small heroes, upper center calm space for one large monster, [테마] theme, no characters, no text.

**포털**
> 2 columns × 1 row, left: active swirling cyan portal gate, right: the SAME gate sealed (dark, vines/stone), identical frame position and size in both cells, [테마] materials, transparent background.
