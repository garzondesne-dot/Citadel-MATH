# 수업 PPT (모션그래픽 UI 데모 스타일)
- `gen_ppt6.js` — 6차시 개념 PPT: 웜그레이 바탕 · 알약 ↔ 흰 카드 · 의미 색 · K.C.W · 슬라이드마다 PowerPoint 「모핑」 전환(같은 이름 `!!…` 도형이 이어서 변함, 2019 · 365) · 없는 버전은 페이드.
- 글꼴 = 맑은 고딕(학교 PC 기본) · 수식 Times New Roman 이탤릭. 색칠 영역 = SVG 마스크 PNG, 선 · 글자 = PowerPoint 도형(고칠 수 있음).
- 실행: `npm i pptxgenjs sharp jszip` 한 폴더에서 `NODE_PATH=<그 폴더>/node_modules node tools/ppt/gen_ppt6.js "(06차시) 개념PPT_v1.pptx"` → pptx 스킬 `validate.py` → 드라이브 04 수업PPT.
