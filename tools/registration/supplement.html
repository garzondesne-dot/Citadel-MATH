2. 창작 과정

단계신청인이 한 일
설계수업 구조 · 규칙 · 수치 · 판정 기준 · 카드 조합 원칙을 정하고, 확정안을 검토한 뒤에만 구현하게 함 (「진행」 승인 방식)
구현 지시 · 검토AI가 작성한 화면 · 규칙을 직접 시험하고, 틀린 점 · 바꿀 점을 구체적으로 지시 (예: 「20초마다 45초 멈춤」 오류 발견 → 「45초마다 1초」로 수정 지시)
수업 적용본인 담당 5개 반 실제 수업에 적용, 학생 반응을 보고 규칙을 다시 정함 (저장 시점, 학습지 분량, 쉼터 놀이 추가, 오답노트 표시 방식 등)
그림무대 · 몬스터 · 아이콘의 칸 배치 템플릿을 정하고 이미지 생성 AI 결과물 중에서 선택 · 배열 (그림 자체는 등록 대상에서 제외)
