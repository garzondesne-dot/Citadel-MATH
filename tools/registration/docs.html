2. 「저작물 내용」 란 초안 (안내서 부록 1 형식: ① 개요 ② GAI 산출물 ③ 인간의 창작적 표현)

① 신청물 전체 개요 교사가 입력한 학습지 문항을 「몬스터」로 바꾸어, 학생 스마트폰 · 교사 스마트폰(리모컨) · 교실 화면(종합상황실)이 실시간으로 함께 진행하는 협동 수업 프로그램이다. 반 전체가 공동 체력을 깎는 레이드, 숫자를 바꾼 재도전, 친구 돕기(힐), 형성평가 보스전, 쉬는 시간 반 전체 놀이(밸런스 · 반대로 · 수학 OX), 수업 뒤 오답노트 · 보충 던전, 교사용 출석부 · 수업 일지 · 학급 대시보드로 구성된다. 특정 교과서의 내용은 포함하지 않으며, 문항은 교사가 입력하는 차시 데이터이다(복제물에는 등록용 예시 차시 1개만 포함). ② 활용된 GAI 산출물 • 소스코드: 생성형 AI(Anthropic Claude, 코드 작성 도구)가 신청인의 지시에 따라 작성 · 수정한 코드가 대부분을 차지한다. 신청인은 기능 · 규칙 · 화면을 문장으로 지시하고, 결과를 실제 수업에서 시험하여 수정을 지시하였다.
• 그림(몬스터 · 배경 · 아이콘 등): 이미지 생성 AI 산출물 — 복제물에서 제외하였고 등록 대상이 아니다.
• 놀이 질문 · OX 문장 · 화면 문구: AI가 초안을 쓰고 신청인이 고르고 고쳤다 (신청인이 직접 쓴 문장이 있으면 ③에 옮겨 적을 것). ③ 인간의 창작적 표현 부분 (신청인이 사실대로 채울 칸 — 아래는 기록에 남은 것 중 후보)
• 수업 구조와 게임 규칙의 구체적 설계: 차시 = 던전, 문항 = 몬스터, 공동 체력 공식(인원 × 소문제 × 기준%), 재도전 4회 · 숫자 변경, 고친 문항에 더 큰 경험치, 정답 · 오답 글자를 교실 화면에 띄우지 않는 원칙, 쉼터 · 집중모드, 오답노트 색 체계 등 (결정 기록 32개 항목)
• 화면 구성 · 배열의 선택: 교사 메뉴 · 캠프 · 무대의 배치, 아이콘 · 무대 그림의 선택과 배열
• 신청인이 직접 작성한 문서 · 문항 · 코드가 있다면 그 파일과 위치
※ 안내서: 「단순 아이디어만을 기술하면 안 되고, 그 아이디어를 어떻게 구체화하여 최종 결과물에 표현하였는지」를 적어야 하며, 복제물에서 확인할 수 있어야 함. 규칙 · 아이디어 자체는 저작권 보호 대상이 아닐 수 있음.
