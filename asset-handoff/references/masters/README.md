# references/masters/ — 승인된 마스터 (정답지)

- 파일: `{ID}_master.png` — 선생님이 승인한 **대기(idle) 1프레임** 원본 그대로 (#4 가 `outputs/{ID}/{ID}_idle_1.png` 에서 복사).
- 이 파일이 그 캐릭터 · 몬스터의 **유일한 기준**. 다른 동작을 만들 때 첨부는 **이 마스터 + 템플릿 한 칸만** (앞 결과물을 이어 쓰지 않음 · 사슬 금지).
- 틀어짐 검사 기준: 실루엣 높이 · 폭 ±5% · 주요 색이 같은 팔레트 칸 · 장비 · 표식 · 룬 유지 · 방향(몬스터 = 왼쪽).
- 게임에 이미 있는 시트를 고칠 때: 그 시트의 대기 칸을 잘라 `{ID}_master.png` 로 둔다 (#4).
