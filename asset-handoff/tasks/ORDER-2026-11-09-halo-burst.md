## 1. `halo-burst` — 후광 빛 입자 퍼짐 (반복 재생)

| 항목 | 값 |
|---|---|
| 템플릿 | `templates/tpl-halo-burst-160x6.png` · **160×160 × 6칸 가로 한 줄** (960×160) · 반복 재생(6칸 → 1칸으로 끊김 없이) |
| 배경 | **검정 `#000000`** (빛 효과 · 밝기 = 진하기) |
| 기준 | 회색 원 = 지금 후광 고리 자리(중심 x80 · y80 · 지름 78px) · 파란 점 = 중심. **회색 원 · 점 · 칸 선은 그리지 않음** |
| 모양 | 고리 **안쪽 뒤에서** 생긴 작은 빛 입자(점 · 작은 4갈래 반짝이 · 아주 작은 빛 깃털)가 **고리 중심에서 바깥 방향(방사형)으로** 흘러나가 **원 밖으로** 퍼지며 작아지고 흐려져 사라짐 |
| 양 | 한 칸에 입자 10~16개 · 크기 1~4px · 큰 반짝이는 칸마다 1~2개만 |
| 퍼지는 거리 | 고리 테두리(반지름 39) 근처에서 가장 밝고 → 반지름 70 근처에서 사라짐 (칸 밖으로 나가지 않음) |
| 방향 | 사방으로 고르게 (위쪽이 조금 더 많아도 됨) · 중심 안쪽(반지름 30 안)은 **비움** — 용사 머리가 그 자리에 옴 |
| 색 | 흰 · 연금빛(#fff6c8 · #ffe08a · #ffd25a) · 아주 옅은 하늘빛 점 몇 개. 무지개 · 분홍 · 보라 · 초록 금지 |
| 움직임 | 6칸 동안 각 입자가 바깥으로 한 걸음씩 이동 → 6칸째 사라진 입자 자리에 1칸째 새 입자가 고리 근처에서 생김 (끊김 없는 반복) · 번쩍임 · 깜빡임 없이 잔잔하게 |
